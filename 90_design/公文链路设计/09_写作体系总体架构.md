### 0.1 v1 丢了什么

v1.0 只做了 W1–W5 五层骨架与三向映射，**把"底层原理与基本假设"漏了**——那部分在已作废的 `07_L1-L5五层知识架构设计.md` 里叫 L0 公理层，是整条挂钩链的根。丢了它的后果在那份稿子里已经论证过：

## 一、A 层：底层原理与基本假设

这一层不解决"怎么写"，解决"凭什么这么判断"。全部条目跨文种、跨粒度成立，是下面所有层的推导根。

### 1.1 六条公理

| 编号 | 公理 | 推出什么 | 管辖 |
|---|---|---|---|
| **A1** | **公文是权力的书面运行**，不是自我表达 | 受众意识、WA 目标法、立意对象感；问题段要克制（写重了等于替领导下判断） | W1 全部、W4 分寸 |
| **A2** | **读者是拍板的人，时间是最稀缺资源** | 结论先行、SCQA 开门见山式、标题结论化、段首撮要 | W2、W4 |
| **A3** | **一次表达只支持一个核心结论** | 主旨句必须是判断句、论点不流窜、以上统下 | W1 闸、W2、W5 核销 |
| **A4** | **说服力来自证据链而非形容词** | 论据三元素、数据须有对比基准、零信息句清除、大话降级 | W3、W4 |
| **A5** | **同层必须穷尽且互斥，否则读者不知道你漏了什么** | MECE、三种排序、总分计数、互换测试 | W2、W5 |
| **A6** | **先框架后文字，改框架的成本是改终稿的十分之一** | 提纲不可跳过、确认点 2 冻结、失分退回 W2 而非 W4 | 全流程 |

六条的来源是五本书的共识部分，不是我造的：A1/A2 来自胡森林的公文本质论与领导意图三层逻辑，A3/A5 来自李忠秋的金字塔（结论先行、MECE），A4 来自王群的论证三元公式与胡森林的论据四要，A6 来自胡森林七步成文与李永新的"定盘子"。

### 1.2 五条基本假设（成立才用这套体系）

公理是"永远成立"，假设是"本项目范围内成立"——**假设一旦不成立，整套体系要重估**，所以必须写明。

| 编号 | 假设 | 不成立会怎样 | 现状 |
|---|---|---|---|
| **H1** | 受众是**中国烟草行业**体制内读者，接受党政公文话语体系 | 立意、术语、分寸全部失效 | 成立 |
| **H2** | 写作目标是**通过审核并被采纳**，不是文学创作或对外传播 | 评价标准要换（创新性会压倒规范性） | 成立 |
| **H3** | **方法论可以被结构化并检索**——写作知识不全是不可言说的默会知识 | 整个 QA 库无意义 | **部分成立**，见下 |
| **H4** | 素材真实性由**人**负责，AI 不生成事实 | 违反 kb-rag 铁律一，交付物不可用 | 成立（已入门禁红线） |
| **H5** | 生成质量可以靠**门禁机械验证**到可交付水平 | 需回退到人工全审 | **待验证**，见下 |

**H3 的边界**：确有一部分是默会的（火候、分寸、政治敏感度）。处理方式是 07 章 v2 的 `enforce` 字段——可判定的进 `hard`，需语义判断的进 `soft`，纯默会的标 `advice` 只作建议不拦截。**不假装默会知识可以被规则化。**

**H5 是全项目最大的未验证假设**。20 条硬门禁能不能守住质量，要等 08 章阶段 2 首件跑完才知道。若守不住，补救方向是加人工确认点，而不是加门禁条数。

### 1.3 A 层的存储

A 层进 QA 库，`depth: axiom`，归 C6 魂，必填 `governs`（管辖哪些大类）。**不写在 SKILL 正文里**——理由见 v1 稿的三点论证：写在正文就没有 id，挂钩链断根，且检索不到。

假设（H1–H5）不进库，写在本章，因为它们是**项目级前提**而非写作知识，需要定期复核而不是被检索。

## 二、总体架构：六层

```
┌──────────────────────────────────────────────────────────────┐
│ A 层 · 公理与假设    6 公理 + 5 假设        推导根，不可检索地执行 │
├──────────────────────────────────────────────────────────────┤
│ W1 思维准备  │ 4 板块 │ 研情→立意→意图→定种                    │
│ W2 结构设计  │ 5 板块 │ 结论先行→入口→纵向→横向→提纲            │
│ W3 内容填充  │ 4 板块 │ 意群→论据→素材→详略                    │
│ W4 语言打磨  │ 5 板块 │ 标题→开头结尾→字词→句子→文气            │
│ W5 质量审查  │ 4 板块 │ 机检→语义审→站位审→终验                 │
└──────────────────────────────────────────────────────────────┘
             ↑ 每层输出 = 下层输入；不过闸不许开工
             ↑ W5 严重失分退回 W2，不退回 W4
```

### W1 思维准备（4 板块）

**过关闸：写不出判断句形式的主旨句，不许进 W2。**

| 板块 | 内容 | 功能 | 知识来源 |
|---|---|---|---|
| W1-1 研情 | 四情（上/内/下/外）、四要素（事/人/体/景）、两夹一锦素材体系 | 建素材底座，防"挤牙膏式生憋" | C6+C5，QA full 档 |
| W1-2 立意 | 立意三字经（时/事/势取交集）、好立意五感、立意三法 | 定方向，立意不准技法全废 | C6，QA full 档 |
| W1-3 意图 | WA 目标法（说服对象+期望行动）、领导意图三层逻辑 | 定受众与行动目标 | C6，QA full 档 |
| W1-4 定种 | 15 文种边界判定、行文方向（上行/下行/平行）、场合 | 决定 W2 骨架与 W5 激活哪些检查 | C1 骨，`enforce: hard` |

**判断句主旨为什么是闸**：主旨不是判断句，W2 的 MECE 无从谈起（不知道对什么做穷尽分解），W5 的论点流窜核销不了（没有主线可对照）。这道闸一松，后面四层全空转。依据 A3。

### W2 结构设计（5 板块）

**过关闸：论点树不过 MECE + 互换测试，不许展开正文。**

| 板块 | 内容 | 功能 | 知识来源 |
|---|---|---|---|
| W2-1 结论先行 | 一句话核心结论；三句话测试（开头三句抄出来读者知不知道你要说什么） | 立主线 | C3，A3/A2 推出 |
| W2-2 入口设计 | SCQA 四变体（标准/开门见山/突出忧虑/突出信心）+ 开头四戒 | 解决"读者凭什么看下去" | C3 开头写法 |
| W2-3 纵向逻辑 | 以上统下、so what 向上 / why so 向下、演绎与归纳 | 保证层层有支撑 | C3 主体展开 |
| W2-4 横向逻辑 | MECE（防重叠/防遗漏）、三种排序（时间/结构/重要）、三块式框架 | 保证同层不重不漏 | C3，A5 推出 |
| W2-5 提纲物化 | 三级提纲（粗纲→细纲→腹稿）、自上而下 vs 自下而上、一稿过诀窍 | 框架落纸，确认点 2 冻结 | C3 + templates |

**两种构建方向的选择规则**（这条直接决定 §三 场景一与场景二的分岔）：

```
题目明确、思路成熟   → 自上而下（从结论出发，设想疑问，逐层回答）
素材一堆、结论未明   → 自下而上（先摞→再归→再改，向上概括）
```

### W3 内容填充（4 板块）

**过关闸：段落缺概括句或数据无对比基准，须补齐。**

| 板块 | 内容 | 功能 | 知识来源 |
|---|---|---|---|
| W3-1 意群 | 意群定义（观点+支撑的最小有机组合）、意群≠段落、完整性检验 | 定内容基本单位 | C3 |
| W3-2 论据三元素 | 观点+概括叙述+典型事例三元公式；事实四要（真实/准确/典型/切题）；理论引用三注意 | 防"观点+事例"两元断层 | C3+C5，A4 推出 |
| W3-3 素材组织 | 先摞→再归→再改；按"为什么/是什么/怎么办"归堆 | 素材转内容 | C5 + paragraphs 库 |
| W3-4 详略配比 | 按文种定各板块比例（汇报成效 40–55%，调研问题-原因-对策逐行映射） | 防头重脚轻 | C1 + templates |

### W4 语言打磨（5 板块）

**过关闸：话题句标题 / 零信息句 / 可移植套话段，须改。**

| 板块 | 内容 | 功能 | 知识来源 |
|---|---|---|---|
| W4-1 标题 | 标题四戒、结论化改写、成效类/措施类/动员类公式、字数节奏 | 标题独立成立 | C2 标题规范 + title-guide |
| W4-2 开头结尾 | 开头四戒、结尾专属呼应（不可移植） | 首尾立住 | C3 开头/结尾写法 |
| W4-3 字词 | 措辞分寸、大话降级、称谓规范、程度副词须有数据支撑、烟草术语 | 准确 | C4 肉 + terms.jsonl |
| W4-4 句子 | 25 字断句、主语补全、排比节奏、领起词交替、口语转书面 | 简洁+生动 | C4 + patterns |
| W4-5 文气 | 文气中断点清零、段间过渡、长段压缩 | 通顺 | C4 + C3 过渡衔接 |

**W4-3 是烟草味的落点**：terms.jsonl 的 T2 搭配层在这里消费——光有定义没搭配，模型会写出"进行卷烟营销的推进"这类别扭搭配（见 07 章 v2 §二）。

### W5 质量审查（4 板块）

**过关闸：20 条硬门禁全绿才放行。**

| 板块 | 内容 | 功能 | 执行 |
|---|---|---|---|
| W5-1 机检 | 序号跳级/数字时间/直引号/总分计数/超长段/字数 | 零成本先筛 | `draft_lint.py`，`enforce: hard` |
| W5-2 语义审 | 措辞分寸/零信息句/25 字测试/术语对照 | 句级 | LLM，`enforce: soft` |
| W5-3 站位审 | 政治表述顺序/政策引用层级/**论点地图核销**/结构比例/首尾呼应 | 篇级 | LLM；严重 fail 退 W2 |
| W5-4 终验 | 20 条硬门禁逐条 ✅/❌ + 待人工裁决项 + 与大纲偏差说明 | 放行 | gongwen + 人 |

**退回规则**（依据 A6）：

```
失分能靠改句子解决吗？
  能  → W4 就地改
  不能 → 退 W2 重排，顺次再走 W3/W4
```

站位、论点流窜、结构比例三类，根源都在 W2，在 W4 改是徒劳。

## 三、功能结构：八类场景

用户拿到的活不止"写一篇"。八类场景共用 W1–W5，但**入口不同、跳过的层不同**。

### 3.1 场景总表

| # | 场景 | 触发 | 走哪些层 | 入口 | 主责 |
|---|---|---|---|---|---|
| **F1** | **有素材写材料** | 给了往年稿/批示/数据/调研记录 | W1→W2(自下而上)→W3→W4→W5 | 素材归堆 | gw-draft |
| **F2** | **无素材写材料** | 只有一句话需求 | W1→W2(自上而下)→**检索补素材**→W3→W4→W5 | 主旨句 | gw-search→gw-draft |
| **F3** | **结构设计** | 「搭个框架」「大纲怎么列」 | W1→W2，**止于确认点 2** | 主旨句 | gw-draft 大纲模式 |
| **F4** | **修改润色** | 「这段太虚」「这句拗口」 | 只走 W4 | 定位失分句 | gw-review 定点操作 |
| **F5** | **整稿改造** | 他人来稿/旧稿翻新 | W5 诊断→定位层→回派该层 | 诊断报告 | gw-review 诊断模式 |
| **F6** | **单点问答** | 「指导思想怎么写」「能不能用高度重视」 | 不走流程，纯检索 | 直接查库 | gw-search |
| **F7** | **素材加工** | 「把这堆材料整理成可用的」 | 只走 W3-3 | 归堆 | gw-draft |
| **F8** | **知识入库** | 「把这批资料萃取进库」 | 不走写作层 | 萃取 | gw-rag（08 章） |

### 3.2 F1 有素材写材料

**关键：走自下而上，不要一上来就定框架。**

```
① 素材归堆（W3-3 提前到这里）
   先摞——全部素材摞在一起，禁止边看边写
   再归——按「为什么/是什么/怎么办」三框分类
   再改——通读，审缺项/审意图/审结构/审亮点
② W1 立意（此时素材已在手，四情自然浮现）
   → 用信息摘要法或逻辑推论法向上概括出主旨句
   ◆闸：主旨句是判断句吗？
③ W2 自下而上搭框架 → MECE 检验 → 提纲
   ◆确认点 2 冻结
④ W3 逐块填充（素材已归堆，按框直接取）
⑤ W4 → ⑤ W5
```

**素材反过来改框架是正常的**，不算返工——归堆时发现某框素材压倒性多，说明框架比例要调。真正禁止的是跳过归堆直接写。

**与知识库的接口**：素材归堆后跑一次检索补缺口（A 级素材<5 条打「素材缺口」标签随大纲呈报，见 05 章 S2）。

### 3.3 F2 无素材写材料

**关键：走自上而下，且素材缺口必须显式暴露，不许编。**

```
① W1 四情靠检索补（上情查政策库，外情查范文库，内情下情**必须问人**）
   ◆闸：内情/下情拿不到 → 明确告知"这两块必须你提供"，不许用通用表述糊过去
② W1 立意 → 主旨句
   ◆闸：判断句
③ W2 自上而下：核心结论→设想读者疑问→逐层回答→递归
④ 检索补素材：按框架每个节点查 paragraphs/articles
   缺数据的位置写 [待补:XX] 占位
   ◆闸：[待补] 不得进终稿（20 条门禁·零编造）
⑤ W3→W4→W5
```

**F1 与 F2 的本质差别不是"有没有素材"，是框架的推导方向**：F1 由素材归纳出框架，F2 由结论演绎出框架。用错方向的典型症状——F1 硬套自上而下，会发现素材塞不进预设的框；F2 硬套自下而上，会因无米下炊而空转。

### 3.4 F3 结构设计（只到大纲）

止于确认点 2，产出 `outline.md`：主旨句 + 三级骨架（每节：标题/核心判断句/素材编号/字数）+ 论点地图 + 缺口标注。

**论点地图**是 F3 的核心产出，也是 W5-3 论点流窜核销的依据——每个论点登记它唯一的归属位置，正文出现重复即为流窜。

### 3.5 F4 修改润色（五类定点操作）

只走 W4，不惊动结构。05 章 5.4 已定义五类操作，本章补它们与 W 层的对应：

| 操作 | 触发 | 走哪层 | 产出纪律 |
|---|---|---|---|
| 提纲重构 | 「结构不对」 | **退 W2** | 重走确认点 2 |
| 标题设计 | 「标题不行」 | W4-1 | 一次出 3 个候选（选择题式呈报） |
| 段落结构 | 「这段太乱」 | W3-1 + W4-5 | 前后对照 |
| 内容修辞 | 「这段太虚」 | W4-3 | 大话降级/具象化；金句只调取不编 |
| 语句修辞 | 「这句拗口」 | W4-4 | 前后对照 |

**注意"提纲重构"虽由 F4 口语触发，实际退回 W2**——这是 §2 退回规则的应用，也是最容易被做错的一类（用户说"结构不对"，若只在句子层修补，改十遍也不对）。

### 3.6 F5 整稿改造

**反着走：先 W5 诊断，定位失分在哪一层，再回派那一层。**

```
W5 四 pass 诊断 → 出失分维度报告
  ↓
失分在 W2（站位/流窜/比例）→ 退 W2 重排 → 顺次 W3/W4
失分在 W3（无支撑/无基准）  → 补素材，结构不动
失分在 W4（措辞/句子）      → 定点改
  ↓
W5 复检
```

不重写无关板块——这是与 F1/F2 最大的区别。

### 3.7 F6 单点问答

不走写作流程，直接检索。这是知识库**使用频次最高**的场景，也是检索分层设计的直接受益者：

```
问「怎么写」类   → depth=method/technique + w_layer 过滤
问「为什么」类   → depth=axiom/principle（A 层在这里被消费）
问「能不能用」类 → C4 肉 + terms.jsonl（分寸层）
问「有没有例子」 → paragraphs / articles
```

### 3.8 F7 素材加工

只走 W3-3 的"先摞→再归→再改"，产出归堆后的素材包，不写正文。常作为 F1 的前置步骤单独交付。

### 3.9 F8 知识入库

不走写作层，走 08 章 gw-rag 流水线。列在这里是为了场景完备——用户说"把这批资料放进库"时不该被路由到写作链路。

## 四、三向映射（A/W 层 ↔ 知识库 ↔ 门禁）

### 4.1 新增字段

| 字段 | 取值 | 说明 |
|---|---|---|
| `w_layer` | W1–W5，**可多值** | 这条知识在哪层用。与 07 章 `depth`（多抽象）、`enforce`（拦不拦）正交 |

三个字段回答三个不同问题，缺一不可：

```
depth    → 这条知识有多抽象？   （axiom/principle/method/technique/rule）
w_layer  → 什么时候用？         （W1–W5）
enforce  → 违反了拦不拦？       （hard/soft/advice）
```

检索直接获益：S3 大纲阶段 `--w-layer W2` 只取结构类方法，现有 `--category c3` 做不到——C3 架里结构方法与过渡句式混在一起。

### 4.2 门禁 ↔ 方法 ↔ 公理

每条门禁反向标注它守护的方法与公理，**空缺即债务**：

| 门禁（05 章 5.3） | 守护的方法 | 层 | 依据公理 |
|---|---|---|---|
| 主旨句成立 | 判断句主旨 | W1 | A3 |
| 论点流窜=0 | 以上统下 + 论点地图 | W2 | A3 |
| 同级标题 MECE+互换测试 | 横向 MECE | W2 | A5 |
| 总分数量误差=0 | 以上统下 | W2 | A5 |
| 板块比例在文种区间 | 详略配比 | W3 | A2 |
| 段首句可还原主线 | 意群+概括句 | W3 | A2 |
| 措施句三要素齐全 | 论据三元素 | W3 | A4 |
| 零信息句=0 / 套话段=0 | 大话降级 | W4 | A4 |
| 无数字支撑程度副词=0 | 事实四要 | W4 | A4 |
| 超 25 字长句 / 文气中断 | 简洁·生动 | W4 | A2 |
| 弯引号 + 术语零违例 | 字词规范 | W4 | H1 |
| 红线 5 条 | 统稿八看 | W5 | A1 |

**有门禁无方法** → 这条门禁拍脑袋定的，补依据或删。
**有方法无门禁** → 无法验证，补检查项或降级 `advice`。

这张表填完，05 章"94 条按文种激活"才有依据——**激活规则 = 文种 × w_layer**。

### 4.3 方法论的分发规则

06 章 6.5 提出"一半 references 一半入库"，判定标准补上：

```
每次写这类文都要用？
  是 → references（常驻，省一次检索）
  否 → QA 库（按需检索）
一句话说得清？
  是 → references 要点卡
  否 → QA 库 full 档（讲透机理与踩坑）
```

| 内容 | 去向 |
|---|---|
| A 层 6 公理 | **QA 库**（depth=axiom，C6）——不写进 SKILL 正文，理由见 §1.3 |
| H1–H5 假设 | **本章**，定期复核，不入库 |
| W1 四情四要素、主旨句三检验 | gw-draft **正文**（过关闸必须常驻） |
| W2 MECE 判定、三种排序、SCQA 四变体 | references/framework-guide |
| W4 标题四戒、开头四戒 | references/title-guide |

| 各层具体技法（量大、按需） | QA 库 |
| 范例、段落、金句 | paragraphs / articles / patterns |
