## 5.1 端到端主干（落盘产物只有 2 个：outline.md 与 review_report.md，其余留会话内）

```
Jeffrey 一句话需求（+可选素材/批示/往年稿）
 → S1 意图分析(gongwen)：文种/场景/受众/行文方向/字数/基调（判定须给依据：「要钱要政策→请示不是报告」）
 → ◆确认点1 意图确认◆ ≤12 行表格；信息不足最多提 3 问；**呈报做成选择题**（两版主旨方向二选一等，
      点头不必过脑、做选择必须过脑）
 → S2 检索(gw-search)：V5 诊断→多路查询→search.py→A/B/C 分级→素材包
      （A<5 条→改写查询重试 2 轮→仍不足打「素材缺口」标签随大纲呈报）
 → S3 大纲(gw-draft 前半)：主旨句(判断句)+三级骨架(每节:标题/核心判断句/素材编号/字数)+论点地图+缺口标注
      → outline.md
 → ◆确认点2 大纲确认◆ **确认即冻结**（改大纲成本是改终稿的 1/10）；后续偏离须书面说明
 → S4 初稿(gw-draft 后半)：逐板块生成防长文漂移；板块内金字塔整合（⑥原理→③④方法→⑤实例）+过渡衔接硬性要求；
      只用 A 级深度整合、B 级点睛；缺数据写 [待补:XX] 占位；**每个 A 级素材必须被使用或显式弃用**；
      【v1.1】遇「指导思想/工作思路/工作目标/思想认识/基本原则/保障措施」类板块，
      自动追加一路检索 `--category c3 --l2 模块写法` + `模块-*` 段落范例，按模块写法要点生成
 → S5 审校(gw-review 四 pass，顺序=形→肉→魂→润色，每 pass 最多 3 轮、轮次由 review_report.md 模板字段累计，
      超限暂停上报)：
      pass1 格式审：draft_lint.py 机检(序号跳级/数字时间格式/直引号/总分计数/超长段/字数)先行
                   + LLM 补判(文种要件/行文规则/标题四戒)
      pass2 措辞审：措辞分寸/大话降级/主语残缺/零信息句/25字测试/烟草术语 YAML 对照——句级改写本 pass 内复检
      pass3 站位审：政治表述顺序/政策引用层级/论点地图核销(意思不流窜)/结构比例/首尾呼应
                   ——严重 fail 回大纲重走确认点2
      pass4 润色：文气中断点清零/最长3段20%压缩/核心句锤炼/金句只从词句大全定向调取不编——产出润色对照表
      → review_report.md（强制产物，不生成不得呈报终稿）
 → ◆确认点3 终稿确认◆ 呈报：终稿全文 + 20 条硬门禁逐条 ✅/❌+定位（按「统稿八看」分组呈现）
      + 与大纲偏差说明 + 待人工裁决项（内部数据/敏感表述——机器只标记，Jeffrey 裁决）
      + **知识库贡献分快评 0/1/2**（3 秒动作，防死因 D3）
 → 归档：drafts\YYYYMMDD_文种_主题\（终稿+outline+review_report 三件套）+ delivery_log.md 追加一行
      （日期/文种/主题/字数/回环次数/A级引用率/贡献分）；需要 docx 调 word-beautify
```

交互原则「三停、中间不扰」；短文种（请示类）确认点 1+2 合并（意图卡直接带三段要点）。

## 5.3 终稿 20 条硬门禁（唯一放行标准，ADR-008）

- **红线 5 条（0 容忍）**：政治表述顺序与固定套语零差错 / 政策引用层级零倒置 / 零编造（数据案例可溯源，[待补] 清零）/ 文种要件齐全 / 待人工裁决项全部经 Jeffrey 明示处理
- **结构 7 条**：主旨句成立 / 论点流窜=0（论点地图核销）/ 总分数量误差=0 / 同级标题过 MECE+互换测试 / 板块比例在文种区间 / 段首句可还原主线 / 结尾专属呼应
- **语言 8 条**：零信息句=0 / 无数字支撑程度副词=0 / 主语残缺=0 / 可移植套话段=0 / 超 25 字未断长句每千字≤2 / 文气中断点=0 / 措施句三要素齐全率 100%（部署板块）/ 弯引号率 100%+术语零违例

94 条质量检查（skill_quality.md）三层分配：~15 条机检（draft_lint.py）、~70 条按 pass 分配且**按文种激活**（总结五忌只在总结类跑）、~9 条前置内化为 S3/S4 生成规则（论点地图/段首撮要/措施三要素——**源头做对比末端查错便宜十倍**）。

## 5.4 修改任务入口（v1.1 新增，ADR-014）

改稿不必走完整主干，按修改颗粒度分两级入口：

**A. 整稿改造**（他人来稿 / 旧稿翻新）：gw-review 诊断模式 → 出三审报告+失分维度定位 → gongwen 回派 gw-draft 定向重写失分板块 → gw-review 复检。（v1.0 已有）

**B. 定点修改**（五类操作，直接说人话触发，如「这个标题再想几个」「把指导思想那段重写」）：

| 操作 | 触发示例 | 执行 | 知识调用 |
|---|---|---|---|
| 提纲重构 | 「大纲重新搭」「结构不对」 | gw-draft 大纲模式重出 outline，重走确认点 2 | c3 全小类 + c1 骨架 + 模板库 |
| 标题设计修改 | 「标题不行」「给几个标题方案」 | gw-review 标题操作：按标题四戒+文种标题规范出 3 个候选方案供选 | c2 标题规范 + c4 惯用语 + 词句大全标题模式 |
| 段落结构修改 | 「这段太乱」「重排这一段」 | gw-review 段落操作：段首撮要/总分对应/MECE 重排/过渡补全，出前后对照 | c3 主体展开·过渡衔接 + 段落库同 func 范例 |
| 内容修辞修改 | 「这段话太虚」「加点实的」 | gw-review 内容操作：大话降级/具象化（数字/场景锚定）/金句定向调取不编 | c4 措辞分寸·惯用语 + patterns 句式库 |
| 语句修辞修改 | 「这句拗口」「排比整齐点」 | gw-review 语句操作：25 字断句/主语补全/排比节奏/领起词交替 | c4 + patterns |

**模块写法借鉴**（贯穿 B 类各操作与 S4 初稿）：凡涉及「指导思想/工作思路/工作目标/思想认识/基本原则/主要任务/保障措施/组织领导」等常用模块，先查 `--category c3 --l2 模块写法` 的方法 QA + `模块-*` 段落范例，再动笔——**先看库里怎么教、范文怎么写，再改**。速查版模块要点常驻 `gw-draft/references/modules/`（见[第六章 6.3](06_Skills体系.md)）。

定点修改的产出纪律：一律附**前后对照**（只列改动句/段），不整稿重发；改动若波及论点地图（内容增删）须声明并同步 outline。
