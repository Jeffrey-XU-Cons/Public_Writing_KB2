# 公司管理成熟度评价体系建设工作汇报材料

企业管理部

各位领导，同志们：

根据会议安排，下面我就管理成熟度评价体系建设工作开展情况作汇报。

一、工作开展情况

自10月17日公司管理成熟度评价体系全面建设启动会召开以来，在各部门大力支持和共同努力下，初步完成管理成熟度评价体系的能力域、能力子域及核心要素的编制工作，稳步推进关键举措和等级特征的制定。现将有关情况汇报如下。

**一是统筹策划，分层培训**。统筹制定《管理成熟度评价体系建设实施方案》，明确成熟度评价体系建设工作组织安排和整体时间计划，为工作有序推进筑牢基础。组建技术研发、原料保障、物资保障、生产制造、市场营销、物流管理、综合管理、卷烟厂八个专项业务组，强化专业力量统筹，形成分工合理、协同高效的专项推进格局。组织开展1场编制人员集中实操化培训，帮助参训人员掌握编制方法，并结合业务差异分组开展8场定向编制培训，为体系建设奠定扎实基础。

**二是****挂图作战，强化评审。**建设办公室根据《管理成熟度评价体系建设实施方案》工作要求，借鉴成熟度试点评价准则建设的经验教训，梳理形成8个阶段、25个关键步骤的成熟度评价体系建设任务图，按节点跟踪起止时间、责任部门和推进进度，并定期更新建设情况，确保体系建设按序推进、稳步落实。建立“业务组内部评审—项目组技术评审—建设办公室综合评审”的三级审核流程，以“分层把关 + 多方协同”模式，确保审核责任清晰、专业把关充分、成果质量可控的效果。

**三是多方协同，加快推进。**一方面，建设办公室依据“6+1+1”成熟度架构，结合公司内设机构职责、流程体系、标准体系及数字化能力架构，牵头初步起草能力域、能力子域及核心要素框架。各业务组立足业务实际开展内部评审修订，形成初步成果。11月6日至7日，组建技术评审组逐项评审；11月19日至20日广泛征求相关部门意见，最终初步形成涵盖43个能力域、165个能力子域、453个核心要素的成熟度评价内容清单。另一方面，按照统一成熟度等级标准，各业务组参照一流企业标杆、行业发展要求、先进管理理念，充分识别当前能力要求和未来提升方向，梳理核心要素在特定成熟度等级下应采取的活动、方法、行为或达到的状态，按照统一描述方式和举措数量要求，制定各核心要素不同等级关键举措。截至11月20日，六个核心业务组和综合管理已经完成关键举措和等级特征初步制定。其中安全管理模块超计划提前完成了成熟度评价条款的编制。

二、存在问题

**一是思想观念需要转变**。部分人员对工作重视程度不够高，没有认识到成熟度评价体系建设的必要性，对发现问题、揭示差距、对标先进的价值理解不深。

**二是对成熟度评价理解不到位**。成熟度评价体系对象是整个条线业务，不局限于部门工作，要穿透条线业务，但是当前仍然存在成熟度仅仅涉及局限于部门工作的观点。

**三是部门协同有待强化**。部分需多部门共同参与的核心管理流程，因各部门之间信息互通共享不足、协同联动不够顺畅，一定程度上制约了整体工作效率的提升。

三、下一步工作安排

紧扣12月底前形成公司管理成熟度评价体系初稿的目标任务，按照成熟度评价体系建设实施方案要求，倒排工期、挂图作战，扎实推进体系建设各项工作，聚力推进关键举措、等级特征、评价条款及评价准则编制和评审工作，确保按期高质量完成既定任务。

**一是深入开展评价准则编制培训**。组织评价条款、评价准则编制专题培训，通过理论讲解与实操演练相结合的方式，帮助编制人员和业务骨干进一步理解评价体系建设的目的意义，掌握编制流程与标准要求。同时，结合业务实际重点难点问题，强化培训针对性与实效性，确保相关人员具备体系编制、优化及落地应用的实操能力，为稳步推进评价体系建设、保障整体建设质量筑牢基础。



**二是扎实开展等级特征、关键举措评审修订。**各业务组根据已有成果，梳理基础管理和卷烟厂的等级特征、关键举措，组织相关部门（单位）评审等级特征、关键举措的完整性、有效性，评审后关键举措清单报建设办公室。12月1日至10日，建设办公室按照三级审核流程对等级特征、关键举措进行审核。



**三是稳步推进评价条款、评价准则编制。**各业务组根据等级特征描述，围绕关键举措，编制成熟度等级评价条款，编制过程需确保条款既保留关键举措的核心价值，又符合成熟度条款的规范要求。12月底，各业务组按照评价条款是否清晰、准确，是否符合公司实际，是否具有可验证性、可操作性开展内部评审，根据评审意见进行修订，进一步形成各项业务的评价准则。
