# 3.6　评价体系运用

## 3.6.1　评价策划

- 3.6.1.1 识别评价需求：明确评价对象（核心业务 / 综合管理 / 卷烟厂）与评价关注点
- 3.6.1.2 确定评价类型：自评（内部实施）或他评（第三方实施）
- 3.6.1.3 界定评价范围：涵盖能力领域、部门单位、岗位人员、时间区间
- 3.6.1.4 组建评价团队：评价组长职责与成员构成（内外部专家组合）
- 3.6.1.5 编制评价实施方案（目标、范围、计划节点、分工、工具方法）

## 3.6.2　证据收集方法

- 3.6.2.1 四类取证方式
  - 人员访谈：访谈关键岗位人员，验证制度执行与机制运行实况
  - 文件与记录审阅：审阅制度、流程、台账、报表等管理文件
  - 现场观察：实地核查作业现场、系统操作、过程执行情况
  - 数据采集与比对：提取系统数据，验证指标结果与管理成效
- 3.6.2.2 证据充分性要求：直接证据为主，间接证据与访谈观察为辅

## 3.6.3　条款符合性评分方法

- 3.6.3.1 五档评分标准

  | 满足程度   | 得分 | 核心判定标准                       |
  | ---------- | ---- | ---------------------------------- |
  | 全部满足   | 1.0  | 直接证据充分，实施完整，未发现不足 |
  | 大部分满足 | 0.8  | 直接证据准确，存在个别轻微不足     |
  | 部分满足   | 0.5  | 证据不充分，仅实施了部分要求       |
  | 基本不满足 | 0.3  | 文件缺失或严重不全，实施停留表面   |
  | 不满足     | 0.0  | 无管理文件，无直接或间接证据       |

- 3.6.3.2 评分关键原则：以事实和数据为依据，评价结论需组内评审达成一致

  ### 5.1　直面差距：体系建设中的问题与不足

  > **讲解要点：** 在肯定前期成绩的基础上，保持清醒认识，从"体系质量"和"组织能力"两个层面，系统剖析当前存在的短板。不回避问题，体现"问题就是机会，就是潜力"的导向。

  #### 5.1.1　评价标准的科学性有待提升

  - **对标一流的深度不够。** 部分评价条款对国家战略部署、行业政策要求、标杆企业实践的吸收借鉴不够充分，与"产品卓越、品牌卓著、创新领先、治理现代"的世界一流企业要求相比仍有差距。
  - **等级递进关系不够清晰。** 部分能力域等级划分的科学性、等级间递进逻辑的严谨性有待加强，存在"级次提升仅靠频次范围扩充，而非手段方式质变"的问题。
  - **条款颗粒度一致性不足。** 跨业务领域的评价条款在表述规范性、颗粒度均匀性方面仍有差异，同类业务要求不统一的问题尚未完全解决。

  #### 5.1.2　体系的系统集成有待深化

  - **纵向贯通有待加强。** 公司级评价与卷烟厂评价的衔接机制尚不完善，部分能力域在两级之间的对应关系、评价尺度的一致性需要进一步理顺。
  - **横向协同有待优化。** 核心业务与综合管理、业务条线之间的交叉领域边界划分需要更加精准，跨部门协同管理能力的评价覆盖有待完善。

  #### 5.1.3　认识深度有待加强

  - **对评价本质的理解存在偏差。** 部分单位和人员对成熟度评价停留在"打分排名"的表面认识，对其"诊断提升、引领发展"的功能理解不够深入；部分人员不愿正视当前管理现状，缺乏"问题就是机会"的思维转变。
  - **对评价范围的认识有局限。** 存在将成熟度评价局限于部门工作、而非穿透整个条线业务的认识偏差，对评价体系跨部门协同、全流程贯通的要求认识不足。

  #### 5.1.4　队伍能力需要持续提升

  - **理论体系掌握不够系统。** 编制人员对成熟度评价的理论方法、等级设计逻辑、标杆管理规范的理解深度不够，影响条款编制质量。
  - **评价实施能力储备不足。** 面向下一阶段的评价实施，评价能力、证据识别能力、报告编写能力等关键能力亟需提升，专业化评价队伍建设任重道远。

  - **10月：公司整体评价。** 汇总各领域、各卷烟厂评价报告，从公司整体视角系统分析，全面评估管理成熟度现状，形成公司管理成熟度评价报告。
  - **8月—12月：评价问题改进实施。** 针对识别出的短板弱项，深入分析研究，制定改进措施，明确责任人和完成时限，建立改进跟踪督办机制，将评价发现转化为效能攻坚任务。
  - **12月：评价体系优化完善。** 根据评价实践和反馈意见，全面优化评价准则、评价流程和评价工具，为评价体系全面应用奠定基础。

  > **标志性成果：** 完成首轮全覆盖式评价，形成公司管理成熟度评价报告和问题清单，评价体系优化完善到位。
