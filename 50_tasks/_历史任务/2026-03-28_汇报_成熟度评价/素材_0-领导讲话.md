# 副总

（2025年10月17日）李特朗

高质高效完成成熟度评价体系建设

李晖总经理在管理效能攻坚启动会上明确指出，要用好管理成熟度评价，持续提高整体绩效和管理能力，推动公司管理成熟度水平迈上新台阶。从长期看，开展管理成熟度评价是一项顺应发展、促进发展、必须做好的创新性工作，早推进、早启动、早完成、早见效。各部门、各单位要认真贯彻李晖总经理讲话精神，将管理成熟度作为推进管理效能攻坚工作的重要抓手，高质高效推动成熟度体系全面建设，努力探索走出一条质量更好、效率更高、服务更优的管理提升新路径。

（一）始终坚持卓越导向。**一要理解核心本质。**成熟度评价的深层内核在于“持续改善、追求卓越”，是锚定打造一流现代化烟草工业企业远景目标，对标世界一流企业的管理理念、模式、方法，通过构建科学闭环的评价体系，对公司管理水平进行穿透式、周期性诊断，引导企业锚定标杆、着眼未来、追求卓越，将“自我完善”融入日常管理，将“持续改进”内化为常态机制，推动管理能力迭代升级。**二是把握关键作用。**成熟度评价的关键作用，集中体现在“打牢基础、引领发展”的协同发力上，其能够有效梳理管理体系的薄弱环节，指明下一步发展方向和工作提升路径，推动管理流程从“合规运行”向“高效协同”优化，技术应用从“满足需求”向“引领创新”升级，队伍能力从“胜任岗位”向“专业精进”跨越，实现管理水平持续提升和关键指标的争先进位。**三是树立正确认识。**成熟度评价的本质是一种帮助企业诊断问题、改进提升的工具、手段和方法，是服务企业长远发展的重要抓手，要正视当前管理状态，将关注点聚焦到今后一段时期的持续改进提升，科学、合理、客观的描述等级特征、编制评价条款、建立评价体系。

（二）准确把握编制原则。**一是坚持战略引领。**评价体系必须遵循中央关于国资国企改革等一系列重大战略部署，服务于企业发展战略和改革方向，聚焦“提升什么能力以实现战略目标”，确保成熟度条款设计与公司方针目标、重点任务紧密对接。**二是坚持对标一流。**以行业内外一流企业为标杆，深入研究其在业务管理、效能提升方面的先进经验，作为成熟度评价体系建设的关键指引，持续推动公司管理水平向先进看齐。**三是坚持合法合规。**要严格对照法律法规硬性标准，全面识别上级政策，系统提取公司现有制度体系要求，推动内外部要求融入评价体系，为公司合规经营提供刚性约束和正向引导。**四是坚持系统集成。**要加强一体协同、系统全面，将企业文化深度融合到评价体系建设过程中，科学理清核心业务、综合管理和卷烟厂能力成熟度评价边界，重点关注各业务能力等级划分的一致性，探索形成一套相对独立、相互支撑、覆盖全面、层次清晰的系统评价体系。

（三）全力推动任务落实。**一是紧盯目标任务。**前期，在“6+1+1”整体架构下，初步编制形成了构成及要求、生产制造核心业务和卷烟厂的评价准则。下一步，要按照责任分工，编制其余五项核心业务和综合管理成熟度评价准则，修订已试点运行的评价条款，全面建成公司管理成熟度评价体系。**二是加快编制进度。**严格落实方案确定的计划安排，坚持成熟一批，评审一批，压茬推进，确保年底前完成全部业务成熟度评价准则的初步编制，明年3月前完成评审修订。**三是确保编制质量。**编制办公室要负起牵总责任，统筹抓好工作推进，协调解决难点问题。各编制小组要负起主体责任，牢固树立“一盘棋”的思想，聚焦核心职能领域，精准界定业务能力框架，明确评价的核心范畴与重点方向，充分吸收先进企业管理模式、实践案例，逐层拆解能力等级的特征定义与关键实践，转化形成具体、量化的评价条款，为全面开展评价工作奠定基础。

（四）着力强化队伍建设。管理成熟度评价对各部门、各单位都是一项陌生的工作，也没有这方面的专业人才，在实施工作中，难免遇到各种各样的问题。各编制小组高度重视，结合业务实际、强化信息共享，选配工作态度严谨、工作作风扎实、专业能力突出的业务骨干纳入编制小组。编制办公室要从思想转变、专业知识、能力提升三个方面入手，本着“缺什么、补什么，差什么、练什么”的原则，分期分批地进行业务培训，明确该干什么，细化怎样去干，全面提升人员业务素质，努力打造一支专业化、高效化的成熟度评价队伍，保障公司成熟度评价体系建设高水平、高质量、高效率推进。
