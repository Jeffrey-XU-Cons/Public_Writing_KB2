## 七、每组执行清单（对照 04 章 §4.4）

```
① 建 30_engine/batches/B-YYYYMMDD-NN/，manifest 登记本批 articles/章节
② plan.md 预估报告：本组篇目或章节清单、预估条数、与已有条目的去重表（参照 B-20260914-01/plan.md 的写法）
③ 首篇（章）先萃 → Jeffrey 抽读口径 → 整组萃取，写 raw_output.md（10 列）
④ python3 30_engine/tools/kb_ingest.py --batch 30_engine/batches/B-xxx --dry-run，过了再去掉 --dry-run
⑤–⑧ validate / 判重 / 抽检（强制差评：指出本批最差一条）/ audit
⑨ 回 Kb-RAG 在 ThinkBook 上重跑 public_writing_qa 导入与建索引，冒烟 10 条
⑩ jsonl＋batches 同一个 commit
```

复核时**亲自数条数、亲自跑校验**，不信执行 agent 的自报：实产比预估少一截，要回头看是不是写到半截断了；报告写“N 条”，文件里要数得出 N 条。
