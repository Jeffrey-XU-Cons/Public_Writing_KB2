# B-20261004-AR-01 · 讲话类范文标注规格

- 目的：P4 第 5、6 轮 F1 起草的漏检全是“稿子相对同类成品缺了什么、多了什么”（漏传达上级部署、讲话复述方案、漏写领导责任、自造提法）。范文库给起草与审校一个对照物：写讲话前读同子类范文的 `must_haves`，逐条核对本稿有没有。
- 范围：`30_engine/batches/B-20261003-deid-个人历史交付物-r9/` 中 16 份讲话类文件（已脱敏，Jeffrey 个人交付物，07 章§3.2 列为优先）。`20_knowledge/corpus/industry_docs/industry/现场会讲话/` 50 份未脱敏，待 P2 脱敏后另批。
- 落点：`20_knowledge/articles/articles.jsonl`；校验 `kb_validate.py 20_knowledge/articles/articles.jsonl`，审计 `kb_audit.py`。
- 字段：04 章§4.1 的 id/title/doc_type/org_level/industry/summary/why_good/linked_qa/source_path/grade，加讲话类 subtype/skeleton/must_haves，加 batch_id。受控值见 `30_engine/tools/vocab.py`（SPEECH_SUBTYPES、ORG_LEVELS、ARTICLE_GRADES）。

## 每条记录怎么写

| 字段 | 写法 |
|---|---|
| id | `AR-NNNN`，标注时用分配给你的临时号，合并时统一重编 |
| title | 脱敏后的讲话标题（保留〔姓名〕〔甲地〕等占位，不还原） |
| doc_type | `讲话稿` |
| subtype | 工作会议讲话／现场会讲话／启动部署讲话／推进会讲话／培训动员讲话／总结讲话，取主要功能 |
| org_level | 讲话人所在层级：行业／省级商业／省级工业／地市级／县级 |
| industry | `烟草` |
| summary | 80—150 字：什么会、谁讲（只写职务）、讲了几点、主线是什么 |
| skeleton | 一级标题列表（原文照录，去序号外的格式符）；二级标题不录 |
| why_good | 3—6 条写法要点，每条“做法——为什么好（位置）”，必须是本文真有的、可迁移到别的讲话的写法，不写“结构清晰”“语言生动”这类空话 |
| must_haves | 4—10 条“同子类讲话起草时必须对照的要件”，每条“要件——本文怎么做（位置）”。优先覆盖：开场交代会议任务与本讲话分工；传达上级会议或文件部署并落到本单位；成绩段概括方式；问题段分寸；部署段压实责任（主要领导、分管、部门）；有方案时讲话与方案的分工（只点名还是复述）；时间节点与量化目标；结尾锚定听众。本文没有的要件不写 |
| linked_qa | 0—5 个相关 QA id（在 `20_knowledge/qa/*.jsonl` 里按问题文本找，只挂真相关的；没有就空列表 `[]`） |
| source_path | 项目内相对路径，如 `30_engine/batches/B-20261003-deid-个人历史交付物-r9/xxx.md` |
| source_anchor | 文件含多篇讲话、报告时，写本条对应哪一篇（如“副局长总结讲话部分”）；单篇写“全文” |
| grade | A：结构完整、写法可作样板；B：可参考但有明显短板（在 why_good 后用 `caveat` 字段写短板）；C：残件、提纲、非讲话，不入库（不输出记录，只在回报里列出理由） |
| caveat | grade=B 时必填，一句话写短板；A 级可省略 |
| batch_id | `B-20261004-AR-01` |

## 纪律

- 只读分配给你的文件和 QA 库；不读其他目录，不读 `50_tasks/`。
- 全部从原文提炼，不补原文没有的内容；引用原文短语用弯引号“”。
- 不还原任何脱敏占位，不写真实单位名、人名。
- 一个文件含多篇讲话时，可拆成多条记录（每条 source_anchor 不同），但只收真正的讲话，工作报告、批示不单独成条，除非它本身就是会上讲的报告且有样板价值（subtype 用“工作会议讲话”）。
