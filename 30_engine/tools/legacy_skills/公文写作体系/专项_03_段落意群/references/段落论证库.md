# 段落论证库——三元公式模板 × 三类段标准结构 × 起承转合 × 过渡词速查

> 用法：①按段型（成效/问题/部署）选标准结构 → ②套三元公式模板填观点—概括—事例 → ③用过渡词速查表把段内段间焊顺。
> 烟草具体句式与禁用表述以 `../../../skill_style.md` 第三、五节为准，本库给的是可跨文种复用的结构骨架。

---

## 一、三元公式模板（观点+概括叙述+典型事例）

> 命门是中间的「概括叙述」——删掉它，观点和事例就断桥。

**基础模板：**
```
[观点句／段旨]。           ← 本段判断（含主体+做法+成效方向）
[概括叙述句]。             ← 把后面事例的共性/机制/总量先收口，「领」出事例
[典型事例1，带数据基准]；  ← 1-2个最有代表性的具体例子
[典型事例2，带数据基准]。
```

**概括叙述句的四种写法**（任选其一搭桥）：

| 写法 | 句式骨架 | 抽象示例 |
|---|---|---|
| 面上共性式 | 「各[主体]普遍[共同动作]，实现了[共同结果]」 | 「各部门普遍围绕核心指标争先进位，实现了减天数、增产量的双向突破」 |
| 机制揭示式 | 「之所以[成效]，关键在于[机制/打法]」 | 「成效背后的关键，是把通用框架改成了扎进业务场景的具体标尺」 |
| 总量收口式 | 「累计[总量数据]，覆盖[范围]」 | 「累计完成X项整改，覆盖全部Y个能力域」 |
| 分类领起式 | 「主要体现在[N]个方面」+ 一是/二是 | 「主要体现在三个方面：一是…二是…三是…」 |

**反例（二元断桥，禁止）：**
```
[观点句]。[张三做了甲]。[李四做了乙]。   ← 观点直接跳到事例，无桥
```

## 二、三类段标准结构（与 skill_style 第三节对齐）

### 成效段：总—分（一是/二是/三是）+ 数据
```
[总体定性句，含核心数据与对比基准]。[可选·概括叙述/规律性判断一句]。
一是[成效名称]。[具体举措/做法] +[数据，必须有对比基准]。
二是[成效名称]。[具体举措/做法] +[数据]。
三是[成效名称]。[具体举措/做法] +[数据]。
```
- 进阶（重点板块用）：总体定性句后加一句「规律性判断」（鲜明/深刻/新颖/实用），从叙事升到分析。
- 红线：每条至少 1 个带基准数据；禁「只有定性没数字」「数字无对比基准」「从外部看/从内部看式咨询框架」。

### 问题段：直接列举，不展开分析
```
在肯定成绩的同时，我们也清醒看到问题和不足。
一是[问题名称]，[一句话描述]。
二是[问题名称]，[一句话描述]。
三是[问题名称]，[一句话描述]。
[收束句：这些问题务必引起高度重视，认真加以解决。]
```
- 红线：问题段**不**大篇幅分析原因（原因分析属专题汇报）；禁反复铺垫的咨询式「既是…也是…」。

### 部署段：总体要求 + 一要/二要/三要
```
[总体要求，1-2句，含量化目标]。
一要[动词+工作方向]。[具体要求，含时间节点和量化目标]。
二要[动词+工作方向]。[具体要求]。
三要[动词+工作方向]。[具体要求]。
```
- 红线：每条要有明确主责与可量化落点，不写「高度重视/扎实推进」空话。

## 三、起承转合——四要素在段落中的功能

| 要素 | 在段中的位置 | 功能 | 常用语 |
|---|---|---|---|
| 起 | 段首段旨句 | 开门见山，亮出本段判断 | （直接陈述判断，不铺垫） |
| 承 | 段旨后第一句 | 顺水推舟，承接上文或铺开本段 | 「围绕这一目标」「具体来看」「为此」 |
| 转 | 段中 | 引入递进/转折，推进论证 | 递进：「不仅…还…」「更重要的是」；转折：「但也要看到」「与此同时」 |
| 合 | 段尾收束句 | 水到渠成，回扣段旨或托出下段 | 「这就是…的根本原因」「为下一步…打下了基础」 |

> 通读检验：以每分钟约 300 字速度扫全文，卡顿处即文气断裂处，在该处补「转/承」过渡句或调整段序。

## 四、过渡词速查（段内连句 + 段间连段）

| 逻辑关系 | 过渡词/短语 | 用在哪 |
|---|---|---|
| 递进 | 不仅…还…、更进一步、在此基础上、更重要的是、尤为关键的是 | 后一层比前一层深/重 |
| 因果 | 正因如此、由此、之所以…是因为…、这就要求、有鉴于此 | 由果溯因或由因导果 |
| 转折 | 但是、然而、与此同时也要看到、值得注意的是、问题在于 | 成绩转问题、肯定转保留 |
| 并列 | 一是…二是…三是…、一方面…另一方面、同时、此外 | 同层平行要点（同段内首选「一是/二是」） |
| 总分 | 主要体现在/概括起来/总的来看（总起）；具体而言/其中（分述） | 段旨句领起分条、分条回收 |

> 提示：段间**少用**纯并列硬接（「另外」「同时」一接到底会显散），优先用递进或因果让逻辑往前走。

## 五、段落合格自检（落到一段）

源自 `../../../../04_corpus/段落库_合格标准_v1.0.md`，压成段级三问：
1. **结构成立**：有逻辑推进，不是孤立半句、不是字段残片。
2. **有可学之处**：展示了某种写法（总分/问题剖析/数据承重/政策引用后本单位阐发/收尾升华任一）。
3. **三元到位**：观点—概括—事例三层齐，数据带对比基准，同一数据不在全文重复。

判废（命中即重写本段）：开头即标点/连接词、结尾断半句、纯背景无判断、数据全无基准、与他段逐字雷同。
