# 段落意群——以意群为单位，用三元公式把论点写实

> 本 skill 解决「段落层」一个问题：让每个段落都是「一个论点+足量支撑」的完整意群，既不空（有数据有事例）也不散（观点—桥—事例三层齐）。
> 上游是框架（先有 MECE 骨架，见 `../专项_01_篇章结构`），平级是标题（段旨与标题锚定，见 `../专项_02_标题炼制`），下游是字句（删繁炼字，见 `../专项_04_遣词用字/SKILL.md` `../专项_05_炼句金句/SKILL.md`）。

## 使用场景

当用户需要：
- 框架与标题确认后，把某个板块的内容方向「填」成正式段落（填充阶段）
- 成稿后诊断某段：是不是空、有没有数据、观点和事例之间有没有「概括桥」、段落是不是太长
- 把「观点+事例」的二元病段，补成「观点+概括叙述+典型事例」的三元段
- 判断成效段/问题段/部署段是否走了对应的标准结构

不要用于：
- 设计整篇骨架、判断板块是否 MECE（用 `../专项_01_篇章结构`）
- 拟标题、做小标题对仗（用 `../专项_02_标题炼制`）
- 单纯炼一个金句、找排比素材、压字数（用 `../专项_04_遣词用字/SKILL.md` `../专项_05_炼句金句/SKILL.md`）

## 输入要求

需要用户提供：
- 文种（汇报／总结／方案／规划／调研报告／讲话稿）——决定成效段/问题段/部署段走哪套结构
- 本段的「核心论点」一句话，或该段所属板块的标题
- 可用的事实素材（数据、举措、案例）；缺数据时按工作流标注待补

如输入不足，最多追问 3 个关键问题：
1. 「这一段你要让读者接受的判断是哪一句？」（无论点写不成意群）
2. 「支撑这个判断的事实有哪些？有没有对比基准（同比/目标/历史最好）？」
3. 「这是成效、问题、还是部署段？」（决定标准结构）

## 工作流

### 流程A：写新段（填充阶段）
**输入**：本段论点 + 文种 + 可用事实素材
**步骤**：
1. 写**段旨句**——用一句话把本段判断写在段首（含主体+做法+成效），它就是后文的「帽子」。
2. 判**段型**——成效段走「总—分（一是/二是/三是）+数据」；问题段走「直接列举不展开」；部署段走「总体要求+一要/二要/三要」（结构见 `references/段落论证库.md`）。
3. 套**三元公式**——观点 → **概括叙述（桥）** → 典型事例。先写一句把观点收口、把后面事例「领」出来的概括句，再上具体事例与数据。**严禁跳过概括层直接堆事例**。
4. 配**论据三元素**——事实须过「真实/准确/典型/切题」四关且带对比基准；需要时引一句理论/政策（融会贯通、适度，不生硬）；概括叙述把二者焊到观点上。
5. **详略分配**——按详略五规律给重点条目分配篇幅，背景与已知内容压短。
6. **节奏控制**——全段≤300字；超则用「一是/二是」分条；每个分条至少 1 个带基准的数据。
7. 用「意群完整性检验」自检（模块1），未过回第 1 步。
**输出**：一个段旨领起、三元齐备、详略得当、过渡自然的完整段落
**失败处理**：
- 段旨句写不出来 → 板块论点本身没立住，退回 `../专项_01_篇章结构` 重定该板块论点
- 只有观点凑不出事例 → 退回素材调度（四情梳理），不许用「成效显著」空话占位，标 `[待补充：需XX类数据]`

### 流程B：诊断改段（成稿阶段）
**输入**：现有某段（或全文逐段）
**步骤**：
1. **拆三层**——把本段拆成「观点句／概括句／事例句」三堆，缺哪堆标红（最常见缺「概括桥」）。
2. **验数据**——每个事实是否带对比基准？同一数据是否在全文别处已出现（意思流窜）？
3. **量详略**——数清各部分字数，背景是否挤占了重点（详略倒置）？
4. **查过渡**——段首与上段尾是否硬接？段内观点到事例是否硬接？
5. **量长度**——是否超 300 字而未分条？
6. 输出「病灶清单 + 三元改写对照」，不擅自改未点名的段落（遵循修改模式，只提示）。
**输出**：段落诊断表（原段问题｜病灶类型｜三元改写）
**失败处理**：
- 补概括桥后发现事例与观点对不上 → 是事例选错，换事例而非硬圆概括句
- 补不出数据基准 → 标 `[待补充]`，不臆造数字

## 方法论模块

### 模块1：意群——内容的基本单位（地基，必过）
- **触发条件**：写任何一段、或诊断任何一段
- **核心**：**意群 = 一个观点 + 支撑它的素材**，是组织内容的最小有机单元。**意群 ≠ 段落**——一个意群可跨几个自然段，一个长自然段也可能塞了几个意群。组织文章以「意群」为单位，不是以「自然段」为单位。
- **操作步骤**：提炼观点 → 选配素材 → 有机组合 → **意群完整性检验**：①本段观点是哪一句？②用了什么事实/理论支撑？③观点与支撑之间的逻辑桥搭没搭？
- **输出要求**：每段能一句话答出「观点是X，靠Y支撑，靠Z连接」
- **常见错误**：把「换行」当「换意群」——一段里塞了两个并列论点（该拆）；或一个论点被切到两段（该合）

### 模块2：论据三元素——事实+理论+概括叙述
- **触发条件**：任何论点段，落事实时
- **三元素**：
  1. **事实论据**——须过四要素：**真实**（不编）/ **准确**（数对、口径对）/ **典型**（能代表面上情况，不取孤例）/ **切题**（直接支撑本段观点，不跑题）；且**必须带对比基准**（同比／历史最好／超额完成目标／对标差距）。
  2. **理论论据**——引政策/论述/规律时三注意：**融会贯通**（化进自己的话）/ **得体适用**（与本段主题契合）/ **适度引用**（点睛即可，不堆砌、不喧宾夺主）。
  3. **概括叙述**——观点与事例之间的「桥」，把零散事实收口成对观点的支撑，是三元公式的命门（详见模块3）。
- **常见错误**：报一个无基准的孤零数字（「完成XX万箱」）；大段抄政策原文不转化；只有事实没有把事实「说回」观点的概括句

### 模块3：三元公式——观点+概括叙述+典型事例（核心，反二元）
- **触发条件**：写成效段、经验段、任何「论点+举例」的段落
- **铁律**：合格段落是 **「观点 + 概括叙述 + 典型事例」三元**，不是 **「观点 + 事例」二元**。
  - **二元病段**：「某项工作成效显著。A 部门做了甲，B 部门做了乙。」——观点和事例之间**断桥**，读者得自己脑补「这些事例凭什么证明成效显著」。
  - **三元正解**：观点 →（**概括叙述**：用一句把这些事例的共性/机制/量级先收口）→ 典型事例（带数据基准）。
- **操作步骤**：
  1. 写**观点句**（段旨，本段判断）
  2. 写**概括叙述句**——回答「这个判断靠什么整体支撑」，给一个面上的概括、机制或总量（如「各部门围绕核心指标争先进位，普遍实现了减天数、增产量的双向突破」）
  3. 上**典型事例**——选 1-2 个最有代表性的、带对比基准的具体例子
- **输出要求**：观点句与事例句之间至少有 1 句概括叙述，删掉它读者就接不上
- **常见错误**：跳过概括层直接「张三做了…李四做了…」；概括句写成空话（「大家都很努力」不是概括叙述，「平均下降11天」式的面上量级才是）

### 模块4：段头撮要法——段旨句置首
- **触发条件**：写每一段、或诊断段落领起
- **操作步骤**：
  1. 每段/每层首部用一句**段旨句**概括本段主旨，置于段首（承上启下 + 全段提要）
  2. 写完正文回头**覆盖检验**：盖住正文只读段旨句，问「这句能否覆盖本段全部内容」——能覆盖且不超范围才合格
  3. **段头串读检验**：把全文各段段旨句抽出来连读，应能串成一篇逻辑完整的提纲
  4. 段旨句须与本板块**标题主题词锚定**（核心动词/名词重合，见 `../专项_02_标题炼制` 模块5）
- **常见错误**：段首先讲背景、判断埋在段中（应把判断提到段首）；段旨句覆盖不全（说A段里却讲了B）

### 模块5：起承转合四要素——段内与段间的衔接
- **触发条件**：写段落推进、或通读觉得「卡顿」处
- **四要素**：**起**（开门见山，段旨直入）/ **承**（顺水推舟，承接上文或铺开本段）/ **转**（见风使舵，引入递进或转折，常用「不仅…还…」「与此同时」「但也要看到」）/ **合**（水到渠成，收束回本段主旨或托出下段）
- **操作步骤**：写完通读，以约每分钟 300 字速度扫，**卡顿处即文气断裂处**，加过渡句或调顺序
- **常见错误**：只有「起承」没有「合」，事例罗列完戛然而止；段间全靠并列硬接，无递进无转折

### 模块6：过渡照应——题文/首尾/前后
- **触发条件**：段间衔接、成稿通读
- **三类照应**：
  - **题文照应**：段旨句呼应本板块标题（主题词重合）
  - **首尾照应**：段尾收束句回扣段首段旨（或全文尾回扣全文头）
  - **前后照应**：后段开头与前段结尾用过渡词勾连（递进/因果/转折/并列/总分，速查见 `references/段落论证库.md`）
- **常见错误**：段与段之间一律「另外」「同时」并列硬接；标题谈A、段首谈B（题文脱节）

### 模块7：详略五规律——篇幅按重要性分配
- **触发条件**：填充前做篇幅预算、或诊断「头重脚轻」
- **五详**：**重要详**（核心论点多写）/ **新颖详**（首次提出、有新意的多写）/ **具体详**（可操作可量化的多写）/ **近期详**（近期工作多写）/ **有特点详**（本单位独有做法多写）。对应**五略**：次要略/已知略/抽象略/旧事略/普遍略。
- **操作步骤**：填充前给每部分定篇幅预算；写完**数字数**，看篇幅是否与重要性成正比
- **常见错误**：**详略倒置**——背景写三段、重点措施只一句；把人人皆知的普遍道理详写、把本单位独创做法一笔带过

### 模块8：段落节奏——长度·分条·数据密度
- **触发条件**：每段定稿前
- **三规则**：
  1. **长度**：正文段一般**≤300字**；超则**必须**「一是/二是/三是」分条；严禁出现 >500 字无分条长段
  2. **数据密度**：成效段每个「一是/二是」条目**至少 1 个数据**，且数据带对比基准；全文数据口径统一
  3. **同数据唯一**：同一数据全文只出现一次（意思流窜见 `../专项_01_篇章结构`）
- **常见错误**：一口气写五六百字不分条；分条了却条条无数字；同一个百分比在三个段落反复出现

## 质量 Rubric

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 意群完整 | 一段塞多论点或半个论点 | 论点散、边界模糊 | 基本一段一论点 | 每段=一观点+足量支撑，边界清 |
| 三元齐备 | 只有观点或只有事例 | 观点+事例缺概括桥 | 三元基本到位 | 观点—概括—事例三层焊死，删桥即断 |
| 段头领起 | 无段旨句/判断埋段中 | 段旨偏话题、覆盖不全 | 段旨基本覆盖 | 段旨置首、全覆盖、与标题锚定 |
| 详略得当 | 详略倒置（背景挤重点） | 篇幅与重要性部分错配 | 大体匹配 | 重点详、背景略，篇幅=重要性 |
| 过渡自然 | 段间硬接、读着卡 | 个别生硬 | 多数顺 | 起承转合全、过渡词得当、无卡顿 |
| 数据落点 | 无数据或纯堆砌 | 有数据无对比基准 | 多数带基准 | 每条带基准、口径统一、不重复 |

**质量等级判定**（满分 18）：
- PASS（≥14）：可直接交付
- WARN（11-13）：可交付但建议小修
- MAJOR（7-10）：必须修订后交付
- REWRITE（<7）：建议重写本段

## 输出格式

写新段时：
```markdown
# 段落方案：[板块名/段旨]
- 段型：成效/问题/部署
- 段旨句（置首）：[一句判断，含主体+做法+成效]
- 概括叙述（桥）：[把事例收口的概括句]
- 典型事例：[事例1（数据+基准）] / [事例2]
- 自检：意群完整✓ | 三元齐✓ | 段头覆盖✓ | 字数__/300 | 数据基准✓
- 成段：[整段正文]
```

诊断改段时：
```markdown
# 段落诊断表
| 病灶类型 | 原文位置 | 问题 | 三元改写 |
|---|---|---|---|
| 缺概括桥 | 第2句直接上事例 | 观点—事例断桥 | 补「各部门普遍实现…双向突破」一句 |
总评：X/18（等级）。优先改：[病灶]。
```

## 反模式

1. **观点+事例缺概括桥（二元病段）**
   - 怎么识别：观点句之后直接「张三做了…李四做了…」，中间无收口句
   - 怎么改：在观点与事例间插一句概括叙述（面上共性/机制/总量），把事例「领」出来——见 `examples/示例_病段诊断与三元改写.md`
2. **详略倒置·背景三段重点一句**
   - 怎么识别：背景/政策铺垫占大半，本单位真正做法只剩一两句
   - 怎么改：背景压成一句，把篇幅预算挪给「具体详/新颖详/有特点详」的重点内容
3. **段落超长不分条**
   - 怎么识别：一段五六百字一逗到底，读者抓不住几个要点
   - 怎么改：按「一是/二是/三是」拆条，每条一个分论点+一个带基准的数据
4. **数据无对比基准**
   - 怎么识别：「完成XX万箱」「编制2977条」这类孤零数字，不知是多是少
   - 怎么改：加同比/目标完成率/历史最好/对标差距（「同比增2.4万箱」「完成率85.7%」）
5. **段间硬接无过渡**
   - 怎么识别：段段「另外」「同时」并列硬拼，无递进无因果，通读处处卡顿
   - 怎么改：按前后照应补过渡词（递进/因果/转折/总分），或调整段序让逻辑顺下来
