# 示例：病段诊断与三元改写——把「观点+事例缺概括桥」补成三元段

> 素材取自 `00_raw_materials` 一篇「管理效能攻坚推进情况汇报」的成效段（已脱敏：单位写「某市烟草」、人名隐去、数据改为示意值 X%/X万箱/X天）。
> 演示流程B（诊断改段），主病灶为**二元断桥**，附带**详略倒置**与**数据无基准**两处小病。

## 一、病段原文（成效段）

> 各部门效能攻坚工作成效显著。早在年初，国家局和省局就对效能攻坚作出部署，要求各单位降本提质增效；公司党委对此高度重视，多次召开专题会研究推进，成立了攻坚领导小组，印发了实施方案，明确了责任分工，营造了浓厚氛围。生产管理部派出驻厂督导联合攻坚，卷烟厂生产作业天数下降了一些；营销部门优化了配送模式，开展了当日达试点。

## 二、诊断表

| 病灶类型 | 原文位置 | 问题 |
|---|---|---|
| **缺概括桥（主病）** | 「成效显著」之后直接跳到生产管理部、营销部门两个事例 | 观点（成效显著）和事例之间**断桥**，读者得自己脑补「这几件事凭什么算成效显著」；事例之间也无面上概括 |
| **详略倒置** | 「早在年初…营造了浓厚氛围」一长串 | 上级部署、党委重视、成立小组、印发方案属**已知略/普遍略**的背景，却占了全段近半篇幅；真正出成效的本单位做法只剩两句（**具体详/有特点详**被压缩） |
| **数据无基准** | 「下降了一些」「开展了当日达试点」 | 「下降了一些」是模糊数字、无对比基准；试点只有动作无成效落点 |

**意群完整性检验**：观点=各部门成效显著 ✓；支撑=两个部门的做法 △（偏弱）；**桥=无 ✗**。三问中「桥」答不出 → 意群不完整，按三元公式重写。

## 三、三元改写

**第一步·压背景（治详略倒置）**：上级部署+党委重视压成一句帽子，不再单独成段铺陈。

**第二步·搭概括桥（治断桥）**：在观点与事例之间插一句「面上共性式」概括叙述，把后面事例的共同机制先收口。

**第三步·补数据基准（治无基准）**：每个事例配带对比基准的数据。

改写后：

> **各部门效能攻坚成效显著，X 项攻坚指标提升率达到 X%，整体质效兼优**（段旨句/观点，含核心数据基准）。年初省局部署降本提质增效后，公司党委专题研究推进、压实责任分工，各部门随即围绕核心指标争先进位——**普遍走出了「减天数、增产量、降成本」同步突破的路子**（概括叙述/桥：把各部门做法的共同机制先收口，再上事例）。**一是生产端提效。**生产管理部驻厂督导联合攻坚，在卷烟厂总产量同比增加 X 万箱的情况下，生产作业天数平均下降 X 天（事例1+对比基准）。**二是配送端提质。**营销部门优化配送模式、推行「当日达+次日达」，服务响应时间较原统一次日配送缩短约 X 小时，客户满意度同比提升 X 个百分点（事例2+对比基准）。

## 四、改写要点

- **断桥→搭桥**：插入「普遍走出了『减天数、增产量、降成本』同步突破的路子」——这是命门句，删掉它观点就接不到事例。它不是「大家都很努力」式空话，而是给出**面上共同机制**的真概括。
- **详略倒置→重点详**：背景从一长串压成一句「专题研究推进、压实责任分工」；篇幅预算让给「具体详/有特点详」的两个部门实做。
- **无基准→带基准**：「下降了一些」→「在总产量同比增加 X 万箱的情况下作业天数平均下降 X 天」（双向对比，最见功夫）；试点补上「响应时间缩短/满意度提升」的成效落点。
- **加分条与段头**：超出单层叙述，用「一是生产端提效／二是配送端提质」分条，每条一个分论点+一个带基准数据，符合段落节奏规则。
- 数据用示意值 X，实际写作须填真实、统一口径的数字，且全文同一数据只出现一次。

## 六、一句话留存

> 成效段最常见的病不是「没事例」，而是**观点和事例之间缺一座桥**——补上那句「面上共性/机制/总量」的概括叙述，二元就变三元，事例才真正「证明」了观点。
