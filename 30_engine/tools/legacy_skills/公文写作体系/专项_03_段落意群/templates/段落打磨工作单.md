# 段落打磨工作单（逐段填空）

> 用法：写新段时填「拟制区」逐层搭三元；成稿改段时填「诊断区」逐条体检。一段填一份。

## 一、基本信息
- 文种：______（决定走成效/问题/部署哪套结构）
- 本段所属板块标题：______（段旨须与此主题词锚定）
- 段型：成效 / 问题 / 部署 / 其他 ______

## 二、拟制区（写新段用——逐层搭三元）

- ① **段旨句（置首）**：______
  - 主体（谁）：______　动作（做了什么）：______　成效方向（达到什么）：______
- ② **观点**（本段要让读者接受的判断，可与段旨句同）：______
- ③ **概括叙述（桥）**：______
  - 选用写法：面上共性 / 机制揭示 / 总量收口 / 分类领起
  - 自检：删掉这句，观点与事例是否就断桥？ 是→桥有效 □
- ④ **典型事例**（1-2 个，最有代表性）：
  - 事例1：______
  - 事例2：______
- ⑤ **数据（每个事例配，含对比基准）**：
  - 数据1：______　基准：同比 / 目标完成率 / 历史最好 / 对标差距 ______
  - 数据2：______　基准：______
  - 自检：是否有无基准的孤零数字？ 有→补基准 □　全文是否已出现过同一数据？ 是→删此处 □
- ⑥ **理论/政策引用**（如需，一句点睛）：______（融会贯通□ 得体□ 适度□）
- ⑦ **成段**（把①③④⑤⑥连成正文）：

  ______

## 三、诊断区（改旧段用）

| 检查项 | 判定 | 病灶/备注 |
|---|---|---|
| 意群完整（一段一论点？） | 完整 / 塞多论点 / 半个论点 |  |
| 三元齐备（观点/概括/事例三层？） | 齐 / 缺概括桥 / 缺事例 / 缺观点 |  |
| 段头领起（段旨置首且覆盖全段？） | ✓ / 偏话题 / 覆盖不全 |  |
| 数据落点（每条带对比基准？） | ✓ / 有数无基准 / 纯堆砌 |  |
| 详略（重点详背景略？） | 得当 / 详略倒置 |  |
| 过渡（与上段、段内事例衔接？） | 自然 / 硬接 |  |
| 长度（≤300字，超则分条？） | ✓ / 超长未分条（__字） |  |
| 同数据唯一（全文不重复？） | ✓ / 与__段重复 |  |

病灶类型可选：缺概括桥 / 缺数据基准 / 详略倒置 / 超长不分条 / 段间硬接 / 意思流窜 / 段旨埋段中

- 观点与支撑之间的桥（概括叙述）是：______
- 三问都答得出 → 意群完整 □
