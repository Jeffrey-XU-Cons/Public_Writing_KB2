# 标题炼制——把话题句炼成结论句，再做亮做工整

> 本 skill 解决「标题层」一个问题：让读者只读标题就掌握核心判断，并让同层标题工整有亮点。
> 上游依赖框架（先有 MECE 骨架再炼标题），下游不负责正文展开。

## 使用场景

当用户需要：
- 框架确认后，把每个板块的「内容方向」拟成正式标题（提纲阶段）
- 成稿后逐条体检标题：是不是结论句、准不准、工不工整、跟正文呼不呼应
- 把一组并列小标题（一是/二是/三是、（一）（二）（三））做成对仗或排比

不要用于：
- 设计整篇骨架、判断板块是否 MECE（用 `专项_01_篇章结构`）
- 正文段落的论证与数据组织（用 `专项_03_段落意群`）
- 单纯找一句金句、排比句素材（用 `专项_05_炼句金句`）

## 输入要求

需要用户提供：
- 文种（汇报／总结／方案／规划／调研报告／讲话稿）——决定能否用谐音、能否用古诗起句
- 待拟/待改的标题，或该板块要表达的「核心判断」一句话
- 该标题所在层级（大标题／一级／二级）及同层的其他标题（用于对仗与 MECE 检查）

如果输入不足，最多追问 3 个关键问题：
1. 「这是讲话稿还是书面材料？」（谐音类、需默读辨义的技法只用于书面）
2. 「这个板块你想让读者记住的一句判断是什么？」（无判断无法炼结论句）
3. 「同一层级还有哪几条标题？」（不给同层就无法做对仗和 MECE 检查）

## 工作流

### 流程A：拟制新标题（提纲阶段）
**输入**：板块的核心判断 + 文种 + 层级
**步骤**：
1. 先写「裸结论」——用一句大白话写出该板块的判断（含主体+做法+成效），不追求文采。
2. 套**标题万能公式**：`[主语 Who]+[做了/要做什么 What]+[取得/预期什么结果 Result]`，压到 16 字以内。
3. 选 1 种**做亮技法**（见模块3）升级，文种不允许的技法（如讲话稿用谐音）直接跳过。
4. 对照同层其他标题做**一致性套裁**：统一句式骨架、对齐字数、对应词性。
5. 用 SPA + 结论句测试（模块1）自检，未过则回到第 1 步。
**输出**：一组工整、各自是结论句、同层 MECE 的标题
**失败处理**：
- 若「裸结论」写不出来 → 板块本身没想清楚，退回 `专项_01_篇章结构` 重定该板块论点
- 若硬凑技法导致不准确 → 放弃技法，保留朴素结论句（准确 > 花哨）

### 流程B：诊断改写旧标题（成稿阶段）
**输入**：现有全文的全部标题清单
**步骤**：
1. 把所有标题单独抄成一列，逐条做**判定测试**：「这句话有没有可能是假的？」——不可证伪的是话题句，标红。
2. 对标红的话题句，补判断改成结论句（保留原话题词作主语）。
3. 同层横向扫一遍：字数是否参差、句式是否混排、有无内容交叉（违反 MECE）。
4. 抽查每个标题与其正文首句是否「主题词锚定」（核心动词或名词重合）。
5. 输出「问题清单 + 改写对照表」，不擅自改未被点名的标题（遵循修改模式）。
**输出**：标题诊断表（原标题｜问题类型｜改写建议）
**失败处理**：
- 若改成结论句后与正文不符 → 是正文没写到位，提示而非强行改标题
- 若同层无法统一句式（板块性质差异大）→ 至少统一「字数±2、首词词性一致」

## 方法论模块

### 模块1：标题三标准 SPA + 结论句法则（地基，必过）
- **触发条件**：任何标题，拟制或诊断都先过这一关
- **操作步骤**：
  1. **S（Simple 简洁）**：大标题≤16字，小标题≤14字；一个标题只装一个判断
  2. **P（Profit 相关）**：站在读者/领导角度，标题要让人看到「与我有关、有何用」
  3. **A（Accurate 准确）**：标题说的就是本段真正写的，不夸大、不偏题
  4. **结论句测试**：把标题单抄，问「能否判真假」。能 → 结论句（合格）；不能 → 话题句（不合格）
- **输出要求**：每个标题标注「结论句✓/话题句✗」
- **常见错误**：
  - 「存在的问题」「下一步打算」「整体设计」——纯话题句，零判断
  - 标题塞两个判断（「既要…又要…且成效显著」）——违反 Simple

### 模块2：标题万能公式与三种语气
- **触发条件**：拟制新标题、或话题句需补判断时
- **操作步骤**：
  1. 套公式 `主语 + 做了/要做什么 + 取得/预期结果`
  2. 按文种选语气：**「要」字式**（讲话部署：「要持续提升管理效能」）／**陈述式**（汇报成效：「管理效能持续提升」）／**祈使式**（动员号召：「持续提升管理效能」）
  3. 成效类套「具体业务+成果词」（「管理体系建设取得重要突破」）；措施类套「着力/全力/聚焦+方向」（「聚焦核心能力，深化管理改革」）
- **输出要求**：标题含可识别的「结果/成效」落点，而非只有动作
- **常见错误**：只有动作没有结果（「坚持推进评价工作」），或只有结果没有路径（「取得重要进展」）——核心论点应路径+成效双维

### 模块3：九类做亮技法（升级层，选用）
> 蒸馏自标题结构专著的九类做亮法。**先有准确结论句，再考虑做亮**；做亮不能牺牲准确。

| 类 | 公式骨架 | 适用 | 禁忌 |
|---|---|---|---|
| 比喻类 | 动词+「比喻词」（引号标注），如「筑牢制度『防火墙』」 | 全文种，最常用 | 比喻词须与主题意象相关 |
| 数字类 | 「X个X」+比喻/成语，如「做到『三个突出』，种好『责任田』」 | 系统部署、汇报 | 数字须真有 N 条对应 |
| 重复类 | 同句式开头×3-4，换核心词，如「聚焦X，让XX『强』起来」 | 讲话、汇报 | 重复词须有强调价值 |
| 引用类 | 古诗/名言起句+行动要求 | 重要讲话 | 诗句须与主题高度契合 |
| 对称类 | 动宾，动宾（字数同、词性对、意并列/因果） | 全文种 | 前半做法、后半成效 |
| 谐音类 | 「将就」还是「讲究」式 | **仅书面材料** | 讲话稿严禁（听众无法辨音） |
| 复合类 | 引用+比喻叠用 | 有功底时的讲话/汇报 | 易堆砌，慎用 |
| 提问类 | 「为什么/怎么干/和谁干」三问式 | 讲话、方案 | 问完必须答 |
| 单字类 | 突出一个字，如「思想上充了『电』」 | 总结成果/经验 | 单字与维度搭配要自然 |

- **操作步骤**：从上表按文种+主题选 1 类（同一篇通常只主用 1-2 类，避免技法打架）→ 套骨架填词 → 回模块1 复测准确性
- **完整模式库**：见 `references/标题模式库.md`（32 个细分模式 + 抽象示例），可直接套用并改造
- **常见错误**：一篇里比喻、谐音、数字混用，显得花哨而散；谐音类误用于讲话稿

### 模块4：烟草系统四种惯用一级标题格式（行业适配）
- **触发条件**：为烟草行业文稿拟一级标题
- **四格式**：
  - A 「动词+工作领域+成效判断」：充分肯定管理提升工作取得的积极成效
  - B 「动词+目标+结果」：全面完成管理体系优化提升目标任务
  - C 「聚焦+领域+方向」（年度报告）：强化党建引领，坚定不移全面从严治党
  - D 「时间+工作内容+定性」（总结）：2024年主要工作
- **常见错误**：用纯名词短语（「工作背景与总体思路」）或咨询式标题（「顶层架构：六大核心业务的分类逻辑」）——均被禁用

### 模块5：同层一致性与主题词锚定
- **触发条件**：一组并列标题、或诊断成稿
- **操作步骤**：
  1. **MECE**：同层标题两两比对，有交叉则合并，有遗漏则补位
  2. **三同对齐**：同句式骨架 / 字数差≤2 / 首词词性一致
  3. **同序**：同层只用一种排序（时间／重要／结构），不混排
  4. **锚定**：每个标题的核心动词或名词，须在其正文首句出现一次
- **常见错误**：第一条「着力推进…」第二条突然变名词短语；标题谈A正文首句谈B

## 质量 Rubric

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 结论性 | 纯话题句，无判断 | 半数标题是话题句 | 多数为结论句 | 全部可证伪的结论句 |
| 准确性 | 标题与正文不符/夸大 | 个别偏题 | 基本贴合 | 标题=本段真实结论，无偏差 |
| 精炼性 | 多数超字数/塞多判断 | 偏长 | 基本达标 | 均≤限字、一题一断 |
| 规范性 | 名词短语/咨询味标题 | 个别不规范 | 基本符合文种格式 | 全部符合行业惯用格式 |
| 工整性 | 同层句式字数全乱 | 部分对齐 | 大体对仗 | 句式/字数/词性三同对齐 |
| 亮点 | 全篇平铺无技法 | 技法生硬或打架 | 1-2 处恰当做亮 | 技法贴主题、不牺牲准确 |
| 呼应性 | 标题与正文首句脱节 | 部分锚定 | 多数锚定 | 每条标题均与正文首句锚定 |

**质量等级判定**（满分 21）：
- PASS（≥16）：可直接交付
- WARN（13-15）：可交付但建议小修
- MAJOR（9-12）：必须修订后交付
- REWRITE（<9）：建议重做

## 输出格式

拟制新标题时：
```markdown
# 标题方案：[板块名]
- 裸结论：[一句大白话判断]
- 万能公式版：[主语+做什么+结果]（X字）
- 做亮版（[技法类]）：[最终标题]
- 自检：结论句✓ | SPA✓ | 同层对齐✓ | 锚定正文首句：[首句关键词]
```

诊断改写时：
```markdown
# 标题诊断表
| # | 原标题 | 问题类型 | 改写建议 | 改后等级 |
|---|---|---|---|---|
| 1 | 存在的问题 | 话题句 | 品牌大而不强的状况尚未根本改变 | PASS |
总评：X/21（等级）。优先改：第__条。
```

## 反模式

1. **话题句标题**
   - 怎么识别：标题单抄后无法判真假（「整体设计」「推进情况」「下步打算」）
   - 怎么改：补一个明确判断/数据，把话题词降为主语（「推进情况」→「攻坚整体进展顺利，指标完成率达85.7%」）
2. **技法压过准确**
   - 怎么识别：为押韵/对仗/谐音硬塞词，标题与正文对不上
   - 怎么改：先保准确的朴素结论句，做亮失败就不做亮——准确是底线，生动是境界
3. **同层混排**
   - 怎么识别：一组小标题一条动宾、一条名词、一条提问，字数从6到20跳
   - 怎么改：选定一种句式骨架，全部套裁，字数对齐到±2
4. **谐音上讲台**
   - 怎么识别：讲话稿里出现「筛/赛/晒」「将就/讲究」这类靠看字辨义的标题
   - 怎么改：讲话稿改用比喻/重复/提问类（靠听也能懂的技法）
5. **标题正文两张皮**
   - 怎么识别：标题核心词在正文首句完全不出现
   - 怎么改：让正文首句复现标题的核心动词或名词，形成主题词锚定

## 来源与边界

蒸馏自：
- 公文标题结构专著：九类做亮技法（比喻/数字/重复/引用/对称/谐音/复合/提问/单字）及 32 个细分模式骨架
- 结构化写作类资料：SPA 原则、标题万能公式、结论先行
- 公文写作心法类资料：三种标题语气、标题四戒
- 行业实际文稿提炼：四种惯用一级标题格式、结论句vs话题句、标题—正文锚定（已脱敏，不含客户名/具体数据）

边界：
- 只管标题层。标题的上游是框架（板块本身要先 MECE），下游是正文（标题改对了不代表正文写到位）
- 谐音类、需默读辨义的技法不适用于讲话稿
- 古诗起句、温情寄语类只适用于仪式性讲话，不用于工作汇报/报告
- 本 skill 只提供方法框架，行业术语与金句素材需配合 `专项_05_炼句金句` 与 `03_dictionary`
