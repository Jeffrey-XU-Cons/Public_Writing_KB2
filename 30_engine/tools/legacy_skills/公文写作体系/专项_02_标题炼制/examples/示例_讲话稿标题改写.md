# 示例：讲话稿标题诊断与改写

> 素材取自 `00_raw_materials/现场会讲话` 一篇「全市烟草企业管理工作会讲话」的真实标题结构（已脱敏，隐去单位与姓名）。
> 演示流程B（诊断改写旧标题），并展示「已经做对的地方」。

## 一、原标题清单（讲话稿）

```
一、必须深刻认识企业管理推动高质量发展的极端重要性
二、必须牢牢把握企业管理上水平的几个关键点
   （一）牢牢把握强化管理的关键
   （二）牢牢把握成本管控的关键
   （三）牢牢把握防范风险的关键
三、必须抓实抓细本年度企业管理工作
   （一）着力推进精益烟叶生产
   （二）着力推进精益卷烟营销
   （三）着力推进精益物流配送
   （四）着力推进精益专卖内管
   （五）着力推进精益科技创新
   （六）着力推进精益财务管理
```

## 二、诊断表

| #              | 原标题                         | 结论句? | 问题类型      | 评注                                                                                                |
| -------------- | ------------------------------ | ------- | ------------- | --------------------------------------------------------------------------------------------------- |
| 一             | 必须深刻认识…的极端重要性     | △      | 偏话题        | 「重要性」是话题，但讲话稿一级标题用「必须」式动员语气可接受，**保留**                        |
| 二             | 必须牢牢把握…的几个关键点     | ✗      | 话题句        | 「几个关键点」未给判断，读者不知关键是什么                                                          |
| 二(一)(二)(三) | 牢牢把握X的关键                | ✗      | 话题句+技法弱 | 三条只是把「强化管理/成本管控/防范风险」套进同一壳，无判断、无亮点                                  |
| 三             | 必须抓实抓细本年度企业管理工作 | △      | 偏话题        | 同①，动员式可保留                                                                                  |
| 三(一)~(六)    | 着力推进精益X                  | ✓      | ——          | **已做对**：六条「着力推进精益__」句式全同、字数对齐、MECE 覆盖六大业务，是合格的对称类标题组 |

**已经做对的两点（保留并表扬）：**

1. 三个一级标题用「必须__」重复类骨架，动员节奏强，适配讲话稿。
2. 第三部分（一)~(六)「着力推进精益__」是教科书级的同层对齐——句式同、字数同、词性同、六业务 MECE。

**主要短板：** 第二部分（一)(二)(三)是空壳话题句，与第三部分的工整形成落差。

## 三、改写（聚焦第二部分）

裸结论（先写大白话判断）：

- 强化管理 → 管理要从「分散管」转向「体系管」
- 成本管控 → 成本要算到每个环节、抠出真效益
- 防范风险 → 风险要抓早抓小、守住底线

套**对称类 + 单字点睛**，与第三部分「着力推进精益__」形成呼应又有区分：

```
二、必须牢牢把握企业管理上水平的三个着力点
   （一）在「统」字上下功夫，推动管理从分散走向体系
   （二）在「精」字上做文章，推动成本从粗放走向精算
   （三）在「early」抓早抓小，推动风控从被动走向主动
```

> 注：「early」为占位，实际改为单字「先」——「在『先』字上抢主动」。修正后：

```
二、必须牢牢把握企业管理上水平的三个着力点
   （一）在「统」字上下功夫，推动管理从分散走向体系
   （二）在「精」字上做文章，推动成本从粗放走向精算
   （三）在「先」字上抢主动，推动风控从被动走向主动
```

**改写要点：**

- 「几个关键点」→「三个着力点」：数字落地，不再含糊
- 每条从「话题句」升为「结论句」：含「从X走向Y」的明确判断，可证伪
- 单字「统/精/先」系列 + 「从…走向…」对仗：同层三同对齐，且与第三部分技法（精益）区分，不打架
- 文种=讲话稿：未用谐音，单字+对称靠听也能懂 ✓
