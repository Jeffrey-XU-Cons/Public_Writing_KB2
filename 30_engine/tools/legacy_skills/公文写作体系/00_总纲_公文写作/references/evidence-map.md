## 跨源印证

- **强印证**：「先框架后内容、结论先行」在五本书整合框架（第二层 2.1）、全流程矿脉（结构化写作四场景「先框架后细节」）、项目工作模式（模式一 Step 3 输出框架先于全文）三处一致 → 定为总纲第二层不可跳过的关闸，并写入反模式1「无框架先写正文」。
- **强印证**：「统稿八看」在整合框架第五层与项目质量规范两处完全一致的八维度出现 → 直接采为总纲总验收 Rubric 的八个维度。
- **强印证**：「同一意思/数据只出现一处」在整合框架（意思流窜检查）与项目质量规范（论点地图）一致 → 反模式2 与第五层核心动作。
- **单一来源**：五层框架与五本书工序（磨刀子/定盘子等）的对应映射仅见于整合框架的全流程速查表；其他文种适配时须以对应文种 skill 的专属骨架为准，不强套五本书工序名。
- **条件分支**：模式一顺走五层、模式二反走第五层定位——来自项目工作模式约定，是本总纲区别于纯方法论 skill 的调度特性，写成第〇步与调度纪律，不与五层流程混为一谈。
- **边界澄清**：本总纲只蒸馏「思维准备层」的本体方法论（立意/WA/四情/详略/创新）与「调度判断」；结构、内容、语言三层的**具体技法**不在本 skill 实现，全部指向下属 11 个 skill，避免与专项 skill 重复造轮子。
