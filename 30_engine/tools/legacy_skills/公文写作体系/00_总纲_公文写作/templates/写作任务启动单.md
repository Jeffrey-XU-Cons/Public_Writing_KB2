# 写作任务启动单（接到任务先填，填完才动笔）

> 用法：接到一个公文写作任务，先把第一层「思维准备」的判断逐栏填死，再进第二层搭框架。
> 任一栏写不出来，说明该想清的没想清——不要带着空栏往下走。无数据的栏标「[待补充：需XX]」，不用模糊话占位。

## 一、文种与模式（第〇步）
- 文种：______（汇报／工作总结／实施方案／发展规划／调研报告／现场会讲话）
- 对应文种 skill：`../../文种_0X_XXXX/SKILL.md`（按上一行判定结果填，如 `../../文种_01_汇报材料/SKILL.md`）
- 工作模式：□ 模式一（写/起草，顺走五层）　□ 模式二（改/统稿，反走第五层定位）
- 任务文件夹：`tasks/______（日期_文种_主题）/`

## 二、WA 目标（模块2，一句话写死）
- **W 说服对象**：______（写给谁看／谁来讲，落到具体层级）
- **A 期望行动**：______（读完/听完，希望对方批准/认同/部署什么——是「行动」不是「了解情况」）

## 三、立意三字经（模块1）
- **时**（时代背景/政策窗口）：______
- **事**（具体哪项工作，不要泛化）：______
- **势**（发展趋势/往哪走）：______
- **三字交集 → 主旨句**（一句可判真假的判断，非话题）：______

## 四、四情清单（模块3，逐项调度，缺项标待补充）
| 情 | 调度内容 | 已有 / 待补充 |
|---|---|---|
| 上情（上级政策原文） |  |  |
| 内情（本单位工作实际） |  |  |
| 下情（基层执行情况） |  |  |
| 外情（同类单位经验） |  |  |

## 五、四要素核查（模块3）
| 要素 | 核查问题 | 填写 |
|---|---|---|
| 事 | 历史沿革/现状/问题/趋势研透了？ |  |
| 人 | 领导意图、受众关切抓准了？ |  |
| 体 | 文种体例骨架确认了？（对应文种 skill） |  |
| 景 | 宏观背景、会议场景清楚了？ |  |

## 六、详略预算（模块4）
- 重点板块（须详写）：______（占比约 __%）
- 次要板块（可略写）：______（占比约 __%）
- 文种比例红线已对照？□ 是（如汇报「果」≥50%、方案「法」≥60%）

## 七、拟用骨架与构建方向（进第二层前）
- 骨架来源：______（A2_审核草稿_11种文体骨架 / A2_补充骨架_修订版）
- 构建方向：□ 自上而下（思路成熟）　□ 自下而上（素材多结论不清）
- 是否需创新（模块5）：□ 否　□ 是，路径：______（结构/角度/文字/**观点论断**）

## 八、第一层过关闸自检
- [ ] WA 的 W 和 A 都写出来了，A 是具体行动？
- [ ] 主旨句是判断句、可判真假，不是话题？
- [ ] 四情至少上情+内情已实，外情/下情缺项已标待补充？
- [ ] 四要素「人」（领导意图）已抓准，不是一稿两用？
- [ ] 详略预算与文种比例红线对得上？

> 八项全勾 → 进第二层（调 `../../专项_01_篇章结构/SKILL.md` 搭粗纲）。有未勾 → 回对应栏补，不进结构层。
