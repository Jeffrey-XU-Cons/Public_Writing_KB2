# 示例：现场会交流汇报骨架解析

> 素材取自 `00_raw_materials/个人历史交付物/汇报类` 一篇全国企业管理现场会的真实交流材料（已脱敏：单位名改「某中烟」，数据改「X%／X 亿元／X 项」）。
> 这是「现场会交流式」汇报——向上级与兄弟单位通报本单位做法、争取认可。演示其骨架、开场、成果段如何写，并标注可学之处。

## 一、原稿骨架还原（脱敏）

```
标题：打造五大能力 提升精益效能 助推企业高质量发展
        （——某中烟）

开篇帽段：
  去年行业企管会以来，某中烟认真贯彻落实国家局关于高质量发展的要求，
  将精益管理摆进高质量发展大背景下谋篇布局，通过增强战略决策、目标管理、
  流程运营、洞察分析、改进创新「五大核心能力」，……现将主要做法作交流汇报。

一、整体布局，增强战略决策能力和目标管理能力
   （一）系统谋划，制定高质量发展规划
   （二）平台助力，完善战略落地机制
二、协同推进，增强流程运营能力
   （一）借助体系转版，夯实管理基础
   （二）开展管理诊断，推动持续改进
   （三）聚焦成本管控，推进降本增效
三、数字赋能，增强洞察分析能力
   （一）深挖数据，提升精益营销水平
   （二）智能寻优，提升精准对标水平
四、激发活力，增强改进创新能力

结尾：……距离行业要求仍有差距，我们将进一步做好以下工作：一是……二是……三是……
```

## 二、骨架逐层解析

| 层级 | 写了什么 | 对应骨架段 | 可学之处 |
|---|---|---|---|
| 帽段 | 定调（贯彻高质量发展）+ 总括做法（五大能力）+ 收口（作交流汇报） | 背景与定位（现场会式开场） | 结论先行：开篇就给「五大能力」总框架，领导一句话掌握全貌 |
| 一～四 | 四个并列板块，每个=一种「能力」 | 核心内容（做法与进展） | 板块用同一句式「动词领起，增强 X 能力」套裁，MECE 覆盖五大能力 |
| 各（一）（二） | 板块内二级，每条=一项具体做法+成效 | 主要做法与进展 | 二级标题也对仗（「系统谋划，制定…」「平台助力，完善…」），做法+落点 |
| 结尾 | 不回避差距 + 三条下步 | 存在问题 + 下步工作 | 现场会稿也保留「问题+下步」，不只报喜 |

**可学点1（领导意图落地）**：帽段把上级反复强调的「高质量发展」「精益管理」直接写进定调句，板块标题统一用上级语境里的「核心能力」框架——领导一读就感到「领会了意图」。对应 SKILL 模块6。

**可学点2（板块按重要性 + 句式套裁）**：四个板块从「战略决策」到「改进创新」，是按管理逻辑的重要性排序；标题全用「动词+增强 X 能力」同一骨架。对应 `../references/汇报骨架与提纲库.md` 套路1。

## 三、成果段写法解析（数据带对比基准）

原稿一处成果段（脱敏后）：

> 「针对烟用材料规格多、通用性差等特点，以『价格就低不就高』为整合原则，对同色系盒皮、内衬纸等材料梳理精简。**X 年至今，在产烟用框架纸和内衬纸规格数分别下降了 X% 和 X%**，有效降低采购成本。通过多措并举，**X 年 1-9 月公司实现降本增效 X 亿元**。」

解析：
- **总—分结构**：先给做法判断（整合原则），再分条铺事实，最后落到成效数据。
- **数据带基准**：「规格数下降 X% 和 X%」用的是「对比过去（历史基准）」；「降本增效 X 亿元」配了时间口径「X 年 1-9 月」。符合 SKILL 模块4「数据必有对比基准」。
- **若要升级为分析级**：可在数据后补一句规律性判断——「这说明，降本增效的空间往往不在压价格，而在做减法、砍冗余规格」。全文只 2-3 处这样升级，避免说教。

对照反模式：若写成「精简了一批烟用材料规格，有效降低了成本」——只有动作无数字、无基准，领导无法判断成效大小，即触发 SKILL 反模式4「数据无对比基准」。

## 四、开场对比（陈述式 vs 现场会式）

同一份材料，两种开场都合格，看场合选：

```
陈述式（向上级主管部门）：
  各位领导：按照国家局关于高质量发展的部署，现将某中烟今年以来推进
  精益管理的情况汇报如下。

现场会交流式（原稿用法，面向同行）：
  去年行业企管会以来，某中烟认真贯彻落实……将精益管理摆进高质量发展
  大背景下谋篇布局，通过增强「五大核心能力」……现将主要做法作交流汇报。
```

两者都做到「开场三禁」：不解释「为什么要搞精益管理」、无「坐标系」比喻、控制在 200 字内。区别仅在现场会式多一句总括做法、语气面向同行交流。

## 五、一句话复盘

这份稿之所以是合格汇报而非工作总结：① 帽段结论先行给总框架（让领导掌握情况）；② 标题与帽段复现上级语境（让领导认可判断）；③ 成果数据带基准（让领导省力判断成效）；④ 结尾不回避差距、给明确下步（让领导放心）。四点正是 SKILL 模块1「汇报=让领导掌握情况并认可判断」的落地。
