# 方案骨架库——子类骨架对照 × 任务分解表 × 保障清单 × 5W2H 检验表

> 套用方式：①按子类选骨架（第一节）→ ②用任务分解表把重点任务拆到部门和节点（第二节）→ ③用保障清单补全三类保障（第三节）→ ④用 5W2H 检验表逐项过筛（第四节）。
> 全部为骨架与表式，填词即用。术语顺序与禁用词另查 `03_dictionary/`。

---

## 一、子类骨架对照

三个子类共用「五段式」主干，按性质增减。下表「○必备 △按需 ×通常省」。

| 段 | 实施方案 | 工作方案 | 活动方案 | 该段写法要点 |
|---|---|---|---|---|
| 背景与目的 | ○ | ○ | ○ | 依据哪份文件、解决什么问题，≤150字，不抄政策原文 |
| 指导思想 | ○ | △ | × | 1-2句扣上级精神+工作主线 |
| 基本原则 | ○ | △ | × | 2-4条，须有实质约束（如「问题导向」「分级分类」），非口号 |
| 工作目标（量化）| ○ | ○ | △ | 必含可测量指标；活动方案改为「预期效果」 |
| 重点任务/活动内容 | ○ | ○ | ○ | 分项3-8条，每条带牵头部门；活动方案改为「活动流程」 |
| 实施步骤（分阶段）| ○ | ○ | ○ | 精确月份；活动方案改为「时间安排/议程」 |
| 职责分工 | ○ | △ | △ | 单列各单位职责，「×部门负责……」；任务少时并入任务段 |
| 保障措施 | ○ | ○ | △ | 组织/资金/考核三类；活动方案侧重「现场/安全/宣传」保障 |
| 督查考核 | ○ | △ | × | 督查主体+频次+结果运用 |

**活动方案特有要素**（实施方案通常不写）：活动主题、参与对象、活动形式、活动地点、注意事项/应急。

### 三子类骨架速写

```
【实施方案（最全）】
一、背景与目的
二、总体要求（指导思想 / 基本原则 / 工作目标·含量化）
三、重点任务（一）…（八）  每项：内容+路径+完成标准+牵头部门
四、职责分工（×部门负责……）
五、实施步骤（启动准备[X月]→全面推进[X月]→总结验收[X月]）
六、保障措施（组织保障 / 经费保障 / 制度保障 / 考核保障）

【工作方案（务实精简）】
一、目的依据
二、工作目标（量化）
三、主要任务（分项，带牵头部门）
四、时间安排（分阶段，精确月份）
五、工作要求（含简要保障与考核）

【活动方案（流程导向）】
一、活动背景与目的
二、活动主题 / 时间 / 地点 / 对象 / 形式
三、活动内容与流程（按时序或环节）
四、组织分工（×部门负责××环节）
五、保障措施（现场/安全/宣传/经费）+ 注意事项
```

## 二、任务分解表（重点任务落地用）

把每项重点任务填进下表，确保「内容—路径—责任—节点—标准」五列齐全。

| 序 | 任务名称 | 实施路径（怎么做） | 牵头部门 | 协办部门 | 时间节点 | 完成标准（量化/产出物） |
|---|---|---|---|---|---|---|
| 1 |  |  |  |  | X月—X月 |  |
| 2 |  |  |  |  |  |  |
| 3 |  |  |  |  |  |  |

**填表三戒**：
- 戒「牵头部门」写集体名词（各单位/相关部门）——必须唯一具体
- 戒「完成标准」写定性词（基本完成/明显提升）——必须可测量
- 戒「时间节点」写模糊词（年内/适时）——必须到月份

**MECE 自检**：把全部任务名称单列，两两问「有没有重叠」「合起来够不够覆盖工作目标」。重叠则合并，遗漏则补位。

## 三、保障措施清单（逐类补全，去套话）

每类至少写一条**带主体+动作+机制**的实措，对照右栏把套话换成实措。

| 保障类别 | 必答要点 | 套话（禁用） | 实措（替换为） |
|---|---|---|---|
| 组织保障 | 谁牵头、设不设领导小组/工作专班 | 加强组织领导 | 成立由××牵头的工作专班，下设办公室在××部门 |
| 经费/资源保障 | 钱从哪出、资源怎么配 | 强化要素保障 | 所需经费纳入年度预算，由××部门统筹列支 |
| 制度保障 | 配套哪些办法/标准/流程 | 健全工作机制 | 制定××实施细则与××检查表，明确操作规程 |
| 考核保障 | 督查主体+频次+结果运用 | 加强督查考核 | ××部门按月调度，结果纳入绩效考核与年度评先 |
| 培训/宣传保障（按需）| 谁培训、谁宣传、覆盖谁 | 营造良好氛围 | 依托××平台分层培训，覆盖全体评价骨干 |

**一句话判废**：保障措施若删掉后整份方案的可执行性不受影响，说明它是套话，须补机制。

## 四、5W2H 落地检验表（整篇过筛）

整篇方案填一次；任一格答「否/不清」即标红回改。

| 要素 | 自问 | 落在方案哪段 | 是否答清 |
|---|---|---|---|
| Why 为何做 | 依据什么、解决什么问题 | 背景与目的/指导思想 | □ |
| What 做什么 | 分成哪几项任务 | 重点任务 | □ |
| Who 谁来做 | 每项谁牵头 | 任务牵头部门/职责分工 | □ |
| When 何时做 | 各阶段起止月份 | 实施步骤 | □ |
| Where 在哪/对谁 | 范围、对象、覆盖单位 | 实施范围/评价对象 | □ |
| How 怎么做 | 每项任务的路径方法 | 任务实施路径 | □ |
| How much 到什么程度/投入 | 量化目标、完成标准、预算 | 工作目标/完成标准/经费保障 | □ |

**任务级三问表**（每项重点任务过一遍）：

| 任务 | 谁做（部门唯一?）| 何时（到月份?）| 做到什么程度（可测量?）| 三问全通? |
|---|---|---|---|---|
| 任务1 | ✓/✗ | ✓/✗ | ✓/✗ | ✓/✗ |
| 任务2 |  |  |  |  |

三问全✓，该任务方可执行；任一✗，回模块4/模块5 补齐。
