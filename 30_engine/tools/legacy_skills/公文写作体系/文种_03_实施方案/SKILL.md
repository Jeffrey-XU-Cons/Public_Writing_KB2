# 实施方案——面向未来的行动设计，落点是可操作可考核

> 本 skill 只解决「方案这个文种怎么搭怎么写」一件事：让一份方案从「提要求」升级为「能执行」——任务分到部门、目标量化、步骤上时间轴、保障不落空。
> 通用技法外包给专项 skill：搭骨架走 `../专项_01_篇章结构`，炼标题走 `../专项_02_标题炼制`，写段落走 `../专项_03_段落意群`。本 skill 不复刻这些。
> 方法论母本：`../../../02_rules/写作体系_金字塔核心框架.md`（5W2H、问题/原因/对策、自上而下搭框架）。

## 使用场景

当用户需要：
- 把上级文件、领导部署或年度计划转化成一份可执行的实施方案／工作方案／活动方案（起草）
- 为一项需多部门协作、有节点和考核要求的系统性工作设计落地路径
- 体检一份旧方案：目标是否量化、任务有没有责任人、步骤有没有时间节点、保障是不是套话

不要用于：
- 搭整篇骨架、判断板块是否 MECE（用 `../专项_01_篇章结构`）
- 把任务方向炼成正式对仗标题（用 `../专项_02_标题炼制`）
- 段落内观点+论据+数据的组织（用 `../专项_03_段落意群`）
- 写「已经做了什么」的回顾性材料——那是工作总结，不是方案（见下方反模式）

## 输入要求

需要用户提供（缺则最多追问 3 项）：
1. **方案子类**——实施方案／活动方案／工作方案？（决定骨架详略：实施方案最全，活动方案弱化保障、强化流程与时间）
2. **依据与目标**——依据哪份上级文件/部署？想达成的可量化结果是什么？（无量化目标无法做可考核的方案）
3. **任务范围与责任单位**——要分解成哪几块任务、由哪些部门承接？（无责任主体方案不可落地）

> 三问之外靠读素材和范文自行判断。子类＋依据目标＋责任单位三项明确后，骨架、任务分解、时间轴均可推进。

## 工作流

### 流程A：起草新方案
**输入**：方案子类 + 依据文件 + 量化目标 + 任务范围/责任单位
**步骤**：
1. **定调用 5W2H 兜底**（模块3）：先把 Why（依据/目的）、What（任务）、Who（责任主体）、When（节点）、Where（范围/对象）、How（路径方法）、How much（量化目标/资源）逐项列清，任一项空白即回去补素材，不带空白下笔。
2. **套标准骨架**（模块2）：背景与目的 → 总体要求（指导思想/基本原则/工作目标·含量化）→ 重点任务（分项，每项带责任主体）→ 实施步骤（阶段+时间节点）→ 保障措施（组织/资金/考核）。子类做增减（活动方案可省指导思想、强化流程）。
3. **任务分解走 MECE + 责任到部门**（模块4）：用「问题/原因/对策」或业务条线拆出 3-8 项任务，两两不重叠、合起来不遗漏；每项落一个明确牵头部门，禁用「相关单位/有关部门」。
4. **目标量化、步骤上时间轴**（模块5）：每个目标配可测量完成标准（数字/达成率/产出物），每个阶段标起止月份。
5. **过 5W2H 落地检验**（模块3）：逐项任务自问「谁做/何时/做到什么程度」三问能否答出，答不出即退回第 3 步。
6. 标题层交 `../专项_02_标题炼制`，段落层交 `../专项_03_段落意群`。
**输出**：一份目标可量化、任务有责任主体、步骤有时间节点、保障落地的方案
**失败处理**：
- 若量化目标写不出 → 上游目标本身没定清，退回向委托方确认，不用「大幅提升」占位
- 若任务拆不开/互相重叠 → 退 `../专项_01_篇章结构` 重做 MECE 分解

### 流程B：诊断改稿
**输入**：一份现成方案全文
**步骤**：
1. 把全文按「背景/总体要求/重点任务/实施步骤/保障措施」五块归位，缺哪块标红（最常缺「实施步骤」和「量化目标」）。
2. 用**落地检验表**（references/方案骨架库.md）逐项任务过三问：谁做？何时？做到什么程度？任一答不出标红。
3. 扫量化：工作目标里有没有「基本实现/大幅提升/明显增强」这类不可测量表述，标红改成数字或产出物。
4. 扫责任：有没有「各单位/相关部门/有关方面」这类模糊责任主体，标红落实到具体部门。
5. 扫时间：实施步骤里有没有「上半年/年内/适时」，标红改成精确月份。
6. 扫保障：保障措施是不是「加强领导、提高认识」纯套话，标红补具体机制（谁牵头督查、什么频次、结果怎么用）。
7. 输出「问题清单 + 改写对照表」，只改点名处，不重写未点名段落。
**输出**：方案诊断表（位置｜问题类型｜原文｜改写建议）
**失败处理**：
- 若改成量化目标后无数据支撑 → 是素材缺口，标「[待补充：需XX数据]」提示而非编造
- 若任务与责任部门确实无法对应 → 提示职责边界问题，回委托方确认，不强行指派

## 方法论模块

### 模块1：文种定位——方案是「面向未来的行动设计」（地基）
- **触发条件**：任何方案，起草或诊断都先过这一关
- **核心判定**：方案写的是「将要怎么做」，不是「已经做了什么」。一句话测试——把每条内容单抄，问「这是承诺一个未来动作，还是陈述一个过往成绩？」是过往的，就是混进了总结/汇报，删或改成未来式。
- **三可标准**（方案区别于其他文种的本质）：
  - **可操作**：每项任务有明确执行路径（怎么做），不止有方向
  - **可落地**：每项任务有明确责任主体（谁做）和时间节点（何时）
  - **可考核**：每项目标有量化或产出物标准（做到什么程度算完成）
- **常见错误**：通篇讲意义和要求，没有具体动作和节点（写成了动员讲话）；或通篇回顾成绩（写成了工作总结）

### 模块2：标准骨架——五段式
- **触发条件**：起草新方案、诊断旧方案归位
- **五段顺序**（不可跳段，子类可增减）：
  1. **背景与目的**：1 段说清依据哪份上级文件/部署、为什么做、解决什么问题，不超 150 字，不照抄政策原文
  2. **总体要求**：指导思想（1-2 句，扣上级精神与工作主线）+ 基本原则（2-4 条，须有实质约束，非口号）+ 工作目标（**必含量化指标**，明确到年度/阶段）
  3. **重点任务**：分项 3-8 条，每条「（一）标题：任务内容+实施路径+完成标准+牵头部门」，条目间有内在逻辑顺序
  4. **实施步骤**：分阶段（一般启动准备→全面推进→总结验收，不少于两阶段），每阶段标起止月份+主要工作
  5. **保障措施**：组织保障（领导机构/牵头部门）+ 资金/资源保障 + 考核保障（督查主体/频次/结果运用），每条有具体机制
- **子类差异**：
  - 实施方案——五段最全，保障与考核最重
  - 工作方案——可合并总体要求，突出重点任务与步骤
  - 活动方案——弱化指导思想，强化「活动流程+时间安排+分工」，常加「活动主题/对象/形式」
- **常见错误**：只有「总体要求」和「保障措施」两头，中间缺「重点任务」和「实施步骤」这个执行核心——方案变空壳

### 模块3：5W2H 落地检验——方案能不能执行的体检表
- **触发条件**：起草定调时兜底、诊断时逐项任务过筛
- **七问对位**：

  | 要素 | 落到方案哪里 | 答不出的后果 |
  |---|---|---|
  | Why 为何做 | 背景与目的 / 指导思想 | 方案失去依据，沦为自说自话 |
  | What 做什么 | 重点任务标题与内容 | 任务空泛，无抓手 |
  | Who 谁来做 | 每项任务的牵头部门、职责分工 | 无人负责，无法落地 |
  | When 何时做 | 实施步骤的阶段时间节点 | 无节奏，拖延无约束 |
  | Where 在哪/对谁 | 实施范围、评价对象、覆盖单位 | 边界不清，执行跑偏 |
  | How 怎么做 | 任务的实施路径、方法步骤 | 只有目标没有路径，做不出来 |
  | How much 做到什么程度/投入多少 | 量化目标、完成标准、资源预算 | 无法判断是否完成，不可考核 |

- **任务级三问**（每项重点任务必过）：**谁做**（牵头部门）→ **何时**（完成时限）→ **做到什么程度**（完成标准）。三问全答出，该任务才算可执行。
- **常见错误**：有 What 有 Why，缺 Who/When/How much——典型「只有要求没有落地」

### 模块4：任务分解 MECE + 责任到部门
- **触发条件**：拆解重点任务、设计职责分工
- **操作步骤**：
  1. 选拆分维度（三选一，全程一致）：**业务条线**（烟叶/营销/专卖/物流/综合）、**问题导向**（针对几个核心问题各设一项）、**流程阶段**（前期/中期/后期）
  2. 拆出 3-8 项，两两比对无重叠、合起来无遗漏（MECE）
  3. 每项落**一个明确牵头部门**（可有协办，但牵头唯一）；禁用「相关单位/各部门/有关方面」
  4. 反向核对：工作目标里每个量化指标，是否都有对应任务支撑其实现路径
- **常见错误**：任务按维度混拆（一条按业务、一条按流程），导致重叠；牵头主体写成集体名词，落地时互相推诿

### 模块5：目标可量化 + 步骤有时间节点
- **触发条件**：写工作目标、写实施步骤
- **目标量化三法**：①数字化（完成率≥X%、降本X万元、覆盖X家）②产出物化（形成1套办法、建成1个体系、出具X份报告）③时限化（X月底前完成）。三者至少占一项，杜绝「基本实现/明显提升/大幅增强」。
- **步骤上时间轴**：每阶段标**精确月份**起止（如「3月—4月」「6月—9月」），不用「上半年/年内/适时」；阶段之间时间连贯，不断档不交叉。
- **常见错误**：目标定性不定量，验收时无标准；步骤只列动作不列时间，沦为任务清单的复述

## 质量 Rubric

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 文种规范 | 写成总结/汇报/讲话 | 半数内容是回顾或要求 | 基本是未来行动设计 | 全篇可操作可落地可考核 |
| 骨架完整 | 缺任务或缺步骤 | 五段缺一 | 五段齐但某段薄 | 五段齐全、详略得当 |
| 目标可量化 | 全为定性表述 | 个别量化 | 多数目标可测量 | 每个目标有数字/产出物标准 |
| 任务有责任主体 | 全用集体名词 | 半数模糊 | 多数到部门 | 每项任务牵头部门唯一明确 |
| 步骤有时间节点 | 无时间 | 用「上半年」类模糊词 | 多数到月份 | 每阶段精确月份且连贯 |
| 保障到位 | 全套话 | 部分套话 | 多数有机制 | 组织/资金/考核均有可操作机制 |

**质量等级判定**（满分 18）：
- PASS（≥15）：可直接交付
- WARN（12-14）：可交付但建议小修
- MAJOR（8-11）：必须修订后交付
- REWRITE（<8）：建议重做

## 输出格式

起草新方案时（先出骨架待确认，再展开）：
```markdown
# 方案骨架：[主题]
- 子类：实施方案/工作方案/活动方案 | 依据：[上级文件]
- 5W2H 兜底：Why□ What□ Who□ When□ Where□ How□ HowMuch□
- 一、背景与目的：[一句话目的]
- 二、总体要求：指导思想 / 原则[N条] / 量化目标[列指标]
- 三、重点任务：（一）…（二）…（每项注牵头部门）
- 四、实施步骤：阶段一[起止月]→阶段二[起止月]→…
- 五、保障措施：组织 / 资金 / 考核
```

诊断改稿时：
```markdown
# 方案诊断表
| # | 位置 | 问题类型 | 原文 | 改写建议 | 改后 |
|---|---|---|---|---|---|
| 1 | 工作目标 | 目标空泛 | 大幅提升管理水平 | 对标指标提升率≥X%、降本X万元 | PASS |
总评：X/18（等级）。优先改：第__条。
```

## 反模式

1. **目标空泛无量化**
   - 怎么识别：工作目标全是「基本实现/明显提升/大幅增强/取得突破」，验收时无客观标准
   - 怎么改：换成数字（≥X%、X万元）、产出物（1套办法、1个体系）或时限（X月底前）
2. **任务无责任人**
   - 怎么识别：任务用「各单位/相关部门/有关方面」承接，落地时无人牵头
   - 怎么改：每项任务落一个唯一牵头部门，协办单位另列
3. **只有要求没有步骤**
   - 怎么识别：通篇「要……、必须……、切实……」，找不到分阶段时间节点
   - 怎么改：补「实施步骤」段，分启动/推进/验收三阶段，每阶段标精确月份
4. **保障措施套话**
   - 怎么识别：保障只写「加强领导、提高认识、强化落实」，无具体机制
   - 怎么改：写清谁牵头督查、什么频次、考核结果怎么用（纳入绩效/追责）
5. **方案写成总结或汇报**
   - 怎么识别：通篇「已完成/取得成效/同比增长」，讲过去而非将来
   - 怎么改：全部改成未来式行动（将开展/拟实现/计划完成），过往成绩只在背景里点一句

## 来源与边界

蒸馏自（已脱敏，不含客户名/具体数据）：
- 公文骨架规范：实施方案标准结构、量化目标与精确时间节点约束、责任主体唯一性要求
- 写作体系金字塔框架：5W2H、问题/原因/对策三框、自上而下搭框架、横向 MECE 与重要性排序
- 行业实际方案提炼：综合性企业管理工作实施方案、数据营销多备选模型方案、管理成熟度评价推进方案的真实骨架与任务分解写法

边界：
- 只管「方案」文种的搭与写。骨架/标题/段落等通用技法分别指向 `../专项_01_篇章结构`、`../专项_02_标题炼制`、`../专项_03_段落意群`
- 行业术语与表述顺序查 `03_dictionary/`，本 skill 不内置术语表
- 方案做对了不代表执行做对——本 skill 只保证「写得能执行」，不负责执行本身
