# 示例：综合发展规划骨架与目标体系解析

> 素材取自 `00_raw_materials/个人历史交付物/规划类` 一份某地市烟草商业「十四五」综合发展规划（已脱敏：隐去单位名、具体数据、人名，金额/比例统一改为「X」或区间占位）。
> 演示流程A（起草新规划）如何落到一份真实规划的骨架，重点拆解三处：①六段骨架全貌 ②目标指标体系写法 ③机遇挑战辩证写法。

## 一、整篇骨架还原（一级标题层）

```
（标题）某市烟草「十四五」规划
（导言）规划期定性 + 编制依据（逐一列出 5 份对接的上级规划）

第一篇  五年砥砺前行……（发展基础与成就）
   ├ 总体定性 + 核心指标（主营收入 X 亿、税利 X 亿、上等烟比例 32%→63%…）
   ├ 做成「三件大事」（——坚持刀刃向内… ——坚持潜心做事… ——坚持争先创优…）
   ├ 分领域成就（——党的建设… ——发展方式… ——专卖内管… ——企业管理… ——创新驱动… ——社会形象…）
   └ 专栏1 「十三五」规划主要指标完成情况

第二篇  锚定奋斗目标……（形势 + 总体要求 + 目标）
   ├ 第一章 机遇挑战   ← 挑战（供需/改革/治理/队伍四方面，层层收到本单位）+ 机遇（四个「没有改变」+ 四大优势）+ 综合判断收口
   ├ 第二章 总体要求   ← 指导思想 / 遵循原则（五条「坚持」）/ 基本思路（「1365」发展思路）
   └ 第三章 主要目标   ← 定性总目标（含量化）+「——在X上开新局」六条具体目标 + 专栏2 主要预期目标

第三篇  加快建成「六大体系」……（重点任务，分领域）
   ├ 第四章 党的建设体系     ├ 第五章 现代烟叶产业体系
   ├ 第六章 卷烟营销体系     ├ 第七章 专卖管理体系
   ├ 第八章 创新体系         └ 第九章 企业治理体系
       （每章下设「第一节/第二节」，每节收口到一个量化小目标，如「到2025年烟叶总量达11万担」）

（末篇）保障措施
```

**解析**：这就是 SKILL 模块2「六段骨架」的真实形态——发展基础（第一篇）→ 形势＋总体要求＋目标（第二篇）→ 分领域重点任务（第三篇六大体系）→ 保障。注意「六大体系」与第三章「六条具体目标（——在X上开新局）」一一对应，这是 SKILL 强调的「任务↔目标锚定」。

## 二、目标指标体系写法（规划之眼）

### 定性总目标（一句话锚定远景 + 量化收口）

> 原文模式：「坚持目标导向、问题导向、结果导向相统一……『十四五』时期改革发展的主要目标是：保持税利年均增长 X%，卷烟销量年均增长 X%、单箱均价年均增长 X%。到『十四五』末，年度税利总额达 X 亿元，卷烟销量达 X 万箱、单箱均价达 X 万元，烟叶生产保障能力达 X 万担、烟叶税达 X 万元。」

**解析**：一句话里同时给了「年均增速」（过程）和「期末目标值」（结果），这正是 SKILL 模块4 指标四要素的雏形——把它结构化就是一张指标表：

| 指标名称 | 上期基数 | 「十四五」末目标 | 年均增速 |
|---|---|---|---|
| 税利总额 | [上期值] | X 亿元 | X% |
| 卷烟销量 | [上期值] | X 万箱 | X% |
| 单箱均价 | [上期值] | X 万元 | X% |
| 烟叶保障能力 | [上期值] | X 万担 | — |

### 具体目标排比（六条「——在X上开新局」）

> ——在全面从严治党上开新局。…… ——在现代企业治理上开新局。…… ——在烟叶发展上开新局。…… ——在卷烟营销上开新局。…… ——在专卖管理监督上开新局。…… ——在深化改革创新上开新局。

**解析**：六条具体目标＝六大体系（重点任务）＝六条改革主线，三者同构。这是规划「路径要清」的体现：目标怎么分，任务就怎么分。

### 任务收口到量化小目标（分领域指标下沉）

> 烟叶章节：「到2025年，全市烟叶总量达到 X 万担……建成高水平基地单元 2 个……万担乡 5 个、千亩村 20 个以上。」
> 营销章节：「到2025年，重点品牌销售占比达 X% 以上，一类烟销量占比 X% 以上。」

**解析**：综合规划的总指标表给「大账」，每个分领域章节再把指标**下沉到本领域的小目标**，做到「目标—任务」两级锚定。这是 SKILL 反模式4「任务与目标脱节」的正面解法。

## 三、机遇挑战辩证写法（形势研判）

### 挑战段（先抑，四方面层层收到本单位）

> 「供需关系方面，受经济周期性因素和结构性因素叠加……『两烟』供需结构性矛盾依然突出……**更加需要**深化供给侧结构性改革。改革发展方面，……企业创新能力还不适应高质量发展要求……**更加需要**以创新驱动塑造新发展优势。企业治理方面，……**更加需要**统筹发展和安全。队伍建设方面，……『本领恐慌』问题依然较为突出……**更加需要**加快干部尤其是年轻干部培养。」

**解析**：四个「方面」从供需→改革→治理→队伍，每段都收到本单位的具体短板，且每段尾用「更加需要……」把挑战转成下文任务的引子。这正是 SKILL 模块5「每个挑战配一个应对方向」。不是空喊「形势严峻」。

### 机遇段（后扬，五层落到本单位）

> 「一是行业宏观政策持续向好的基本面没有改变……这些，是推动『十四五』发展的最大动能。二是全市经济社会加快发展的基本盘没有改变……最大支撑。三是烟草产业支柱地位的基本轴没有改变……最大底气。四是全省烟草商业『一盘棋』共同发展的基本点没有改变……最大保障。」（后接「发展优势方面」四条）

**解析**：四个「没有改变」从行业→地方经济→产业地位→全省一盘棋，每条都落到「对本单位是最大X（动能/支撑/底气/保障）」，全部收到本单位能抓的有利条件。

### 综合判断（收口定调）

> 「综合判断，『十四五』时期全市烟草依然处于重要战略机遇期，但机遇和挑战都有新的发展变化。全体干部职工要坚定发展信心，增强机遇意识和风险意识……善于在危机中育先机、于变局中开新局。」

**解析**：先定调「仍处战略机遇期」，再用「坚定信心＋风险意识＋底线思维」收口。这是 SKILL 模块5 综合判断的标准收法。

## 四、对照 Rubric 评分（这份范本为什么好）

| 维度 | 得分 | 理由 |
|---|---|---|
| 战略高度 | 3 | 开篇即从「全面建成小康向基本实现现代化迈进」「两个大局」定位，对接 5 份上级规划 |
| 形势研判 | 3 | 挑战四方面收到本单位短板，机遇四「没有改变」落到本单位，辩证收口 |
| 目标指标体系 | 3 | 定性总目标 + 量化（税利/销量/均价/烟叶）+ 分领域指标下沉 |
| 任务分领域 MECE | 3 | 六大体系与六条具体目标一一对应，业务领域不交叉 |
| 保障可行 | 2 | 有保障篇，部分条目可再落实到「怎么考」 |
| 上级规划对接 | 3 | 导言逐一列对接规划，正文把上位「六大体系」要求转化为本单位章节 |
| **合计** | **17/18 (PASS)** | 战略设计骨相完整，目标体系与任务锚定到位 |

> 反面提醒：若把第三篇六章的每一节都写成「X月X日前由X科室完成」，本范本就会从规划退化为实施方案（SKILL 模块6 红线）——规划的任务停在「到2025年达到 X」这一阶段性目标层，不下到动作级分工。
