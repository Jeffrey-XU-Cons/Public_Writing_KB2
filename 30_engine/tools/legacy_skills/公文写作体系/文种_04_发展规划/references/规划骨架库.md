# 规划骨架库——发展规划/专项规划骨架对照 + 目标指标表式 + 形势分析框架 + 常用表述

> 套用方式：①按规划类型（综合/专项）选骨架 → ②照「目标指标表式」立指标专栏 → ③照「形势分析框架」辩证写形势 → ④从「常用表述库」取规划语气词，再回 SKILL「质量 Rubric」复测。
> 全部为「结构骨架 + 抽象表述」，已脱敏，不含客户名/具体数据。完整政策术语见 `03_dictionary/tobacco_terms/05_十五五规划术语.yaml`。

## 一、综合发展规划骨架（地市局/工业商业公司整体五年规划）

适用：一个单位面向 5—10 年的整体战略设计（如「X烟草『十五五』规划」「X中烟『十五五』规划」）。

```
（标题）X主体「X规划期」发展规划
（导言）规划期定性 + 编制依据（逐一列出对接的上级规划）+ 编制说明

一、X时期发展基础与面临形势
  （一）上一期发展成就          ← 总体定性 + 核心量化指标 + 分领域成就（带数据）
  （二）面临的机遇挑战与有利条件  ← 挑战（外部→行业→本单位短板）+ 机遇（大势→国家→行业→省级→本单位）+ 综合判断收口

二、总体要求
  （一）指导思想   ← 一段，政治表述顺序严格（详见下「指导思想政治表述顺序」）
  （二）基本原则   ← 5—6 条「坚持X」，有内在逻辑（政治保障→发展理念→政绩观→系统观念→争先进位→科学方法）
  （三）发展思路   ← 可提炼战略代号（如「1365」「1279」战略推进体系），解释每个数字

三、发展目标
  （总体目标）     ← 一句战略定位句锚定远景状态
  （具体目标）     ← 6—8 条「——X领域实现新X」排比，每条一句定性
  （专栏：主要预期指标）  ← 定量指标表（见下「目标指标表式」）

四—N、重点任务（分领域，每领域一个一级标题）
  四、加快建成……党的建设体系
  五、加快建成……产业/烟叶体系
  六、加快建成……营销体系
  七、加快建成……专卖管理体系
  八、加快建成……创新/数字化体系
  九、加快建成……企业治理体系
    （每章下设「第一节/第二节」或「（一）（二）」分子任务，每个子任务收口到一个可对应指标的小目标）

末、保障措施
  （一）加强党的领导  （二）健全实施机制  （三）强化资源投入  （四）加强人才支撑  （五）完善评估考核
```

要点：一级标题用「判断短语＋领域＋定性」（如「加快建成监管有力、打击有力、保障有力的专卖管理体系」），分领域须与「三、发展目标」的具体目标条目一一对应。

## 二、专项规划骨架（某一领域的专项规划）

适用：单一领域的中长期专项规划（如物流/人才/数字化/营销/品牌/绿色发展专项规划）。比综合规划更聚焦、指标更专。

```
（标题）X主体X领域「X规划期」专项规划 / X领域中长期发展规划

一、发展现状与形势分析
  （一）X领域发展现状    ← 本领域上期建设成果 + 现存短板（带本领域专项指标）
  （二）面临形势与需求    ← 上级对本领域的新要求 + 技术/业务趋势 + 本单位本领域的差距

二、总体思路与目标
  （一）指导思想（本领域版，对接上级本领域专项规划）
  （二）基本原则（本领域 3—5 条）
  （三）发展目标   ← 本领域定性总目标 + 本领域专项指标表（如物流：人均配送效率/单箱物流费用/订单准确率）

三、重点任务（按本领域子板块分，不按全单位领域分）
  （一）X子领域建设   （二）X能力提升   （三）X体系完善 …
  （每项收口到本领域专项指标）

四、保障措施（侧重本领域：组织保障/投入保障/技术保障/考核保障）
```

要点：专项规划的「分领域」不是全单位业务领域，而是**本专项内部的子板块**；指标也用本专项指标（不重复全单位综合指标）。专项规划仍须在导言对接上级**本领域**专项规划（如行业现代物流发展规划）。

## 三、目标指标表式（专栏标本）

> 规划之眼。定性总目标定调，定量指标表落地。每个指标四要素必齐：名称、上期基数、规划期末目标、年均增速。

### 综合规划主要预期指标表（标本）

| 指标类别 | 指标名称 | 上期基数（X年） | 规划期末目标（X年） | 年均增速 |
|---|---|---|---|---|
| 经济效益 | 税利总额（亿元） | [基数] | [目标] | [X%] |
| 经济效益 | 上缴税金（亿元） | [基数] | [目标] | [X%] |
| 卷烟营销 | 卷烟销量（万箱） | [基数] | [目标] | [X%] |
| 卷烟营销 | 单箱结构/均价（万元） | [基数] | [目标] | [X%] |
| 卷烟营销 | 一二类烟销量占比（%） | [基数] | [目标] | [↑X pct] |
| 烟叶生产 | 烟叶收购量（万担） | [基数] | [目标] | — |
| 烟叶生产 | 上等烟比例（%） | [基数] | [目标] | [↑X pct] |
| 品牌发展 | 重点品牌销量占比（%） | [基数] | [目标] | [↑X pct] |
| 科技创新 | 研发投入强度（%） | [基数] | [目标] | [↑X pct] |
| 管理水平 | 管理成熟度等级 | [基数级] | [优化级以上] | — |
| 绿色发展 | 单箱卷烟综合能耗 | [基数] | [目标] | [年均降X%] |

> 注：占比类指标增速用「↑X 个百分点（pct）」，总量类用「年均增 X%」，约束类（能耗）用「年均降 X%」。无基数处标「[待补充：需XX口径基数]」，禁用模糊词占位。

### 定性总目标 + 具体目标排比标本

```
总体目标：锚定打造……一流现代化X企业的远景目标，到规划期末，实现……，为……打牢关键基础。

具体目标：
——党的建设全面加强。……
——运行质效实现新提高。……
——品牌市场实现新进步。……
——科技创新实现新突破。……
——生产制造实现新升级。……
——治理效能实现新增强。……
——软实力实现新提升。……
```

## 四、形势分析框架（机遇/挑战辩证）

> 形势分析＝辩证，不是单写困难也不是单喊信心。先抑（挑战，层层收到本单位短板）后扬（机遇，层层落到本单位有利条件），最后收口定调。

### 挑战段框架（先抑，由外到内）

| 层 | 写什么 | 收口方式 |
|---|---|---|
| 外部经济社会环境 | 宏观经济下行/中美博弈/人口老龄化 | 「对……造成较大不确定性」 |
| 行业形势 | 总量接近峰值/结构提升压力/新型烟草冲击/供需错配 | 「稳增长难度不断加大」 |
| 本单位短板 | 党建/队伍/质效/品牌大而不强/指标排名靠后 | 「亟待进一步增强」 |

每个挑战段尾可缀一句「更加需要……（应对方向）」，把挑战转成下文任务的引子。

### 机遇段框架（后扬，由大到小）

| 层 | 写什么 | 落点 |
|---|---|---|
| 发展大势 | 中华民族伟大复兴势不可挡 | 「支撑条件坚实有力」 |
| 国家层面 | 经济长期向好、上级全会部署、政策加力 | 「展现光明前景」 |
| 行业层面 | 治理优势/市场优势/产业优势/品牌优势/网建优势 | 「五大优势没有变」 |
| 省级层面 | 省委省政府重视、出台支持政策 | 「外部环境优化」 |
| 本单位层面 | 高于行业平均的发展态势、软硬实力提升 | 「集聚强大合力动能」 |

### 综合判断（收口定调）

```
总体看，X时期发展机遇大于挑战、优势多于困难，是……的重要战略机遇期，我们完全有基础、有条件、有能力战胜风险挑战，奋力实现……目标。
（导向：坚定信心 + 机遇意识 + 风险意识 + 底线思维）
```

## 五、规划常用表述库

> 规划专用语气词，区别于方案的操作词。取自规划真实交付物与 `05_十五五规划术语.yaml`，按场景分类。

### 编制依据（导言用，对接上级规划）

- 「根据《国民经济和社会发展第X个五年规划和20XX年远景目标纲要》《烟草行业『X五』规划》《全省烟草商业『X五』规划》，结合本单位实际，编制本规划。」
- 「主动服务和融入进一步全面深化改革、推进中国式现代化战略大局」

### 立意起句（战略高度，时事势）

- 「X时期，是我国基本实现社会主义现代化夯实基础、全面发力的关键时期，也是行业和公司纵深推进高质量发展的关键阶段」
- 「在基本实现社会主义现代化进程中具有承前启后的重要地位」
- 「世界百年未有之大变局深度演化……同步交织、相互激荡」

### 指导思想政治表述顺序（严格不可倒置）

> 习近平新时代中国特色社会主义思想 → 党的二十大及二十届历次全会精神 → 党中央国务院决策部署 → 国家局党组/全国烟草工作会议 → 省委省政府/全省烟草工作会议 → 本单位上期部署

```
坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，认真落实党中央、国务院决策部署和国家局党组、省委省政府工作安排，坚持稳中求进工作总基调，坚持行业「十六字」方针，以推动高质量发展为主题，以……为主线，统筹发展和安全，加快培育新质生产力，全力推动……取得新成效。
```

### 基本原则领起词

- 「坚持党的全面领导」「坚持高质量发展」「坚持正确政绩观」「坚持系统观念」「坚持争先进位」「坚持科学方法」
- 句式：「——坚持X。……（一段阐释，落到本单位怎么做）」

### 发展思路（战略代号提炼）

- 「确立一个目标、推动『三高』、建成『六大体系』、实施『五项工程』」（综合）
- 「聚焦一个总体战略，实施两大支撑工程，推进七项提升行动，抓好九项重点任务」（工业，简称战略推进体系）
- 要点：数字代号后必须逐项展开解释，不能只抛代号。

### 目标定性词（远景状态，避免空心）

- 「实现质的有效提升和量的合理增长」「保持在合理区间」「迈入行业第一方阵」「实现由大到强的根本转变」
- 排比领起：「——X实现新提高/新进步/新突破/新升级/新增强/新提升」

### 重点任务领起词（方向性，非操作性）

- 「加快建成……体系」「持续推进……」「深入实施……」「全面提升……能力」「着力优化……布局」
- ⚠ 避免方案化动词：禁用「X月X日前完成」「X部门牵头」到动作级（见 SKILL 模块6）

### 保障措施落点词

- 党的领导：「把党的领导落实到规划实施全过程各方面」
- 组织机制：「健全规划实施的组织领导和统筹协调机制，分解落实责任」
- 资源投入：「强化资金、人才、技术等要素保障，向重点任务倾斜」
- 考核评估：「建立规划实施监测评估机制，开展中期评估和总结评估，强化结果运用」
