## 一、排比骨架（同句式并列，须有强调价值，不凑数）

> 三项最稳、四项加力、超五项慎用。每组核心词须差异化、字数对齐。

| 骨架名 | 公式 | 适用场景 |
|---|---|---|
| 三/四「同动词」式 | 把……集中在/体现在/展现在/锁定在「关键词」上 | 干部要求、任务落实 |
| 三「以……」式 | 以「更强的X」补短板，以「更多的X」增动力，以「更大的X」抓落实 | 年度部署、号召 |
| 三/四「聚焦……」式 | 聚焦「A」，让XX「单字动词」起来；聚焦「B」，让XX「动词」起来 | 多板块并列部署 |
| 三「让……」式 | 让「形容词」服务成为一种工作常态/行为习惯/价值追求 | 理念升华 |
| 三「在……中」式 | 在「A」中增强X能力，在「B」中增强Y能力 | 能力锤炼、磨砺 |
| 三「破X立Y」式 | 破「旧观念」，立「新意识」（可叠成五破五立） | 思想解放、改革动员 |
| 三「只有……才能」式 | 一切「难题/机遇/愿景」，只有在「实干」中才能「破解/把握/实现」 | 动员结尾、立论 |
| 喻体收尾式 | 画出「同心圆」/筑牢「压舱石」/找准「公约数」（每项以喻体收束） | 提纲型分点、最显气势 |
| 程度递进式 | 「主心骨」越来越硬，「主导权」越抓越牢，「主旋律」越唱越响 | 成效总结 |

要点：骨架是壳，填词时让每项有真内容（主体+动作），避免「主动、深入、周密、精心」这类**只有副词没有宾语的空排比**。
完整 130 条分 21 主题（能力/制度/规矩/纪律/人民/清廉/干部/创新/干事/服务/群众/坚持/精神/学习/斗争/廉洁/党性等）→ 见 `03_dictionary/golden_sentences/词句应用大全_排比句库.yaml`（id 前缀 GS）。

## 二、比喻喻体分类（抽象比具体，同段须同一意象家族）

> 选喻原则：本体抽象 → 选量级匹配、意象相关的喻体；喻体加引号；常规工作别用「手术刀/猛药/癌症」等过重喻体。

| 意象家族 | 代表喻体 | 喻什么 |
|---|---|---|
| 航船车辆 | 压舱石、定盘星、方向盘、风向标、导航仪、安全带、发动机、快进键 | 方向引领、驱动力 |
| 军队战争 | 攻坚战、阵地战、主力军、桥头堡、组合拳、杀手锏、冲锋号、作战图 | 任务艰巨、战略性、决心 |
| 人体部位/经脉 | 牛鼻子、主心骨、硬骨头、大动脉、经脉、梗阻、末梢神经、毛细血管 | 关键环节、堵点、末端落实 |
| 作用器物 | 金钥匙、试金石、压舱石、连心桥、防火墙、高压线、指挥棒、紧箍咒 | 举措作用、约束力 |
| 疾病诊疗 | 体检、望闻问切、对症下药、补钙、淬火、提纯（重喻：手术刀、猛药、毒瘤） | 问题诊断、整改（重喻慎用） |
| 角色定位 | 领头雁、火车头、店小二、施工队长、行家里手、参谋员、督查员 | 干部/机构角色 |
| 农耕自然 | 责任田、源头活水、沃土、磁场、摇钱树、深耕、滴灌（精准）、漫灌（粗放） | 培育、精细化/粗放对比 |

## 三、固定句式分类（按场景取骨架，填词后须接本单位实际）

> 来源：`03_dictionary/sentence_patterns/固定句式模板.yaml`（id 前缀 SP，92 条，`template` 字段带【XX】占位）；`开头结尾句式库.yaml`（id 前缀 OC，78 条）。下表只列抽象骨架，**不带原文 example**（含真实地名数据，须脱敏）。

### （一）引用上级精神/政策——借势导入
> 注：库内无「引原文」专类，靠「借政策机遇导入本单位工作」的承接句实现引上级的功能。
- 借势过渡：`借（乘）……的东风，全面掀起……新高潮`
- 借势推进：`以……为契机（突破口/切入点），切实做好……工作，推动……再上新台阶`
- 战略定位：`把……作为……的关键一招`
- 配套用法：引完上级精神，**紧接一句本单位的对接动作**（不留「贯彻落实……」空壳）。

### （二）成效陈述
- 动词排比：`干（改/换）出了……，干出了……，干出了……`
- 引领式：`突出「A」，……提升；围绕「B」，……有力；深化「C」，……显现`
- 程度词搭配（成果类词语库）：不断/持续/明显/逐步/全面 + 提升/健全/优化/巩固；迈上新台阶、实现新突破、开创新局面。

### （三）问题剖析（最丰富）
- 重轻对照：`重「A」、轻「B」；重「C」、轻「D」`
- 多少对照：`「A」多、「B」少；「C」较多、「D」较少`
- 不字列举：`……不高；……不强；……不够实`
- 三段递进（推荐）：`现象（仍存在……）→ 表现（主要表现在……）→ 根因（根子在……）`

### （四）工作部署
- 三段式（核心）：`起始句（任务方向）→ 中间句（措施 A/B/C）→ 收尾句（成效目标）`
- 编号部署：`一要……，二要……，三要……`
- 抓手句：`以……为载体/抓手，认真……，不断……`
- 抓字句：`明确目标抓关键；强化督查抓落实；创新机制抓执行`
- 要点：部署句须「方向 + 抓手 + 落点」三者齐全，不能只有方向。

### （五）开头
> 通用三段范式：**【形势/现象/引言】→【意义/原因】→【思路/方向】**
- 形势概括 + 概念界定 + 政策思路（报告/方案）
- 权威引古语 + 明确意义 + 发展方向（讲话）
- 提出问题 + 说明意义 + 指导思想（报告/讲话）
- 年度回眸排比：`回眸XX年，是……的一年；是……的一年`
- 季节起兴（仅讲话/座谈）：以春景古句引题营造气氛（见金句索引「开头·季节」）。

### （六）结尾
- 结尾对仗金句：`蓝图绘就，正当扬帆破浪；重任在肩，更须策马加鞭`
- 落实强调式：`千忙万忙，不抓落实就是瞎忙；千难万难，敢抓落实就不难`
- 讲话结束语：`同志们，……+ N 劲/N 心/N 情`（三劲、三心三情等排比收束）
- 升华金句收束：用「自强不息」「任重道远」「不积跬步无以至千里」类金句拔高（见第四节）。

## 四、金句化用三原则 + 主题索引

> 来源：`03_dictionary/golden_sentences/石头哥_金句素材.yaml`（id 前缀 GS，含 quote/source/meaning/usage_tips）。

### 三原则（反对生硬堆砌）
1. **融会贯通**：金句化入论述、引出下文判断，不孤零零贴一句。
2. **得体适用**：场合主题对（廉政≠创新≠担当）、文种对（古诗起句/温情寄语仅讲话与仪式）。
3. **适度引用**：一篇至多 1-2 处点睛；**引完必接一句「今意/落点」**，把古语接到本单位工作上。

## 五、通俗类比「相当于……」素材

> 复用 `skills/skill_style.md` 第八节。一篇 1-2 处，参照物须受众熟悉、量级对得上。
- 百分比 → 「××%，相当于每 20 项里有 17 项达标」
- 海量条款 → 「××条，相当于平均每个领域 18 条具体指标」
- 大额金额 → 「降本××亿元，相当于一个中型企业一年的利润」
- 抽象评价 → 「成熟度评价就像企业体检——不是为了得高分，是为了知道哪里需要治」
