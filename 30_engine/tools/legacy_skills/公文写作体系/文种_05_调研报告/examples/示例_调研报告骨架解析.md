# 示例：调研报告「问题—原因—对策」链条解析

> 素材取自 `00_raw_materials/调研报告` 两篇真实专题调研报告（一篇某省级中烟「管理效能攻坚专题调研报告」，一篇某市烟草「薪酬绩效调研报告」）。
> 已彻底脱敏：隐去单位名、姓名，具体数据替换为「X%」「X 家」占位。演示如何拆出三块链条并体检。

---

## 一、原报告骨架还原（脱敏）

### 案例甲：管理效能攻坚专题调研报告（专题诊断式·变体A）

```
开篇：调研背景与方法
  「根据工作安排，由分管领导带队，围绕管理效能攻坚推进情况，
   通过座谈交流、书面调研、数据分析、内部研讨等多种方式，
   对 X 家卷烟厂、投资公司等单位进行专题调研。」  ← 调研方法交代齐全 ✓
一、管理效能攻坚总体推进情况（现状+成效）
  核心数据：公司级指标提升率 X%、各厂指标提升率 X%，总体趋优。  ← 摆事实、有数据 ✓
二、专题调研发现的主要问题（4 条，分类）
  （一）对管理效能攻坚缺乏足够认识
  （二）个别指标完成存在压力，数据应用停留描述性统计
  （三）管控精细化程度不够
  （四）标准制修订和执行质量存在差距
三、下阶段工作思路（6 条对策）
（附）专题调研问题统计表：问题描述｜改进建议｜提报单位｜完成时限｜责任部门
```

### 案例乙：薪酬绩效调研报告（学习借鉴式·变体B）

```
开篇：调研背景与方法
  「按党委要求，由人事部门牵头，到 X 个兄弟单位开展学习调研，
   围绕薪酬结构、薪酬分配、绩效考核几方面学习交流。」  ← 主体+对象+方式+主题 ✓
一、兄弟单位的薪酬管理特点（外情，客观描述其做法）
二、反思本单位存在的问题（5 条）
三、对本单位薪酬改革的建议（6 条）
```

---

## 二、抽出「问题—原因—对策」三列对应表（案例甲）

把案例甲的中间三块拆开对齐。**注意：原报告问题与对策分置两节，靠附表把二者钉死——这正是「对策对应原因」的强落地形式。**

| # | 问题（基于调研事实）| 原因（由表及里挖到的层级）| 对策（主体+动作+抓手）|
|---|---|---|---|
| 1 | 数据应用停在描述性统计，缺预测性分析（多厂座谈反映）| 表层：基础台账与统计口径未统一；根层：缺数据分析能力与工具支撑（能力/资源）| 统一统计口径与台账规范；引入数据分析工具、培育分析骨干 |
| 2 | 管控精细化不够，业务牵头部门对细节把控不到位（座谈反映）| 中层：各条线业务分散、协同机制不畅；考核指标设置未兼顾单位差异（机制）| 牵头部门加强业务指导；优化绩效考核指标分解的科学性 |
| 3 | 标准制修订质量不高、修订频次过高（集中审核暴露）| 表层：制修订前瞻性不够；中层：基层标准制修订沟通协调机制不健全（机制）| 健全基层制修订协调机制、缩短周期；强化集中审核负责制 |

**体检结论**：三行均三项齐全、可编号映射，问题有座谈/审核出处，原因挖到了机制/能力层（非「重视不够」），对策含主体与抓手 → 链条合格。

## 三、反面诊断：原报告里偏弱的一条（案例甲问题一）

原报告问题（一）「对管理效能攻坚缺乏足够认识」一节，是典型偏弱写法，用本 skill 体检：

| 体检项 | 原文表现 | 判定 |
|---|---|---|
| 问题基于事实 | 「少数干部职工认识不够深刻」「营造氛围不够深入」——未指出调研出处 | △ 偏主观臆断 |
| 原因深度 | 通篇是「认识不深刻、决心不足、统筹不够、推进偏慢」 | ✗ 停在态度评价，未挖机制原因 |
| 对策对应 | 下阶段「进一步提升思想认识、凝聚合力」 | ✗ 空喊口号，无主体无抓手 |

**改写示范**（套模块2/3/4）：

裸问题（先写大白话，补调研出处）：
- X 家单位座谈中，X 家反映「不清楚攻坚指标与本岗位的关系」——问题不是「认识不深刻」，而是**「指标到岗到人的传导断了」**。

由表及里挖原因：
- 表层：攻坚指标只分解到部门，未细化到岗位
- 中层：缺少指标层层签订、可视化跟踪的机制
- 根层（停）：再问下去触及考核体系重构，超出本次可干预范围

对策接回原因（补主体+动作+抓手）：
- 「企管部牵头，将 X 项攻坚指标逐项分解到岗到人，签订指标责任书；建立月度可视化跟踪看板，让每名职工看见自身岗位与攻坚目标的关联。」

| 维度 | 改前 | 改后 |
|---|---|---|
| 问题基于事实 | △ | 「X 家座谈反映」有出处 ✓ |
| 原因有深度 | ✗ 态度评价 | 挖到机制层「指标传导断」✓ |
| 对策可操作 | ✗ 空喊 | 含主体+动作+抓手 ✓ |
| 对策对应原因 | ✗ | 对策正面接住「传导断」✓ |

## 四、案例乙的「对应」亮点（值得学的地方）

案例乙（薪酬调研）虽未单设「原因」一节，但把原因揉进问题、把建议逐条接回问题，对应关系清晰：

| # | 问题 | 隐含原因 | 对应建议 |
|---|---|---|---|
| 1 | 薪酬对主营业务导向性不突出 | 关键指标考核占比低（机制）| 创新薪酬分配模式，业务指标与绩效直接挂钩 |
| 2 | 日常薪酬管理过细、基层主动性不足 | 发放统一把控、基层无自主权（机制）| 引入重点工作积分制，下放二次分配空间 |
| 3 | 新老员工收入差距大 | 历史性过渡工资未消化（客观条件）| 用 10–15 年过渡期逐年消化差异工资 |

**已做对的两点（保留并学习）：**
1. 用「外情」（兄弟单位做法）作镜子照差距，问题天然有参照、不空。
2. 每条建议都能接回某条问题，无两张皮——这是调研报告对策的及格线。

**可提升处：** 原因层未独立、未标深度，部分原因仍偏现象描述。若要升格，把每条问题的原因单列一节、按「由表及里」标到机制/能力层即可。

## 五、一句话提炼

> 看一份调研报告够不够格，只做一件事：**把问题、原因、对策三列抽出来对齐，看每一行能不能从「是什么不对」一路读到「为什么」再读到「怎么治」。读不通的行，就是要回炉的行。**
