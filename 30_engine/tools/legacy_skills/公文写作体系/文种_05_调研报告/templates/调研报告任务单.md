**问题分类法（四选一，全表统一）**：
- [ ] 层级法：认识 / 机制 / 能力 / 数据(基础)
- [ ] 业务条线法：生产 / 营销 / 物流 / 专卖 / 财务……

## 五、对应完整性复核（全表填一次）
- [ ] 每条问题都有对应原因（无「有问题无原因」）
- [ ] 每条原因都有对应对策（无「有原因无对策」漏治）
- [ ] 每条对策都接得回某条原因（无「有对策无原因」无的放矢）
- [ ] 问题、原因、对策编号可一一映射（无两张皮）
- [ ] 一组问题只用一套分类法（无混用）

## 六、调研方法交代自检
