# 示例：总结骨架解析

> 取两篇真实 corpus 总结，脱敏后解析其骨架与成绩段写法，对照 `../SKILL.md` 的三块式。
> 客户名/数据/姓名已脱敏：单位→「某地市烟草／某区域部门」，数值→「X／X%／X 个百分点／全省第 X」。

---

## 示例一：单位工作报告（corpus-B 脱敏）

### 骨架透视

```
〔标题〕  坚持发展新定位 厚植发展新优势
         全力以赴开创某市烟草高质量发展新局面
         ——在 20XX 年某市烟草工作会议上的报告
〔称谓〕  同志们：
〔议程段〕以习近平新时代中国特色社会主义思想为指导，深入学习贯彻…，
         认真总结上年各项工作，安排部署本年工作任务。…
         下面，我代表市局（公司）党委作工作报告。

一、苦干实干、狠抓落实，上年工作有力有效              ← 成绩块（占比约 45%）
   〔总体定性〕总体保持稳中有进、稳中提质、稳中增效态势。
   〔核心数据〕主营业务收入 X 亿元，同比增长 X%；税利 X 亿元，同比 X%；
              上缴税收 X 亿元，同比 X%。
   「回顾一年来的工作，主要呈现以下几个特点：」
   （一）强基础、固根本，党的建设坚强有力。  一是…二是…三是…四是…
   （二）练内功、提水平，烟叶工作成效显著。  一是…二是…三是…四是…
   （三）调状态、促改革，卷烟营销卓有成效。  一是…二是…三是…
   （四）重外打、严内管，专卖管理扎实有效。  一是…二是…三是…四是…
   （五）建机制、搭平台，创新工作富有实效。
   （六）增动力、激活力，企业管理规范高效。  一是…二是…三是…四是…五是…
   〔次要工作一句带过〕同时，新闻宣传、离退休、教育培训…都取得长足进步。
   〔过渡到问题〕在肯定成绩的同时，仍然存在一些突出问题：
        一是高质量发展的危机感、使命感不够强。
        二是适应高质量发展的能力素质不够高。
        三是严格规范的生命线守得不够牢。

二、凝心聚智、善作善成，全面厚植高质量发展新优势        ← 形势/战略层（报告特有，约 18%）
   〔形势总判断：引上级最新精神 + 本单位挑战（烟叶规模跌至冰点…）〕
   （一）必须始终坚持党建统领。  一要…二要…三要…四要…
   （二）必须始终坚持创新驱动。
   （三）必须始终坚持打牢基础。
   （四）必须始终坚持做精做优。
   （五）必须始终坚持争创一流。

三、锐意进取、全力以赴，扎实推动本年工作实现新发展        ← 打算块（约 35%）
   〔总体要求 + 主要预期指标（烟叶 X 万担、上等烟 X%、卷烟 X 万箱…）〕
   （一）聚焦政治性、组织力、融合度，推动党的建设取得新成效。 一要…二要…
   （二）聚焦稳基础、提水平、展形象，推动烟叶生产取得新进步。
   （三）……（共六个「聚焦」板块）
〔结尾〕  动员段，呼应主标题。
```

### 三处可学

**1. 小标题：三字动宾对仗 + 成效定性**
「强基础、固根本，党的建设坚强有力」——前半「强基础、固根本」是两组三字动宾，后半「党的建设坚强有力」是成效判断。六个板块小标题句式高度统一（练内功提水平／调状态促改革／重外打严内管…），同层对仗。这是单位报告的标志风格。

**2. 成绩段：总体定性 + 一是/二是/三是 + 每条数据**
以烟叶板块为例，总起「烟叶工作成效显著」，再分「思想作风有转变／工作措施有力度／工作水平有提升／助农增收有进展」四条，每条挂数据（如「上等烟比例 X%，同比提高 X 个百分点」「担均价 X 元，同比增加 X 元」）。无一条只定性。

**3. 问题段：克制、列举、不展开原因**
三条问题各一句定性（危机感不强／能力素质不高／规范守得不牢），不分析成因，收口「必须坚持问题导向…切实加以解决」，把消解动作留给第三部分的「六个聚焦」。这正是总结区别于汇报之处——**汇报会展开原因，总结把原因留给打算去对应**。

### 一处反面提示
报告的「形势/战略」中间层（第二部分）只立意定调、不排年度任务；若把「必须始终坚持打牢基础」下写成「X 月完成 X 认证」这类年度量化任务，就该移入第三部分。立意层与部署层混淆，是报告类高频毛病。

## 示例二：部门年度工作总结（corpus-A 脱敏）

### 骨架透视

```
〔标题〕  20XX 年某区域部门企业管理总结和 20XX 年工作计划
〔引语〕  按照要求，现将综合部企业管理上年工作总结和本年工作计划报告如下：（无背景铺垫）

一、上年工作开展情况                                    ← 成绩块
   （一）目标导向，业绩考核科学有效     〔考核体系+结果排名〕
   （二）标准领航，基础管理持续夯实     一是…二是…三是…四是…五是…
   （三）对标提升，核心指标稳步提升     一是…二是…三是…（含对标排名 全省第 X）
   （四）优化流程，建设五星配送服务体系  一是…二是…三是…四是…
   （五）全面融合，全力推进管理创新     一是…二是…

二、下一步工作计划                                      ← 打算块（问题并入各条对应）
   （一）强化标准运行，提升企业规范化运行水平  一是…二是…三是…
   （二）强化标杆引领，切实增强综合实力       一是…二是…三是…
   （三）强化目标导向，建设物流指标管理体系   一是…二是…三是…
   （四）强化质量改进，推进仓储管理提质增效   一是…二是…三是…
```

### 与单位报告的三点差异（学「简版怎么搭」）

| 维度 | 部门总结（示例二） | 单位报告（示例一） |
|---|---|---|
| 语态 | 「综合部…报告如下」 | 「我代表党委作工作报告」 |
| 开篇 | 一句引语，无指导思想 | 议程段含指导思想引用 |
| 中间层 | 无形势层，成绩→打算直连 | 有「形势/战略」一层 |
| 小标题 | 「目标导向，业绩考核科学有效」（做法,成效两段，对仗较松） | 三字动宾严格对仗 |
| 问题处理 | 问题并入「下一步」各条对应消解，未单列问题段 | 成绩块末尾单列三条问题 |

### 一处可学：小标题「做法+成效」结论句
「对标提升，核心指标稳步提升」——前半「对标提升」点做法，后半「核心指标稳步提升」点成效，是结论句不是话题句（对比反面「关于对标工作」纯话题）。下文首句即复现「对标」「核心指标」，标题—正文锚定到位。

### 一处反面提示
该样本「下一步」部分条目多为「强化…、提升…、推进…」方向性表述，量化目标和时间节点偏少（如「持续提升关键业绩指标排名」未给目标值）。按本 skill Rubric「打算可量化」维度，这类条目应补「到 X 月使 X 指标达到 X」——这是部门总结最常见的失分点，起草时务必在任务单第四栏把量化目标填实。

---

## 小结：两示例对照看总结骨架

- **共性**：都走「成绩（数据落地）→（问题）→打算」主线；成绩段都是「小标题→分条→数据」；都不在成绩段堆背景。
- **繁简差**：单位报告多「形势/战略」层、有称谓与指导思想、小标题严格对仗、单列问题段；部门总结直连两块、语态轻、问题可并入打算。
- **共同易错**：下步打算量化不足。两篇都提示——打算条目必须落到「量化目标+时间节点」，否则就是反模式4。
