# 总结骨架库

> 配合 `../SKILL.md` 模块2 使用。本库给两个子文种的骨架对照、各板块字数预算、成绩段总分结构、问题段结构。
> 通用结构方法（MECE、排序、纵向以上统下）交 `../../专项_01_篇章结构/SKILL.md`，不在此重复。

---

## 一、两个子文种骨架对照

总结类底层都是「成绩-问题-打算」三块。区别在篇幅、语态、是否加「形势」中间层、小标题风格。

### 子文种A：部门/年度工作总结（1500-4000 字）

```
〔标题〕  「20XX 年 X 部门工作总结」或「…总结及 20XX 年工作计划」
〔引语〕  一句话：「按照要求，现将 X 部门 20XX 年工作总结报告如下」（≤50 字，不铺垫背景）

一、20XX 年工作开展情况               ← 成绩块
  （一）〔做法+成效〕小标题
       一是…（举措+数据）  二是…  三是…
  （二）……（共 4-6 个板块）

二、存在的问题与不足                  ← 问题块（短总结可并入第一部分末尾一段）
  一是…  二是…  三是…（3-5 条，列举式）

三、下一步工作计划                    ← 打算块
  （一）〔动词领起〕小标题（含量化目标）
       一是…  二是…  三是…
  （二）……（与问题对应）
```

要点：开篇可省指导思想；主体语态「X 部门」「我们」，不用「我代表」。

### 子文种B：单位工作报告（4000-10000 字）

```
〔标题〕  上行写主题定性「坚持发展新定位 厚植发展新优势」
         下行写动员结语「全力以赴开创…新局面」
         副标题「——在 20XX 年 X 工作会议上的报告」+ 日期 + 报告人
〔称谓〕  「同志们：」
〔议程段〕「以习近平新时代中国特色社会主义思想为指导，深入学习贯彻…，
         认真总结 20XX 年工作，安排部署 20XX 年工作任务。…
         下面，我代表 X 党委作工作报告。」（200-300 字，含指导思想）

一、〔判断短语〕，20XX 年工作有力有效        ← 成绩块
   〔总体定性句 + 3-5 个核心经济指标（同比）〕
   「回顾一年来的工作，主要呈现以下几个特点：」
   （一）〔三字动宾对仗 + 工作领域 + 成效定性〕，党的建设坚强有力。
        一是…  二是…  三是…  四是…（每条带数据）
   （二）……（共 4-8 个板块）
   〔过渡〕「在肯定成绩的同时，全市烟草仍然存在一些突出问题：」
        一是…  二是…  三是…（问题块，3-5 条）

二、〔判断短语〕，全面厚植高质量发展新优势    ← 形势/战略中间层（报告特有）
   〔形势总判断（引上级最新精神 + 本单位挑战）〕
   （一）必须始终坚持 XX。  一要…  二要…  三要…
   （二）……（3-6 项战略方针，只立意定调，不展开年度任务）

三、〔判断短语〕，扎实推动 20XX 年工作实现新发展  ← 打算块
   〔总体要求（含工作主线）〕
   〔主要预期指标（核心经济+业务指标，含具体数字）〕
   （一）聚焦 X、X、X，全力以赴推动 XX 取得新 XX。
        一要…（措施+节点+量化目标）  二要…  三要…
   （二）……（3-8 项重点工作）
〔结尾〕  动员段，呼应主标题（可选）
```

要点：报告比部门总结多「形势/战略」一层；称谓、指导思想、政治表述顺序均有刚性规范。

## 二、各板块字数预算

| 板块 | 部门总结（占比） | 单位报告（占比） | 硬约束 |
|---|---|---|---|
| 开篇总体评价 | 5%-10% | 单列议程段+总体定性，约 5%-8% | 含 3-5 个带基准数据 |
| 主要工作 | 55%-65% | 35%-50% | 4-8 板块，核心板块篇幅最大 |
| 形势/战略中间层 | 无 | 15%-20% | 报告特有，只定调不排任务 |
| 存在问题 | 5%-15% | 5%-15% | 不超过成绩块的 15% |
| 下步安排 | 20%-30% | 35%-45% | 与问题逐条对应 |

详略原则（源自详略五规律）：重要详、新颖详、近期详；次要略、已知略、旧事略。写完数每部分字数，看是否与重要性成正比——背景三段、重点一句即为详略倒置。

## 三、成绩段：总分结构标准件

```
〔总体定性句，含核心数据，带对比基准〕。
〔可选·分析级：这说明/实践证明，<规律性判断>。〕
一是〔成效名称〕。〔具体举措/做法〕+〔数据，必带同比/目标完成率/排名〕。
二是〔成效名称〕。〔举措〕+〔数据〕。
三是〔成效名称〕。〔举措〕+〔数据〕。
```

判定要点：
- 每条「一是/二是」至少 1 个数据；数据必带基准，禁「完成 X 万箱」式裸数。
- 小标题与首句锚定：首句须复现小标题核心动词或名词。
- 重点板块（全文 2-3 个）才用「分析级」加规律性判断，避免通篇「这说明」。
- 成效与举措成对：只有「取得成效」无举措 → 补做法；只有「开展了工作」无成效 → 补数据结论。

## 四、问题段：克制结构标准件

```
在肯定成绩的同时，我们也清醒地看到存在的问题和不足。
一是〔问题名称〕，〔一句话表现〕。
二是〔问题名称〕，〔一句话表现〕。
三是〔问题名称〕，〔一句话表现〕。
这些问题，必须坚持问题导向，采取有效措施，切实加以解决。
```

判定要点：
- 3-5 条，列举式，每条 50-100 字。
- **不展开原因分析**（原因留给「下步」对应消解；展开原因是专题汇报的活，不是总结）。
- 不回避：禁「总体良好、无重大问题」带过；问题须具体到工作事项。
- 不反复铺垫：禁「这些值得高度重视的问题，既是…也是…」咨询式套层。

## 五、下步段：可量化结构标准件

```
〔总体要求 1-2 句，含工作主线/量化主要预期目标〕。
一要〔动词+工作方向〕。〔具体举措，含时间节点（精确到月/季）+ 量化目标〕。
二要〔动词+工作方向〕。〔举措+节点+目标〕。
三要〔动词+工作方向〕。〔举措+节点+目标〕。
```

判定要点：
- 每条含「做什么（措施）」+「做到什么程度（量化目标/时间节点）」二元，缺一不可。
- 与问题段同序对应：问题第 N 条，下步应有第 N 条措施消解。
- 工作部署段三元逻辑（是什么/为什么/怎么办）：纯措施段须补一句重要性，详见 `../../../skill_framework.md`。
