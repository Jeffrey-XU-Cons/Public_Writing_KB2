# 工作总结——回顾既往，用数据与判断说清「做了什么·差在哪·下步怎么干」

> 本 skill 只解决「总结／工作报告」这一个文种怎么搭、怎么写。
> 通用骨架／标题／段落／字句技法分别指向：篇章结构用 `../专项_01_篇章结构/SKILL.md`，标题用 `../专项_02_标题炼制/SKILL.md`，段落意群用 `../专项_03_段落意群/SKILL.md`，炼句金句用 `../专项_05_炼句金句/SKILL.md`。

## 使用场景

当用户需要：
- 起草一份新的工作总结（用素材搭「成绩-问题-打算」三块式骨架→展开成稿）
- 诊断改稿（成绩段无数字／写成流水账／问题与下步两张皮／打算太虚）
- 把手里的素材（台账·数据·上级精神）搭成「成绩-问题-打算」三块式

不要用于：
- 设计整篇骨架、判断板块是否 MECE（用 `../专项_01_篇章结构/SKILL.md`）
- 小标题对仗、把话题句炼成结论句（用 `../专项_02_标题炼制/SKILL.md`）
- 段落内部论据三元（举措-数据-判断）的组织（用 `../专项_03_段落意群/SKILL.md`）
- 单纯找一句金句、排比句素材（用 `../专项_05_炼句金句/SKILL.md`）
- 只讲一两件事、聚焦单一主题且含请示事项（用 `../文种_01_汇报材料/SKILL.md`）

## 输入要求

需要用户提供：
- 周期（年度／半年／季度／专项，决定总结覆盖范围）
- 子文种（部门总结 or 单位工作报告，决定语态称谓与是否加形势层）
- 素材（工作台账·数据·上级精神，是成绩段写实的来源）
- 受众（向谁汇报／谁来宣读，决定语体与称谓）

如果输入不足，最多追问 3 个关键问题：
1. 「这是部门总结还是单位工作报告？」（决定语态称谓与是否加形势层）
2. 「要总结的周期是哪一段？」（决定覆盖范围与板块取舍）
3. 「有没有可用的带基准数据？」（无数据则成绩段无法写实，只能挂「成效显著」式空话）

## 模块1：文种定位——总结是什么、不是什么

- **本质**：总结是「回顾既往」的文体——立足已发生的一个周期（年度／半年／季度／专项），用数据和判断说清三件事：**做了什么（成绩）、差在哪（问题）、下步怎么干（打算）**。
- **三个动作**：① 摆事实——把周期内的工作用数据落地；② 下判断——不止罗列，要对成绩提炼规律性认识、对差距给出定性；③ 接未来——问题与下步一一对应，打算可量化、有节点。
- **总结 vs 汇报（关键区别，必记）**：
  - **时态与目的**：总结回顾「整个周期」、对全局负责，落点是「成绩-问题-打算」的闭环；汇报通报「某段进展或某专项」、对当下负责，落点是「情况+下步」，常含请示。
  - **完整性**：总结必须三块齐全、覆盖全周期全板块（4-8 个并列板块）；汇报可只讲 2-4 个板块、聚焦单一主题，不求穷尽。
  - **数据密度与基准**：总结的成绩段每条都要有数据且带对比基准（同比／目标完成率／历史最好／全省排名）；汇报数据可略松。
  - **问题段**：总结的问题段克制、列举式、不展开原因（原因留给「下步」对应）；专题汇报的问题段要展开原因分析。
  - 一句话：**总结是「一个周期的成绩单+体检报告+作战图」，汇报是「一件事的进度条」。** 不可一稿两用。

## 模块2：标准骨架——「成绩／问题／打算」三块式

总结类文稿的底层骨架恒为三块（源自金字塔「成绩-问题-打算」框架）。两个子文种在此骨架上分繁简：

```
【开篇·总体评价】（1 段，占比 5%-10%）
  一句话定性（含判断，可证伪）+ 3-5 个核心数据（带对比基准）
  例：「总体保持稳中有进、稳中提质、稳中增效态势」+ 收入/税利/上缴税收三组同比数

【主要工作】（4-8 个板块并列，占比 50%-65%）
  每板块一个对仗小标题 + 总分结构（聚焦…→一是/二是/三是）+ 每条带数据
  ← 详见模块3

【存在问题】（3-5 条，占比 5%-15%）
  「在肯定成绩的同时，我们也清醒看到」+ 一是/二是/三是（列举式，不展开原因）
  收口一句「这些问题必须…切实加以解决」

【下步安排】（3-5 条或并入工作部署，占比 20%-35%）
  每条含量化目标+时间节点，与「存在问题」逐条对应
```

**两个子文种的差别（详见 `references/总结骨架库.md`）：**

| 维度 | 部门/年度工作总结 | 单位工作报告 |
|---|---|---|
| 篇幅 | 1500-4000 字 | 4000-10000 字 |
| 主体语态 | 「综合部就…工作总结如下」 | 「我代表 X 党委作工作报告」，称谓「同志们：」 |
| 开篇 | 一句话引出，可省指导思想 | 必含「以…为指导」指导思想引用（政治表述顺序不可倒置） |
| 中间层 | 成绩→问题→打算 三块直连 | 三块之间常加「形势分析与战略定位」一层（占 15%-20%） |
| 小标题 | 「目标导向，业绩考核科学有效」式（做法+成效） | 「强基础、固根本，党的建设坚强有力」式（三字动宾对仗+成效定性） |

## 模块3：主要工作板块写法

每个工作板块是一个独立意群，标准写法为「小标题 + 聚焦 + 一是/二是/三是 + 每条数据」：

1. **小标题做成结论句**：用「坚持 X、有力 Y」或「X 导向，Y 持续提升」格式——前半做法、后半成效定性，禁纯名词短语（「标准化工作」）和纯话题句（「关于对标」）。对仗细则交 `../专项_02_标题炼制/SKILL.md`。
2. **板块首句点「聚焦」**：用一句话说清本板块围绕什么发力（「围绕…」「聚焦…」），并复现小标题核心词（标题—正文锚定）。
3. **正文「一是/二是/三是」分条**：每条 = 具体举措 + 成效数据。每条至少 1 个数据，数据必带对比基准。
4. **重点板块可升级「分析级」**：全文挑 2-3 个最核心板块，在总体定性句后加一句规律性判断（「这说明……」），其余板块保持叙事级，避免通篇说教。详见 `skill_style.md` 成效段进阶写法。

**一个达标的成绩板块长这样（脱敏样例）：**
```
（X）对标提升，核心指标稳步提升。围绕打造引领性指标的目标，持续开展对标跟进与改善。
一是分层分类对标成效明显，全省排名第 X，同比前移 X 位。
二是人均配送效率同比变化全省第 X，万箱终端配车、送货响应时间均居全省前列。
三是完成内部对标评比，形成 X 项省内标杆指标。
```
对照判据：小标题「对标提升，核心指标稳步提升」是结论句；首句复现「对标」「核心指标」（锚定）；三条各带数据且有基准（排名/同比/项数）。

## 模块4：排序——同层不混

- **主要工作板块**：按**重要性顺序**排（最核心成效在前），或按**固定业务结构顺序**排（党建→主业→管理→保障）；不得把边缘工作放第一条。
- **进展/历程类内容**（如专项推进、阶段回顾）：按**时间顺序**排（启动→推进→收官）。
- **下步安排**：与「存在问题」**同序对应**（问题第几条，打算第几条解决）。
- **硬规则**：同一层级只用一种排序逻辑，不得前三条按重要性、第四条突然按时间。排序方法论交 `../专项_01_篇章结构/SKILL.md`。

## 工作流

### 流程A：起草新总结
**输入**：周期 + 素材（工作台账/数据/上级精神）+ 子文种（部门总结／单位报告）
**步骤**：
1. **定周期与定性**：确认总结周期；用一句可证伪的话写「总体定性」，配 3-5 个带基准的核心数据（写不出 → 素材不足，回去补数据）。
2. **列工作板块**：从素材归堆出 4-8 个并列板块，做 MECE 检查（板块间不交叉、合起来覆盖全周期）——结构判断交 `../专项_01_篇章结构/SKILL.md`。
3. **定排序**：按模块4 选一种排序，同层统一。
4. **炼小标题**：每板块炼「做法+成效」结论句小标题，同层对仗——交 `../专项_02_标题炼制/SKILL.md`。
5. **填成绩段**：每板块按「聚焦→一是/二是/三是→每条数据」展开，重点板块升级分析级。
6. **写问题段**：3-5 条列举式，克制、不展开原因。
7. **写下步**：3-5 条，与问题逐条对应，每条含量化目标+时间节点。
8. 自检 Rubric ≥ 14/18，存稿。
**失败处理**：某板块写不出数据 → 标「[待补充：需 X 类数据]」，不用「成效显著」占位。

### 流程B：诊断改稿
**输入**：现有总结全文 + 用户指出的问题
**步骤**：
1. 抽出全部小标题单列，逐条判结论句/话题句，标红话题句。
2. 扫成绩段：逐条查「有无数字、数字有无基准」，无数字或无基准的标红。
3. 查问题段：是否展开了原因（应删）、是否回避（「总体良好」带过，应补真问题）。
4. 查问题↔下步对应：列两栏比对，找「有问题无措施」「有措施无对应问题」。
5. 查篇幅配比：背景/成绩/问题/打算是否失衡（详略倒置）。
6. 输出「问题清单 + 改写对照表」，只改点名处，其余只提示（遵循修改模式）。
**失败处理**：
- 若改成结论句后与正文数据不符 → 是正文没写实，标注提示而非替用户编数据。
- 若问题↔下步无法逐条对应 → 提示该问题缺措施，不擅自补虚措施。

## 输出格式

起草新总结，先输出骨架供确认（套 `templates/工作总结任务单.md` 填）：
```markdown
# 总结骨架：[周期]·[子文种]
- 总体定性：[一句可证伪判断] | 核心数据：[3-5 个带基准]
一、[做法+成效小标题]（聚焦：__）  一是[举措+数据] 二是 三是
二、……（共 4-8 板块，排序：重要性/结构/时间，同层统一）
存在问题：一是… 二是… 三是…（3-5 条，不展开原因）
下步安排：一要…（对应问题1，含量化目标+节点） 二要…
- 自检：三块✓ | 成绩条条带基准✓ | 问题↔下步对应✓ | 同层同序✓
```

诊断改稿，输出问题清单 + 改写对照表：
```markdown
# 总结诊断表
| # | 位置 | 问题类型 | 改写建议 |
|---|---|---|---|
| 1 | 成绩（三） | 只定性无数字 | 补「同比 X%／完成率 X%」 |
| 2 | 问题段 | 展开了原因 | 删原因分析，留给下步对应 |
总评：X/18（等级）。优先改：第__项。
```

## 质量 Rubric

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 文种规范 | 写成了汇报/方案；语态/称谓错位 | 子文种特征模糊 | 基本符合总结体例 | 周期、语态、三块齐备，子文种特征到位 |
| 三块完整 | 缺成绩或问题或打算 | 三块都有但某块敷衍 | 三块完整 | 三块完整且占比合理（成绩 50%+、问题 5%-15%） |
| 成绩有数据基准 | 多数条目只定性无数字 | 有数字但少基准 | 多数条带基准 | 每条成效均含数据且带对比基准 |
| 问题克制 | 不写问题或大篇分析原因 | 问题展开过度 | 基本列举式 | 3-5 条列举、不展开原因、直陈真卡点 |
| 打算可量化 | 全是「继续加强/推进」 | 部分有目标 | 多数有目标或节点 | 每条含量化目标+时间节点，与问题对应 |
| 详略得当 | 背景占大头、成绩一句话 | 篇幅略失衡 | 大体合理 | 篇幅与重要性成正比，核心板块充分 |

**等级判定（满分 18）**：PASS（≥14）可交付｜WARN（11-13）小修｜MAJOR（7-10）须修订｜REWRITE（<7）重做。

## 反模式

1. **成绩段只定性无数字**——「各项指标稳步提升、工作取得积极成效」。改：每条补「同比 X%／完成率 X%／全省第 X」。
2. **流水账无主次**——把所有事不分轻重平铺，背景写三段、重点一句话。改：定重要性排序，给核心板块分配足够篇幅，次要工作并入「同时，…等工作也取得进步」一句带过。
3. **问题与下步两张皮**——问题列了 A/B/C，下步讲的是 D/E/F。改：下步逐条认领问题，问题第几条打算第几条解决。
4. **打算无量化目标**——「下一步要进一步加强、持续深化、扎实推进」。改：替换为「到 X 月完成 X，使 X 指标达到 X」。
5. **把总结写成汇报**——只讲一两件事、夹带请示、缺问题段。改：补齐全周期板块、删请示、补三块。

## 完成前检查清单

- [ ] 周期、子文种（部门总结／单位报告）已确认，语态/称谓正确？
- [ ] 「成绩-问题-打算」三块齐全，占比合理？
- [ ] 开篇总体定性是可证伪的判断句，且配 3-5 个带基准的核心数据？
- [ ] 每个成绩条目都有数据且带对比基准？
- [ ] 问题段 3-5 条、列举式、未展开原因、未回避？
- [ ] 下步每条含量化目标+时间节点，且与问题逐条对应？
- [ ] 同层排序唯一、不混用？篇幅与重要性成正比？
- [ ] 通用结构/标题/段落/字句问题是否已转交对应专项 skill？
- [ ] 自评 Rubric ≥ 14/18？
