# 讲话稿任务单（逐项填空）

> 用法：起草新讲话前先填完本单，把听众、量化目标、形象化表述、号召语都想清楚，再动笔。改造旧汇报时只需填「三、号召语锚定检验」一栏自检。

## 一、基本信息
- 会议名称：______
- 讲话人身份：______（局长／总经理／分管领导）
- 听众身份：______（一线职工／中层管理／卷烟厂厂长／……）
- **听众最关切的事**：______（最担心 / 最在意 / 最想得到——决定号召语锚定谁）
- 篇幅要求：______ 字（默认 3000-8000）

## 二、开场（≤200 字，自检无感性铺垫）
- 本次会议主要任务（一串动词短语）：______
- 承上一句（刚才 XX 同志汇报/传达了……）：______
- 收口：下面，我讲 ___ 点意见。
- [ ] 称谓后无「大家好」 [ ] 无形势分析 [ ] 无「意义重大」铺垫 [ ] ≤200 字

## 三、三段骨架（含各板块量化目标）

### 第一部分：充分肯定成绩
- 一级标题（…要继续坚定 ___ 的信心）：______
- 总体肯定句 + 核心数据：______
- 分板块成效（每条对仗 + 1 个带对比基准的数据）：
  - （一）______ ｜数据：______
  - （二）______ ｜数据：______
  - （三）______ ｜数据：______
- 指出不足（1-3 条，一句一条，不展开）：______

### 第二部分：准确把握形势
- 一级标题（…要继续坚定 ___ 的决心）：______
- 总体形势判断（引上级精神 + 本单位挑战）：______
- 角度一（先引上级，再结合实际「为什么必须做」）：______
- 角度二：______
- 角度三：______

### 第三部分：部署重点任务
- 一级标题（…要继续坚定 ___ 的恒心）：______
- 总体要求（含量化目标 + 工作主线）：______
- 一要 ______：量化目标 ___｜时间节点 ___｜责任主体 ___
- 二要 ______：量化目标 ___｜时间节点 ___｜责任主体 ___
- 三要 ______：量化目标 ___｜时间节点 ___｜责任主体 ___

> 三个一级标题尾巴是否「信心 / 决心 / 恒心」三连？ [ ] 是

## 四、生动性：拟用的形象化表述（至少 1 处，建议 2 处）
- 形式（比喻 / 典故俗语 / 身边案例）：______
- 具体表述：______
- 关键数据通俗化（「___ 相当于 ___」）：______

## 五、鼓动性：号召语 + 锚定检验
- 号召语初稿：______
- **替换检验**：把「我们/大家」换成「______（具体听众）」后，是否仍通顺？
  - [ ] 仍通顺 → 泛化，须重写为针对本次听众的专属表述
  - [ ] 换了即不通顺 → 锚定到位 ✓

## 六、语体自检（成稿后）
- [ ] 抽查 10 句，句句 ≤20 字、可一口气念完
- [ ] 所有精确数字已口头化（约数/比例/相当于）
- [ ] 板块切换处有提顿词（同志们/下面/要特别强调）
- [ ] 每板块≥1 处疑问或感叹句
