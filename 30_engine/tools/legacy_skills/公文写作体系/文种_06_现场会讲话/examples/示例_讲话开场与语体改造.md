# 示例：讲话开场写法 + 汇报句→讲话句语体改造

> 素材取自两篇真实现场会/工作会讲话（已脱敏：单位→「某市/某省烟草」，数据→约数/X%，姓名→「某领导/XX同志」）。
> 演示两件事：①开场怎么写；②一段「汇报书面句」如何改造成「讲话口语句」。

---

## 一、开场写法示范（≤200 字，无感性铺垫）

取自一篇「管理效能攻坚推进会」讲话开场，脱敏后：

```
同志们：
今天会议的主要任务是，认真贯彻落实公司管理效能攻坚三年行动部署，总结攻坚开展情况，
分析存在问题，安排部署下一步重点工作，动员公司上下凝聚共识、奋力完成各项任务。
刚才，XX同志汇报了总体进展和专题调研情况，相关部门汇报了任务落实情况，我完全同意。
下面，我讲三点意见。
```

**为什么这是合格开场（对照模块3铁律）：**
- 第一句即「主要任务是……」，一串动词短语（贯彻/总结/分析/部署/动员）讲清会议干什么 ✓
- 承上一句「刚才 XX 同志汇报了……我完全同意」，自然衔接前序议程 ✓
- 「下面，我讲三点意见」收口，引出正文 ✓
- 全段约 130 字，无「会议意义重大」铺垫，无形势分析 ✓

**该篇三个一级标题（三连动员句式，教科书范例）：**
```
一、工作成效显著，要继续坚定效能攻坚的信心
二、准确把握形势，要继续坚定突围破局的决心
三、锚定目标任务，要继续坚定笃行不怠的恒心
```
三段尾巴「信心 / 决心 / 恒心」押同一句式，上台念出来有节奏、有递进。

## 二、语体改造：汇报书面句 → 讲话口语句

下面取一段真实工作总结的书面表述，演示走流程B「语体改造清单」后的效果。

### 改造前（汇报书面体，脱敏）

> 公司围绕落实上级推进高效能治理的战略部署、坚持系统性管理能力提升的总体要求，扎实开展了管理成熟度评价体系建设工作，目前已完成评价条款 2977 条，覆盖能力域 42 个，核心指标提升率达到 85.7%，工作整体成果显著、质效兼优。

**问题诊断**：
- 首句 50 字，含多重从句（「围绕……坚持……开展了……」三层套叠），一口气念不完
- 数据全是精确值（2977 条、42 个、85.7%），耳朵接不住
- 无提顿词、无情感句，纯客观陈述，没有现场感

### 改造后（讲话口语体）

> 同志们，上级明确提出推进高效能治理。这是行业的总方向。
> 公司要把它落到实处，靠什么？靠管理成熟度评价体系。
> 这套体系，我们写了将近三千条评价条款，覆盖四十多个能力域。
> 效果怎么样？核心指标提升超过八成五——相当于每 20 项里 17 项达标。
> 这说明，只要肯干，管理上的问题是能解决的。

**改造对照（逐条对应清单）：**

| 清单项 | 改前 | 改后 |
|---|---|---|
| 拆长句 | 50 字一句 | 拆成 5 个短句，最长 17 字 |
| 拆从句 | 「围绕…坚持…开展了…」套叠 | 改「靠什么？靠……」一问一答 |
| 数据口头化 | 2977 条 / 42 个 / 85.7% | 将近三千条 / 四十多个 / 超过八成五 |
| 通俗化 | 无 | 「相当于每 20 项里 17 项达标」 |
| 加提顿 | 无 | 「同志们」「靠什么？」 |
| 加情感句 | 无 | 「效果怎么样？」「这说明，只要肯干……」 |

### Rubric 评分对比（语体口语化 + 生动性 + 文种规范三维）

| 维度 | 改前 | 改后 |
|---|---|---|
| 文种规范 | 1（第三人称客观陈述） | 3（「同志们/我们」现场感） |
| 语体口语化 | 0（长句缠绕、从句嵌套） | 3（句句≤20 字、可一口气念） |
| 生动性 | 0（无形象） | 2（「相当于……」通俗化） |
| 数据口头化 | 0（全精确值） | 3（约数+比例+相当于） |

## 三、一处生动性 + 鼓动性收尾示范（脱敏）

真实讲话里这样收尾形象又有力（脱敏后）：

> 「千里之堤，毁于蚁穴。」费用上的小问题放任不管，必将后患无穷。
> 各位单位一把手，降本增效就在你们手上。
> 省局今后只看结果，用数字说话——还是那句老话，「不看广告，看疗效」。

**为什么合格：**
- 生动性：「千里之堤毁于蚁穴」「不看广告看疗效」两处形象化，靠听也能懂（非谐音，不依赖看字）✓
- 鼓动性替换检验：「各位单位一把手……就在你们手上」——把「一把手」换成「一线职工」立刻不通顺，说明锚定了具体听众 ✓
