# 公文写作体系 · Skill 调度索引

> 把烟草行业公文写作的「书本方法论」蒸馏成 12 个可反复调用的 skill：1 个总纲 + 6 个文种 + 5 个专项。
> 蒸馏自五本公文写作专著与两部标题/金句资料，融合本项目既有 `02_rules`／`03_dictionary`／`04_corpus`／`skill_*.md`，全部脱敏（无客户名、无具体经营数据、无姓名）。
> 每个 skill 同构：`SKILL.md`（方法）+ `references/`（主参考库 + evidence-map 证据索引）+ `templates/`（可填空工作单）+ `examples/`（取自语料的脱敏真实示例，带前后对比）。

---

## 一、体系地图

```
                       ┌─────────────────────────────┐
                       │   00_总纲_公文写作（总指挥）   │
                       │  判文种 + 五层流程调度 + 验收  │
                       └──────────────┬──────────────┘
              ┌───────────────────────┼───────────────────────┐
              ▼                                               ▼
   ┌───────────────────┐                         ┌───────────────────────┐
   │  文种层（搭什么）   │                         │   专项层（怎么炼）      │
   ├───────────────────┤                         ├───────────────────────┤
   │ 文种_01 汇报材料   │                         │ 专项_01 篇章结构（结构）│
   │ 文种_02 工作总结   │                         │ 专项_02 标题炼制（标题）│
   │ 文种_03 实施方案   │  ── 任一文种成稿时调用 ──▶│ 专项_03 段落意群（段落）│
   │ 文种_04 发展规划   │                         │ 专项_04 遣词用字（用词）│
   │ 文种_05 调研报告   │                         │ 专项_05 炼句金句（表述）│
   │ 文种_06 现场会讲话 │                         └───────────────────────┘
   └───────────────────┘
```

- **总纲**只负责派活与串联，本身不写技法。
- **文种 skill**管「这个文种怎么搭、骨架/开场/各板块/红线」。
- **专项 skill**管「跨文种的通用炼制能力」，被任何文种在成稿时调用。

## 二、五层流程 → 调用哪个 skill

| 层 | 核心动作 | 主调 skill | 过关闸 |
|---|---|---|---|
| ① 思维准备 | 判文种、立意三字经、WA 目标、四情四要素 | `00_总纲_公文写作` | 写不出主旨句不进下一层 |
| ② 结构设计 | 结论先行、SCQA、MECE、提纲三级 | `专项_01_篇章结构` | 论点树 MECE 不过不展开 |
| ③ 内容填充 | 意群、三元公式、详略、数据基准 | `专项_03_段落意群` | 段落缺概括桥/无数据基准须补 |
| ④ 语言打磨 | 标题结论化 + 字词准确 + 句子生动 | `专项_02_标题炼制`＋`专项_04_遣词用字`＋`专项_05_炼句金句` | 话题句标题/套话/平句须改 |
| ⑤ 质量审查 | 统稿八看、意思流窜、术语规范 | `00_总纲_公文写作`（配 `../skill_quality.md`） | 八看 Rubric ≥20/24 才交付 |

## 三、文种判定速查

| 你要写 | 选 | 区别要点 |
|---|---|---|
| 向上通报某项工作让领导拍板 | 文种_01 汇报材料 | 给领导看、结论先行、问题段克制 |
| 回顾整个周期、对内沉淀 | 文种_02 工作总结 | 成绩/问题/打算三块齐全 |
| 面向未来、要可落地可考核 | 文种_03 实施方案 | 目标可量化、任务有责任人时间节点 |
| 中长期战略、定方向远景 | 文种_04 发展规划 | 定性目标+定量指标体系，不下到动作级分工 |
| 用事实找问题挖原因提对策 | 文种_05 调研报告 | 问题-原因-对策可逐行映射 |
| 讲给人听、要听得进听完想做 | 文种_06 现场会讲话 | 短句口语提顿、生动鼓动、为耳朵写 |

## 四、怎么用

**人（Jeffrey）用：**
1. 接到任务，先开 `00_总纲_公文写作/SKILL.md`，按它判文种、判模式（写/改）。
2. 用对应文种的 `templates/<文种>任务单.md` 把思维准备填死。
3. 搭骨架/炼标题/写段落/锤字句时，按需翻对应专项 skill 的 `references/` 库与 `templates/` 工作单。
4. 成稿后用总纲的「统稿八看」Rubric 验收。

**Agent 用（配合项目 CLAUDE.md 工作模式一/二）：**
- 模式一（写）：总纲顺走五层，逐层调专项 skill，每层过关闸。
- 模式二（改）：总纲反走——先用八看定位失分维度，再回派到对应专项 skill 做定向修改，不重写无关板块。

## 六、蒸馏来源与边界

- **蒸馏自**：公文写作底层心法、公文写作心法（原则与禁令）、结构化写作、公文写作大手笔（品味公文）、笔杆子是怎样炼成的，及公文标题结构、公文金句素材两部资料。
- **脱敏声明**：所有 skill 与示例已剥离客户单位名、具体经营数据、人名，只保留通用方法、流程、判断标准与脱敏后的结构示例。
- **边界**：本体系提供方法框架与诊断工具；具体行业术语、金句素材仍需配合 `03_dictionary` 调用。烟草外行业套用时，文种 skill 的「惯用格式」红线需重新校准。

## 七、质量门控

12 个 skill 经统一机械质检（结构完整性 / 弯引号 / 脱敏 / 交叉引用解析）+ 对抗式质量审查（比对金标准、按 9 段结构与 Rubric 逐项挑刺）。
门控明细见 `_质量门控汇总.md`。
