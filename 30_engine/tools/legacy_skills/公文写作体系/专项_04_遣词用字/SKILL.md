# 遣词用字——把字词打磨到准确、简洁、无套话、不带咨询味

> 本 skill 只解决「字词层」一个问题：让每个词都准确、必要、规范，让读者读到的是信息而不是套话。
> 上游依赖结构（先有 MECE 骨架，用 `专项_01_篇章结构`）和标题（用 `专项_02_标题炼制`）；本 skill 不管句子修辞与金句（那是 `专项_05_炼句金句`）。

## 使用场景

当用户需要：
- 成稿后做一轮「语言瘦身」：逐段删繁、清套话、查禁用词、改搭配（流程A）
- 对某一个词、某一句搭配定向查证「这个词能不能用、这个搭配对不对」（流程B）
- 把一段「高度重视、扎实推进、进一步加强」式的空话，改写成「重视了什么、做了什么、达到什么」的具体表述

不要用于：
- 设计整篇骨架、判断板块是否 MECE（用 `专项_01_篇章结构`）
- 拟标题、把话题句炼成结论句（用 `专项_02_标题炼制`）
- 找排比句、比喻、金句素材，做句子层面的修辞（用 `专项_05_炼句金句`）

## 输入要求

需要用户提供：
- 待体检的文稿全文，或待查证的具体词句
- 文种（讲话稿口语词可酌情保留，书面材料须全删）——决定口语词、情绪词的去留尺度
- 是否对外（外发材料对烟草行业禁忌词 PW-203、绝对化用语把关更严）

如果输入不足，最多追问 2 个关键问题：
1. 「这是讲话稿还是书面材料？」（决定『老百姓』『同志们』『下面我讲』等口语词能否保留）
2. 「这份稿子是内部用还是要外发？」（决定行业禁忌词、绝对化用语的把关松紧）

## 工作流

### 流程A：通篇语言瘦身（成稿阶段，逐段过）
**输入**：文稿全文 + 文种
**步骤**：
1. **删繁打底**：逐段做「删繁三遍」——删冗余结构（『进行了讨论』→『讨论了』）、删叠加副词（『非常十分重要』）、删空引导语（『值得一提的是』『可以说』）。目标：每段删去约 10% 的字而意思不变（记进 `templates/语言瘦身工作单.md`）。
2. **套话扫雷**：对照「十个不写」逐段标红空话/套话/大话，凡『高度重视/进一步加强/扎实推进/切实提高』后面没有具体内容支撑的，按「套话替换四问」（重视了什么？做了什么？做到什么程度？得到什么结果？）改写为具体表述。
3. **禁用词体检**：对照 PW 禁用词表查绝对化用语（最/完全/所有）、俗语网络语、行业禁忌词；对照口语转书面表查『搞/弄/挺/老百姓』。书面材料一律替换，讲话稿据文种保留。
4. **搭配核对**：对照 MM 搭配规范表查易错动宾（『制定规划→编制规划』『落实任务→完成任务』）与量词（『一项规划→一个规划』）。
5. **去咨询味**：扫『底层逻辑/顶层架构/三个维度/三重力量/用一句话概括』等咨询黑话，按对照表换成行业惯用表达。
6. **炼字收口**：同义堆砌择一（『加强和提高』『不断加强和提高』），近义词重复删除；通读一遍做最后炼字。
**输出**：瘦身后全文 + 一张「修改清单」（原表述｜问题类型｜改后）
**失败处理**：
- 若一句套话删掉后该处「无话可说」→ 是内容本身空，提示退回 `专项_03_段落意群` 补事实，不能用另一句套话填补
- 若某专业术语找不到行业惯用表达 → 查 `03_dictionary/tobacco_terms/`，仍无则标注「[待核术语]」，不擅自生造

### 流程B：定向查词（任意阶段，单点查证）
**输入**：一个词 / 一处搭配 / 一句疑似套话
**步骤**：
1. 判类型：属禁用词？搭配错误？套话？口语词？咨询味？（对照 `references/用词规范库.md` 五张表）
2. 给裁决：能用 / 不能用 / 有条件用（注明文种条件），并给出替换词。
3. 给依据：标出来源规则号（PW-2xx / MM-0xx / CP-4xx / LS-0xx / OTF-0xx），让结论可追溯。
4. 若是套话，用「套话替换四问」现场示范一句改写。
**输出**：`[原词] → [裁决] → [替换] → [依据规则号]`，套话另附一句改写示范
**失败处理**：
- 若该词「视语境而定」（如『抓好』庄重型替换、口语场合可留）→ 不给一刀切结论，列出两种语境分别裁决

## 方法论模块

### 模块1：准确为底线（地基，必过）
- **触发条件**：任何用词，瘦身或查词都先过这一关
- **核心法则**：准确是底线，简洁是追求，生动是境界——三者冲突时准确优先
- **操作步骤**：
  1. **一词不能拆两词**：能一个词说清的不用两个词（『加强和改进』若对象同则择一；对象不同才并列）
  2. **专业术语用行业惯用表达**：管理类术语查 `03_dictionary/tobacco_terms/`，不用通用 AI 替代说法（『成熟度评估』→行业惯用『成熟度评价』；『管理诊疗』→『管理诊断』）
  3. **概念用对不用混**：易混专有概念按规范写（『共同致富→共同富裕』『中国特色现代化→中国式现代化』『精益管理≠精细管理』）
  4. **不夸大不绝对**：删『最/完全/所有/永远/一定要』等绝对化用语，留有余地
- **输出要求**：每处替换标注「准确性问题类型」（拆词/术语不规范/概念混用/绝对化）
- **常见错误**：用『管理诊疗』『成熟度评估』等近义生造词；『提高质量』（质量须搭『提升』）；『高质量的发展』（中间不加『的』）

### 模块2：简洁三法（瘦身主引擎）
- **触发条件**：每段正文写完后、或拿到他人初稿做瘦身时
- **三法**：
  - **避免重复**——同一意思全文只出现一次；同句内重复词（『继续继续』『大力大力』）直接删
  - **炼字**——一个词能说清不用两个词；删可有可无的字（『进行了讨论』→『讨论了』，『给予了支持』→『给予支持』）
  - **删繁**——每写完一遍，删去所有可以不要的字，**目标每段删约 10% 而意不变**
- **操作步骤**：逐段三遍过——一遍删冗余结构与叠加副词，一遍删空引导语（『值得一提的是』『可以说』『从某种意义上讲』），一遍通读炼字。每段记录「原字数→删后字数」。
- **输出要求**：给出每段瘦身比例，全文累计删字比例
- **常见错误**：把删繁当成删内容（删的是冗字不是论据）；只删一遍就收手（删繁须多遍）

### 模块3：十个不写（套话/废话扫雷清单）
- **触发条件**：通篇体检时逐段对照
- **十类不写**：废话 / 套话 / 错话 / 大话 / 空话 / 假话 / 病话 / 难懂的话 / 过时的话 / 矛盾的话
- **操作步骤**：逐段标红，对号入座——
  - **空话/套话**：『高度重视』『扎实推进』『进一步加强』后无具体内容 → 用模块5 改写
  - **大话**：『绝对没有问题』『一定会完成』『颠覆性变革』→ 改留余地表述（『有信心』『历史性变革』）
  - **病话**：主语残缺（『通过……提高了……』缺主语）、搭配错误、双重否定（『如无不妥，请批示』）
  - **难懂的话**：咨询黑话、生造四字格 → 用模块6 + 行业惯用词
  - **过时/矛盾**：陈套结尾语（『如有不当之处，请批评指正』）、前后口径不一
- **输出要求**：每条标红注明属十不写的哪一类
- **常见错误**：把「四字格排比」当文采堆砌（连续 5 个以上无支撑的四字格要砍）

### 模块4：禁用词与搭配体检（对照 PW / MM）
- **触发条件**：通篇体检的硬关卡，或定向查证某词
- **三查**：
  1. **查禁用词（PW）**：绝对化用语（PW-201：最好的/完全/所有/永远）、俗语网络语（PW-202：要不得/折腾/给力/点赞）、行业禁忌词（PW-203：烟草销售→卷烟营销、烟民→消费者规模、上瘾→消费粘性）
  2. **查搭配（MM）**：动宾易错（MM-301：编制规划/完成任务/增强意识/取得成效/采取措施）、量词（MM-302：一个规划/一次会议/三条建议/一项措施）
  3. **查口语词（LS/OTF）**：动词（搞/弄/干好/抓好）、程度词（挺/蛮/很给力）、称谓（老百姓）、冗余（进行了/给予了/作出了+了）
- **操作步骤**：用 Grep 跑一遍高频禁用词与口语词正则（清单见 `references/用词规范库.md`），逐条裁决：书面材料一律替换；讲话稿据文种保留口语词（『老百姓』『同志们』可留，网络语仍禁）
- **输出要求**：命中表（命中词｜所在位置｜规则号｜替换）
- **常见错误**：把讲话稿当书面稿，误删『同志们』『下面我讲』等合理提顿词；漏查行业禁忌词导致外发风险

### 模块5：套话替换为具体（信息含量提升）
- **触发条件**：凡出现『高度重视/进一步加强/扎实推进/持续深化/切实提高』等空动词短语
- **套话替换四问**（把抽象动词还原为可核查的事实）：
  1. **重视/加强了什么？**——具体的对象、领域、抓手是什么
  2. **做了什么？**——采取了哪些具体动作、措施、机制
  3. **做到什么程度？**——量化标尺：覆盖率、完成率、时间节点
  4. **得到什么结果？**——成效数据 + 对比基准（同比/目标完成率/排名）
- **操作步骤**：对每句套话四问填空，至少补足前两问；能补数据的补第三、四问。补不出 → 是内容空，退回补素材，不可用另一套话顶替。
- **输出要求**：套话替换对照表（原套话句｜四问填空｜改后具体句）
- **常见错误**：把一句套话换成另一句套话（『高度重视』→『充分认识重要性』，仍是空话）；只补一句过渡而无事实

### 模块6：去咨询味（咨询黑话 → 行业惯用）
- **触发条件**：咨询机构起草的稿子转为甲方公文体时（高发区）
- **核心对照**（完整表见 `references/用词规范库.md`）：
  - 结构黑话：底层逻辑→基本思路；顶层架构→整体架构；核心框架→主要框架
  - 拆分黑话：三个维度/三个层面/三重力量→一是、二是、三是；从外部看/从内部看/从实践看→直接列条
  - 引导黑话：用一句话概括→（删，直接说）；这正是……的根本出发点→（删，多余总结）
  - 标题黑话：『顶层架构：六大核心业务的分类逻辑』式冒号副标题→改烟草惯用一级标题格式
- **操作步骤**：Grep 扫黑话词 → 逐处换行业惯用词；『N 个维度』类一律拆成『一是/二是/三是』扁平罗列
- **输出要求**：去咨询味对照表
- **常见错误**：只换词不换结构（把『三个维度』改成『三个方面』，仍是咨询拆分句式，应直接『一是二是三是』）

## 质量 Rubric

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 准确性 | 术语生造/概念混用/绝对化普遍 | 个别用词不准 | 基本准确 | 术语全用行业惯用，无拆词、无绝对化 |
| 简洁度 | 冗字冗句满篇，无瘦身 | 删了一遍仍偏长 | 基本精炼 | 每段删≥10%、无可删冗字 |
| 无禁用词 | PW 禁用词多处命中 | 个别命中 | 基本无 | 绝对化/俗语/行业禁忌词全清 |
| 搭配规范 | 动宾/量词错误普遍 | 个别错配 | 基本规范 | MM 易错搭配全部正确 |
| 套话清除 | 通篇『高度重视/扎实推进』空转 | 半数套话未落地 | 多数已具体化 | 套话全替换为含事实/数据的具体表述 |
| 去咨询味 | 咨询黑话+口语词混杂 | 个别残留 | 基本干净 | 无咨询黑话、书面语体统一 |

**质量等级判定**（满分 18）：
- PASS（≥14）：可直接交付
- WARN（11-13）：可交付但建议小修
- MAJOR（7-10）：必须修订后交付
- REWRITE（<7）：建议重做

## 输出格式

通篇瘦身时：
```markdown
# 语言瘦身报告：[文稿名]
## 一、瘦身总览
- 总字数：原 ____ → 改后 ____（删字率 __%）
## 二、修改清单
| # | 原表述 | 问题类型 | 改后 | 依据 |
|---|---|---|---|---|
| 1 | 高度重视，提高认识 | 套话(空话) | 党政负责人任第一责任人，逐部门分解任务到岗 | CP-401/模块5 |
## 三、自评：__/18（等级）。仍需人工核：[待核术语/待补数据]
```

定向查词时：
```markdown
[原词] → [能用✓/不能用✗/有条件用△（条件）] → [替换：__] → [依据：规则号]
（套话另附：四问改写示范一句）
```

## 反模式

1. **空洞套话占位**
   - 怎么识别：『高度重视』『扎实推进』『进一步加强』后接不出任何具体对象、动作、数据
   - 怎么改：用「套话替换四问」补足『做了什么+什么结果』；补不出就退回补素材，绝不用另一句套话替换
2. **咨询黑话**
   - 怎么识别：『底层逻辑』『顶层架构』『三个维度』『三重力量驱动』『用一句话概括』
   - 怎么改：换行业惯用词（基本思路/整体架构），『N 个维度』直接拆『一是二是三是』——换词更要换句式
3. **搭配错误**
   - 怎么识别：『制定规划』『落实任务』『加强意识』『取得措施』『一项规划』
   - 怎么改：查 MM 表逐字纠（编制规划/完成任务/增强意识/采取措施/一个规划）
4. **堆砌近义词**
   - 怎么识别：『加强和提高』『不断加强和提高』『凝心聚力、真抓实干、攻坚克难、砥砺前行』连串四字格
   - 怎么改：同对象择一；四字格保留 1-2 个有支撑的，其余改具体描述
5. **口语词混入书面**
   - 怎么识别：书面材料里出现『搞好/弄清楚/挺好/老百姓/接下来/总的来说』
   - 怎么改：查口语转书面表替换；注意区分文种——讲话稿可留部分提顿口语，书面稿一律书面化
