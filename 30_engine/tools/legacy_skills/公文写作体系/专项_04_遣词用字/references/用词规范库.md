# 用词规范库——五张可查表（禁用词 / 搭配 / 套话 / 咨询味 / 口语词）

> 查法：先判类型（禁用？搭配？套话？咨询味？口语？），再到对应表里定位，按「替换 + 依据规则号」落地。
> 权威源以 `../../../../03_dictionary/official_terms_v2.yaml`（PW/MM/CP）与 `../../../../02_rules/language_style/`（LS/OTF）为准，本表是高频条目的速查精编。

## 表二：错误搭配对照表（对照 MM 模块）

### 2-A 动宾搭配（MM-301）

| 错误搭配 | 正确搭配 | 例 |
|---|---|---|
| 制定规划 | 编制规划 | 编制十五五规划 |
| 落实任务 | 完成任务 | 完成全年任务 |
| 加强意识 | 增强意识 | 增强安全意识 |
| 进行研究 | 开展研究 | 开展专题研究 |
| 取得进步 | 取得进展 | 工作取得新进展 |
| 建立成效 | 取得成效 | 工作取得成效 |
| 进行工作 | 开展工作 | 开展本项工作 |
| 强化管理 | 加强管理 | 加强队伍管理 |
| 推动发展 | 促进发展 | 促进产业发展 |
| 制定目标 | 确定目标 | 确定年度目标 |
| 取得措施 | 采取措施 | 采取有效措施 |
| 形成计划 | 制定计划 | 制定工作计划 |
| 进行通知 | 下达通知 | 下达专项通知 |
| 提高质量 | 提升质量 | 提升写作质量（质量搭『提升』，比例/速度搭『提高』）|

### 2-B 量词搭配（MM-302）

| 错误 | 正确 | 规律 |
|---|---|---|
| 一项规划 | 一个规划 | 规划用「个」 |
| 召开一个会议 | 召开一次会议 | 会议用「次」 |
| 进行一次改革 | 推进一项改革 | 改革用「项」 |
| 三项建议 | 三条建议 | 建议用「条」 |
| 一种措施 | 一项措施 | 措施用「项」 |
| 五份方案 | 五个方案 | 方案用「个」 |

### 2-C 并列搭配错误（对象不同不可并列）

| 错误 | 正确 | 说明 |
|---|---|---|
| 加强和提高（同对象） | 择一 | 同一对象不堆两动词 |
| 不断加强和提高 | 持续加强 / 不断深化 | 『加强』与『提高』对象不同，不宜并列（OTF-042）|
| 提高工作效率和质量 | 提高效率、提升质量 | 『质量』须搭『提升』（OTF-037）|

## 表三：套话 → 具体表述对照表（对照 CP 模块 + skill_style 第五节）

> 套话不是简单换词，须用「四问」（重视了什么？做了什么？到什么程度？什么结果？）补足事实。下表「改写方向」给的是落地公式，不是现成句。

### 3-A 空洞动词短语（须四问落地）

| 空套话 | 改写方向（补事实） |
|---|---|
| 高度重视 | 谁任第一责任人 + 建了什么机制 / 开了什么会 / 分解到什么岗 |
| 进一步加强 | 加强的对象 + 新增的措施 + 达到的标尺（覆盖率/完成率）|
| 扎实推进 | 推进了哪几项 + 进度节点 + 阶段成果数据 |
| 持续深化 | 深化前是什么状态 → 深化后变成什么状态（前后对比）|
| 切实提高 | 提高到什么数值 / 同比提升多少个百分点 |
| 充分发挥……作用 | 发挥在哪个环节 + 产生什么可量化效果 |
| 要高度重视、着力解决 | 直接接具体措施，不单独成段（OTF-043）|

### 3-B 开头 / 过渡套话（CP-401，可直接替换）

| 原套话 | 替换 |
|---|---|
| 当前形势发生了新变化 | 面对新变化、新形势 |
| 与此同时 | 同时 |
| 随着……的深入推进 | 在……推进中 |
| 为了进一步 | 为进一步 |
| 据了解 | 了解到 |
| 值得一提的是 | 需要指出的是 |
| 事实上 | 实际上 |
| 从某种意义上讲 | 从某种意义说 |
| 这充分说明 | 这充分表明 |
| 可以说 | 可以认为 / 由此可见 |

### 3-C 结尾套话（CP-402 + LS-042）

| 原套话 | 替换 |
|---|---|
| 以上汇报，如有不当之处，请批评指正 | 以上汇报，请审阅 |
| 如无不妥，请批示 | 以上请示，请批准 |
| 各部门要认真落实 | （与正文重复则删） |
| 敬请…… | 请…… |
| 切盼 | 期待 / 期望 |

## 表四：咨询味词替换表（对照 skill_style 第五节）

> 去咨询味的关键：不止换词，更要换「拆分句式」。『N 个维度』一律改成扁平的『一是/二是/三是』。

### 4-A 结构 / 标题黑话

| 咨询味 | 行业惯用 |
|---|---|
| 底层逻辑 | 基本思路 |
| 顶层架构 / 顶层设计 | 整体架构 |
| 核心框架 | 主要框架 |
| 顶层架构：六大核心业务的分类逻辑（冒号副标题）| 改烟草惯用一级标题格式（见 `专项_02_标题炼制`）|

### 4-B 拆分黑话（换词＋换句式）

| 咨询味 | 改法 |
|---|---|
| 三个维度 / 三个层面 / 三重力量共同驱动 | 直接『一是……二是……三是……』 |
| 核心价值体现在三个方面 | 『主要体现在：一是……二是……三是……』 |
| 从外部看……从内部看……从实践看…… | 删三维框架，直接列条 |

### 4-C 引导 / 总结黑话（多余，直接删）

| 咨询味 | 改法 |
|---|---|
| 用一句话概括：…… | 删引导语，直接表达 |
| 这正是我们建设这套体系的根本出发点 | 删（多余总结句）|
| 我们清醒认识到……既是……也是…… | 删反复铺垫，直接陈述问题 |
| 显而易见 / ……来看，应当 | 改为直接陈述事实 |

### 5-E 高频易错字（形近 / 音近）

| 错 | 对 |
|---|---|
| 布署 | 部署 |
| 即/既混用 | 既（已经）/ 即（就是）|
| 的/地/得混用 | 名词前『的』、动词形容词前『地』、谓语后『得』|
| 己/已混用 | 己（自己）/ 已（已经）|
| 未/末混用 | 未（没有）/ 末（最后）|
