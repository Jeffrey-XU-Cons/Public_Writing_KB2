## 零、框架设计前置：立意高度确认（消化 D-06 / MT-004 时·事·势）

**底层依据：** 框架搭多高，文章立意就多高。跳过立意直接排板块，生成的是「能用但不出彩」的平庸文稿。三个问题回答完毕再搭骨架，立意才不会在中途「塌陷」。

**开始搭框架之前，须先回答以下三题：**

**① 时——当前最新上级精神/政策是什么？**
写出 1–2 句：本文须贯彻/呼应的最新上级部署（精确到文件名或会议名）。
> 示例：「国家局推进企业管理提升三年行动，明确要求完善体系评价机制、持续开展有效性评价。」

**② 事——本文核心工作的现状、问题、本质是什么？**
写出 3–5 句：核心工作做了什么、卡在哪、本质矛盾是什么。
> 示例：「公司已建成2977条评价条款，覆盖42个能力域；核心问题是如何让条款从纸面走进卷烟厂和业务部门的实际管理动作；本质是从'有标准'到'用标准'的转化。」

**③ 势——本文论断是否顺应当前行业/公司发展方向？**
确认一句：本文的核心判断与当前趋势一致（不违背政策导向、不与已定战略相悖）。
> 示例：「管理成熟度评价体系与'奋进一流'战略、管理效能攻坚方向完全一致，符合行业'精细化管理'趋势。」

**三题回答完毕后，再进入框架设计。** 若某题回答不出来，说明素材准备不足，须补充后再开始。

## 一、框架设计的核心原则

### 原则一：结论先行
每个部分的第一句必须是核心结论，而不是背景铺垫。
- ❌ 「自2022年管理体系优化提升专项行动启动以来，公司上下认真贯彻落实……」（背景铺垫）
- ✅ 「两年来，管理提升工作历程艰辛，成绩来之不易，主要呈现以下特点。」（结论先行）

### 原则二：同级MECE
同一层级的内容必须相互独立、完全穷尽，不重叠不遗漏。
检查方式：把同级标题单独列出，判断：
- 是否有内容交叉（如「成效显著」和「指标完成符合预期」有重叠）
- 是否有遗漏（对照任务清单，是否所有工作板块都覆盖到）

### 原则三：意思不流窜
每个论点、每个数据、每个成效，在全文只在一个地方出现。
检查方式：在框架阶段就做「意思分布表」，标注每个核心论点只能出现的位置。

### 原则四：层级递进明确
相邻层级之间必须是包含关系，同层级之间必须是并列关系。
- 一级标题是「总体判断」
- 二级标题是「支撑一级的具体方面」
- 正文是「支撑二级标题的事实和数据」

### 原则五：用核心观点统率全文

**底层依据：** 毛泽东「人的头脑是加工厂，没有材料不行，有了材料要经过加工，要产生观点，用观点统率材料。」好公文不是堆数据、排板块，是用一个核心判断把所有素材组织起来。

**操作要求：** 在搭骨架之前，先用一句话写出全文的「主旨句」——这句话不是标题，是判断。骨架里的每一部分、每一个数据，都必须能说出它是「为这个主旨句服务的哪一面」。不能服务的内容须删除或调整。

**主旨句格式：**

```
[时间段] + [主体] + 在[工作领域]方面 + [取得/面临][什么判断] + ，[核心数据/事实印证]
```

**示例：**

- ✅ 「2025 年以来，公司在管理成熟度评价体系建设上完成了从概念到 2977 条评价条款的落地，构建了行业首套'六大业务+综合管理+卷烟厂'分层评价体系。」（主体明确，判断鲜明，数据印证）
- ✅ 「过去一年，全市烟草在烟叶规模跌至冰点的压力下，通过精益管理把上等烟比例从 50.6% 提升到 60.42%，走出了一条'小而精、特而优'的发展路径。」（含挑战、含动作、含成效）
- ❌ 「2025 年管理成熟度评价工作取得显著成效。」（无判断、无数据、可移植到任何单位）
- ❌ 「全市烟草高质量发展迈上新台阶。」（套话，未提炼具体判断）

**主旨句的三项检验：**

1. **可证伪性**——这句话有没有可能是假的？如果换个单位、换个时段就成立，说明没有提炼出本文专属的判断。
2. **统率性**——骨架里的每个分板块，能否回答"这一段是为主旨句的哪一面服务的"？回答不上来，说明该板块与主旨脱节，须删除或重组。
3. **数据锚**——主旨句中是否含至少一个具体数据或事实锚点？纯定性判断（"成效显著""扎实推进"）不合格。

**主旨句与标题的关系：**

主旨句是写给自己看的"靶心"，不直接出现在文稿里；文稿的主标题、开篇定性句、结尾呼应句，都应该是主旨句的不同表达版本。三处加起来形成全文的"主旨闭环"——开篇定调、正文支撑、结尾回应，读者读完能从三个位置感受到同一个核心判断。

### 原则六：排列顺序与内容性质匹配（消化 C-02 / SP-008）

**底层依据：** 排列顺序不是任意的——用错顺序会让读者感到「这几条为什么这样排？」，打断阅读节奏。内容性质决定排列逻辑，不能反过来。

**三种排列逻辑及适用内容：**

| 内容性质 | 对应排列顺序 | 错误用法示例 |
|---------|------------|------------|
| 工作进展 / 历史回顾 / 阶段推进 | **时间顺序**（过去→现在→未来） | ❌ 先说「2026年计划」再说「2024年启动」 |
| 成效汇报 / 工作板块并列 | **重要性顺序**（最重要的先说） | ❌ 把边缘工作放第一条，核心成效放最后 |
| 问题分析 / 原因阐述 / 下步部署 | **意义顺序**（原因→结果；问题→措施；主→次） | ❌ 先讲措施后讲问题，读者不知道为何要这样做 |

**检查步骤：**
1. 对每个并列板块（一是/二是/三是，或（一）（二）（三））判断其内容性质
2. 确认所选排列顺序与内容性质匹配
3. **同一层级内不得混用不同排序逻辑**（如前三条按重要性排，第四条突然按时间排）

## 二、不同文种的框架模板

### 工作会议讲话框架（三段式）

```
【第一部分标题格式】：「充分肯定/全面总结+工作领域+成效定性」
核心论点：过去一段时间工作做得怎么样（总体肯定+指出不足）
段落数：1个总体概述段 + 3-5个分板块 + 1个问题段
每个分板块：有对仗小标题 + 总分结构 + 数据支撑

【第二部分标题格式】：「准确把握形势/深刻认识意义+动员性结语」
核心论点：为什么要做这件事（形势分析或重要性阐述）
段落数：1个总体判断段 + 2-4个分析角度
每个角度：先引用上级指示，再结合本单位实际展开

【第三部分标题格式】：「锚定目标任务/全力推进+年度重点工作」
核心论点：接下来要怎么做（年度部署，有量化目标）
段落数：1个总体要求段（含量化目标） + 3-6项重点工作
每项重点工作：「一要/二要/三要」格式，含时间节点和量化目标
```

### 工作报告框架

```
【开篇概述】：总体评价（一句话定性）+ 核心数据（3-5个）
字数：200-300字

【主要工作板块】（4-8个板块并列）
每个板块格式：
  小标题：「（X）坚持[做法]，有力[成效判断]」
  内容：聚焦什么+一是/二是/三是+每条有数据
字数：每板块400-700字

【存在问题】（3-5条）
格式：「一是[问题]，[一句话表述]。二是……」
字数：200-400字，不展开分析

【下步安排】（3-5条）
格式：每条有量化目标和时间节点
字数：300-500字
```

### 专题汇报框架

```
【背景与定位】（约300-500字）
- 政策背景（为什么要做）
- 问题背景（现有工具的局限）
- 建设定位（这件事解决什么问题）

【核心内容】（约1500-3000字，2-4个部分）
- 各部分有独立标题
- 每部分内部用「一是/二是/三是」分条
- 每条有具体数据或举措

【推进情况与成果】（约800-1500字）
- 推进机制（怎么组织的）
- 阶段成果（做了什么，有多少）
- 数据要完整（不能只说「建成了X个」，要有对比说明）

【存在问题】（约300-500字）
- 直接列举，不过度分析原因

【下步工作】（约500-800字）
- 时间节点+量化目标+标志性成果
```

## 三、句级框架设计方法

框架设计必须细到每段的每一句，以及句间衔接逻辑。

### 句级框架格式

```
（一）[小标题]（本段核心论点：XXX）
  第1句：[作用标注]——[具体内容方向]
  第2句：[作用标注]——[具体内容方向]
  衔接词：「在此基础上」「由此带来」「与此同时」「不仅如此」
  第3句：[作用标注]——[具体内容方向]
```

### 常用句间衔接逻辑

**递进关系（层层加深）：**
「不仅……更……」「在此基础上……」「进一步……」

**因果关系（原因→结果）：**
「正是因为……所以……」「由于……从而……」「这一举措带来……」

**转折关系（成绩→问题）：**
「在肯定成绩的同时，我们也清醒地看到……」
「成绩来之不易，但也要看到……」

**并列关系（同等重要）：**
「一是……二是……三是……」
「既……也……」「不仅……还……」

**总分关系（总述→分条）：**
「主要呈现以下特点」「具体体现在三个方面」「重点做好以下工作」

### 工作部署段的三元逻辑检查（消化 D-02 / BG-013）

**底层依据：** 所有机关公文在段落层面都离不开「是什么·为什么·怎么办」三元结构。纯措施堆砌（只有「怎么办」）让读者不知道为何重要；纯重要性铺垫（只有「为什么」）让读者不知道怎么行动。两者缺一，段落说服力减半。

**三元定义：**
- **①是什么**：本项工作的内容界定（做的是什么、针对什么问题）
- **②为什么**：本项工作的重要性或紧迫性（不做会怎样、做了有何价值）
- **③怎么办**：具体措施、时间节点、量化目标（谁来做、怎么做、做到什么程度）

**三元配比要求：**

| 段落类型 | 必须包含 | 最低标准 |
|---------|---------|---------|
| 工作部署段（一要/二要/三要） | ②+③ | 重要性1句 + 措施≥2句（含时间/量化目标） |
| 问题分析段 | ①+② | 说清是什么问题 + 说清危害/原因 |
| 工作总结段 | ①+③ | 说清做了什么 + 说清结果/数据 |

**常见缺陷与修复：**
- **纯措施段**（只有③）→ 在首句补充「为什么要做这项工作」（1句重要性说明）
- **纯方向段**（只有②）→ 在重要性阐述后补充「具体路径」（措施+时间+目标）

**示例：**
```
❌ 纯措施段（缺②）：
「一要加快推进评价标准修订。由企管部门牵头，各业务组于7月底前完成三级特征描述的修订，确保等级台阶感清晰可辨。」
（知道怎么做，但不知道为什么急）

✅ 补充②后：
「一要加快推进评价标准修订。当前三级与四级的特征描述区分度不足，直接影响评价结论的说服力和被评价方的接受度——这是本次专家评审最集中的意见，必须在正式发布前解决。由企管部门牵头，各业务组于7月底前完成修订，确保相邻等级台阶感清晰可辨。」
```

## 四、框架完成后的自查清单

在展开全文之前，对照以下清单逐项检查：

```
主旨检查（先做）：
□ 是否已提炼出一句话主旨句，且通过三项检验（可证伪性 / 统率性 / 数据锚）
□ 骨架里每个一级板块能否回答「我在为主旨句的哪一面服务」
□ 主旨句的核心判断词是否会在开篇定性句、结尾呼应句中各出现一次（主旨闭环）

结构检查：
□ 一级标题是否符合烟草系统标题格式（动词领起+判断句）
□ 同级标题是否MECE（相互独立，完全穷尽）
□ 各部分字数分配是否合理（核心内容占比60%以上）
□ 层级归属验证（消化 B-5 / SP-006 扣紧主题原则）：将一级标题和其下所有二级标题列成树状图，逐个判断：「该二级标题的内容，是否完全归属于一级标题所指定的工作范畴？」
  - 若可以归属：关系成立
  - 若更接近其他一级标题的范畴：须重新归属，或调整一级标题表述
  - 典型问题：「加强组织领导」下放了「完善资金保障机制」→ 后者应归入「强化保障措施」而非「组织领导」

创新点标注（消化 D-05 / SP-002）：
□ 与同类历史文稿相比，本次框架的创新点是什么？框架输出后须额外标注：
  - 新提法：[首次使用/首次系统阐述的表述，或本文独有的核心概念]
  - 新数据：[本期新增的最新数据，上次文稿未有]
  - 新举措：[本期新增的工作机制/方法/路径]
□ 若三项均无创新，须说明原因，并考虑是否调整框架角度——无创新的框架生成的是同质化内容，读者阅读价值低

论点检查：
□ 每个部分的核心论点是否唯一（不与其他部分重叠）
□ 意思分布表是否完整（每个核心论点只在一处出现）
□ 是否有「结论先行」（每部分第一句是结论，不是背景）
□ 论从事出验证（消化 A-4 / LR-008）：每个一级、二级标题下的核心结论句，是否有至少2个具体事实或数据作为落点支撑？验证方法：遮住结论句，只看支撑段，读者能否自然得出同一个结论？不能则说明结论与支撑材料脱节，须补充具体事实落点或修改结论句，使二者精确对称。
□ 核心论点二元检查——措施+成效（消化 D-13 / LR-005）：每个一级标题的核心论点（该部分的中心判断），是否同时包含「路径/做法」和「成效/结果」两个维度？
  - 只有成效（「取得了……成效」）而无路径 → 在正文首段补充关键举措（1-2句）
  - 只有举措（「坚持……工作」）而无成效判断 → 在标题或首句中补充成效结论（含数据）
  - 示例：
    ❌ 「（一）管理体系建设取得重要进展」（只有成效，无路径）
    ❌ 「（一）坚持推进管理成熟度评价工作」（只有路径，无成效判断）
    ✅ 「（一）深化管理成熟度评价体系建设，核心指标达标率提升至行业前三」（路径+成效双维）

数据检查：
□ 成效部分是否有量化数据规划（框架阶段就要标注需要哪些数据）
□ 数据是否有对比基准（同比/目标完成率/行业对比）
□ 全文数据是否在框架中明确了统计口径

逻辑检查：
□ 句间衔接逻辑是否标注（每段的句间关系是否明确）
□ 段间过渡是否自然（每个二级标题之后是否需要过渡句）
□ 问题部分与下步部署是否一一对应
```
