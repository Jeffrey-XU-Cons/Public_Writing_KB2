# terms.jsonl 说明（T1 定义 + T2 搭配）

> P2.4（11 章）产出，2026-09-25。工具 `30_engine/tools/t2_collocation.py`，测试 `40_tests/kb_ingest/test_t2_collocation.py`。
> 这是 07 章 §2.3 设计的统一词典 `terms.jsonl` 的**第一版**：390 条 legacy 术语，T1 定义沿用 legacy，
> T2 搭配由语料统计生成；T3（分寸）/T4（辨析）留空，待后续阶段。

## 结果

| 指标 | 值 |
|---|---|
| 术语 | 390 条（5 个 legacy YAML 共 398 条，去重后 390，与 CLAUDE.md 口径一致） |
| 统计语料 | 3,009 份 = raw_materials 3,118 − 提示词模板库 − P2.2 清单里的空壳和重复副本 |
| 语料中出现过 | 293 条（75%） |
| 有 T2 搭配 | 173 条 |
| 不同搭配词 | 419 个，**逐个人工核过** |

**覆盖率 75% vs 07 章记录的 58%**：07 章是在 378 万字语料上测的，这次是全量约 3,300 万字，语料大 9 倍，覆盖率上升合理。
没出现的 97 条多是 legacy 词典里"造出来的"提法（07 章 §2.1 已指出"164 条是造出来的，语料里没人这么说"），P2.5 筛候选词时一并考虑是否剔除。

## 跑前查了什么（按"先看已有能不能用"）

- 07 章那份"1,242 候选"的词频数据当时没存下来，没有现成的词频/共现文件可复用。
- Kb-RAG `tools/query_terms.py` 有一条"不引入 jieba"的 ADR，理由是"jieba 需预下载语言模型"——**这个理由不成立**：jieba 词典随包自带，装完离线即用。且那条 ADR 管的是在线查询依赖，本工具是离线批处理，jieba 不进检索链路，不冲突。Kb-RAG 的"双字滑窗"切不出长短不一的搭配词，不适合做 T2。

## 三轮迭代

| 轮 | 抽查发现 | 修复 |
|---|---|---|
| 1 | 前接混入数量词（五家、各个）、介词（关于、根据）、泛化机构名（公司、有限公司）、轻动词（进行、提供） | 停用表 + 数量短语正则 |
| 2 | 想用 jieba 词性做白名单，结果"深化"被标成缩略语 j、"全面""规范"标成名词，好词被误杀 | 改成只剔除明确虚词类（数词/量词/介词/代词/连词）的反向过滤 |
| 3 | 搭配里出现**"某表外地名"**——"某地物流中心"是具体单位，地名表没有、jieba 也没识别成地名 | ①加"至少出现在 5 份不同文件"的门槛；②门槛仍没拦住（该地材料分散在 5 份以上），补全国地级市进脱敏工具的共用地名表 |

## 安全设计

- 07 章样例里的"典型例句"如果从原文抽，会把单位名、数据原样带出，等于绕过脱敏闸。本版改为 **`典型搭配`**：用 top 前接 + 术语 + top 后接拼成短语，不抽原句。**字段名与 07 章样例不同是有意的。**
- 搭配词过三道滤：脱敏工具的地名/单位规则、jieba 人名/地名/机构名标注、跨文件门槛；最后人工全量过目。

- 跨文件门槛 `MIN_DOCS=5` 让有搭配的术语从 220 条降到 173 条，是用覆盖面换安全，有意为之。

### 候选怎么算、口径是否可信

相邻 2–3 个实词拼成 4–8 字的词组，频次≥60、词典未收 → **9,859 个候选**。
与 07 章样例比：卷烟营销 1047→6772、精益管理 989→10533、管理诊断 852→6863、现代终端 423→2375，平均放大约 7.7 倍，
和语料放大约 9 倍（378 万字→3,300 万字）一致，说明方法与当年大体相同。候选数远多于 1,242，同样是语料变大的结果。

### 入库门槛（11 章§五③拍板）+ 人工复核后补的结构过滤

门槛：频次≥100、含行业词根、≥5 份文件、非地名单位人名 → 首跑 439 个。人工逐个看后，归纳出四类不是词条的东西：

1. 动词+术语：推进精益、提升卷烟营销、导入精益管理——这是 T2 搭配，不是新词
2. 范围修饰+术语：全省烟草、省外卷烟、五家卷烟厂
3. "X工作/X水平"：卷烟营销工作、精益管理水平
4. 碎片与公司全称残片：卷烟非法（原词"卷烟非法流通"）、**烟草物流有限责任**

加规则后 **291 个入库**，略低于 07 章预估的 300–500。宁可少收，不让"动词+术语"混进 T1。

### 新增词条的 T1 定义全部留空

291 条 `t1_definition` 为空。定义要人或 LLM 写，**不能从语料统计里编**（CLAUDE.md §4.1）。T2 搭配照常生成。

### 覆盖率 86% 要打折看

"语料中出现 583/681 = 86%"数字上达到 07 章 85% 的目标，但新增 291 条是从语料里挑出来的，必然全部出现，这个提升是构造出来的。
真正有信息量的是：**老词典 390 条里有 97 条在 3,300 万字中一次都没出现**，大概率是 07 章 §2.1 说的"造出来的提法"，待定是否剔除。

### 新增搭配词复核

新词条带来 405 个新搭配词，逐个过目，抓出 3 个：**梵净山**（贵州地标）、**粤桂**（两省合称）、**有限责任**（公司全称残片）。前两个补进脱敏工具共用地名表，第三个进停用表。复核后搭配词共 837 个，无残留。

## P2.5 收尾（2026-10-07）：新增词 T1 定义草稿 + 零频老词去留建议

Claude 受 Jeffrey 授权自主推进（`30_engine/runs/2026-10-07_自主推进决策日志.md` D-10）。工具 `30_engine/tools/t1_contexts.py`，测试 `40_tests/kb_ingest/test_t1_contexts.py`。

### 做法

1. **先取证，再写定义**。`t1_contexts.py --missing` 对 291 个空定义词逐个到语料取上下文：r10 脱敏批次 + `20_knowledge/corpus/`（含 `chunks_full.jsonl` 等切块文件的 `text` 字段），跳过不外流清单 4 份；每词每文件最多取一段，优先取“是指／即／包括”这类定义句；片段过 `deidentify` 再输出。纯标准库，两机可跑，全量约 20 秒。片段只供人工核对，不入库。
2. **按语料用法写**，1—3 句、40—120 字，说清“是什么、在烟草行业里指什么”，不带单位名、人名、数据。语料里的规范定义（如行业标准里的“现代卷烟零售终端”“卷烟非法流通”）照其口径概括，不照抄原句。
3. **语料撑不起定义的留空**，写 `t1_note`（以“语料不足：”开头）。判据：该词在语料里多半只是更长提法的截断（“现代卷烟零售”98% 后接“终端”，“卷烟品牌精准”98% 后接“营销”），或是具体机构、公司名称的一部分，或用例太少。截断比例用临时统计核过。
4. **写回走同一个脚本**：`t1_contexts.py --apply 定义.tsv --notes 备注.tsv`。只填 `kind=术语` 且定义为空的行；已有定义一律拒写；每条草稿先过 `validate_definition()`（长度、弯引号、无数字、`deidentify` 无改动），一条不过整批不写。

### 结果

| 项 | 数 |
|---|---|
| 写入 T1 草稿 | 262 条，加 `t1_status: "draft"`、`t1_source: "语料归纳（2026-10-07，未经人工审）"` |
| 留空并写 `t1_note` | 29 条（更长提法的截断或切分 21、偶然连用或表格栏目 2、机构或公司名 3、用例过少 3，详见各行 `t1_note`） |
| 原有 390 条定义 | 一个字未动（逐字段比对：只有上述 3 个字段有变化） |
| `terms.jsonl` 行数 | 765 不变（术语 681 + 官方规则 84） |

允许出现的数字只有方法名里的 A3、5S、6S、7S，校验器白名单写死。

**草稿怎么用**：写作链路查到 `t1_status=draft` 的定义，只能当参考，不能当权威口径引用。Jeffrey 审过一条，把那一行的 `t1_status` 改成 `reviewed`（或删掉该字段）即可；不同意的直接清空定义，留着 `t1_note` 说明原因。整体回退：删掉所有 `t1_status=draft` 行的定义和这两个字段。

### 97 条零频老词

只出建议，没改任何 `status`，见 `老词去留建议_20261007.md`：保留 1、并入 15、剔除 81。97 条里管理成熟度框架的能力域、子域标签 45 条，“十五五”规划术语 30 条，零频的原因在词典造词，不在语料。

### 注意

- **重跑 `t2_collocation.py` 会冲掉这批草稿**：它从 legacy YAML 和 `candidates_accepted.jsonl` 整体重建 `terms.jsonl`，新增词的定义按设计写空，`t1_status`／`t1_source`／`t1_note` 也不会保留。以后要重算 T2，先改 `t2_collocation.py` 让它保留已有 T1 字段，或重算后再跑一次 `--apply`。
- `t1_contexts.py` 输出的片段来自未脱敏的 `20_knowledge/corpus/`，虽然过了 `deidentify`，规则外的地名和人名仍可能漏掉（实测有县区名、街道名和名单里的人名漏网）。片段不要外流，也不要存进同步目录。

### 核查记录（2026-10-07，独立核查）

按决策日志 D-12，由未参与起草的核查代理反向找错，修正就地做。

**抽查了什么**

- **定义与语料用法**：用 `t1_contexts.py --term` 取 67 个草稿词的语料上下文逐条对读，优先抽高风险词（低频词、地方性终端分类、“X发展”“X经营”这类组合词、带“包括/四个/四大”等列举的定义），另把 262 条草稿全文过目一遍，专找循环定义和空话。
- **脱敏与数据**：262 条草稿和 34 条 `t1_note` 全量用正则扫省市名、卷烟品牌、咨询机构名、阿拉伯数字、带量词的中文数字，再逐条过 `deidentify`。命中的只有 A3、5S 这类方法名，以及“一类卷烟”“四个方面”这类分类或列举（“烟叶质量包括外观质量、物理特性、化学成分、感官质量”与语料里的企业标准术语条一致）。无单位名、人名、地名、品牌、经营数据。
- **原有定义未动**：从 legacy 5 个 YAML 重新读出 390 条定义，与 `terms.jsonl` 中 `in_dict_before=true` 的行逐字比对，0 处差异；旧词无一行带 `t1_status`；291 条新词里有定义的都标了 draft，空定义的都带 `t1_note`。
- **老词去留建议**：97 个词与 `terms.jsonl` 零频老词集合一一对上，保留 1／并入 15／剔除 81 与表格逐行计数一致。抽 32 个近义说法重算“本次语料”次数和处数，32 个全部与文中一致；“原口径”次数用 `10_source/raw_materials` 子串粗算，量级一致（差 0—2%，原口径另剔除了提示词库和空壳，粗算没剔）。抽 24 个“已在词典／需新增”的说法到 `terms.jsonl` 核对，23 个标注正确。
