## 零、框架设计前置：立意高度确认（D-06 / MT-004 时·事·势）

框架搭多高，文章立意就多高。跳过立意直接排板块，生成的是「能用但不出彩」的平庸文稿。

**开始搭框架之前，须先回答以下三题：**

**① 时——当前最新上级精神/政策是什么？**
写出 1–2 句：本文须贯彻/呼应的最新上级部署（精确到文件名或会议名）。

**② 事——本文核心工作的现状、问题、本质是什么？**
写出 3–5 句：核心工作做了什么、卡在哪、本质矛盾是什么。

**③ 势——本文论断是否顺应当前行业/公司发展方向？**
确认一句：本文的核心判断与当前趋势一致（不违背政策导向、不与已定战略相悖）。

三题回答完毕后，再进入框架设计。若某题回答不出来，说明素材准备不足，须补充后再开始。

## 一、框架设计的核心原则

### 原则一：结论先行
每个部分的第一句必须是核心结论，而不是背景铺垫。
- ❌ 「自2022年管理体系优化提升专项行动启动以来，公司上下认真贯彻落实……」（背景铺垫）
- ✅ 「两年来，管理提升工作历程艰辛，成绩来之不易，主要呈现以下特点。」（结论先行）

### 原则二：同级MECE
同一层级的内容必须相互独立、完全穷尽，不重叠不遗漏。

### 原则三：意思不流窜
每个论点、每个数据、每个成效，在全文只在一个地方出现。

### 原则四：层级递进明确
相邻层级之间必须是包含关系，同层级之间必须是并列关系。

### 原则五：用核心观点统率全文

**操作要求：** 在搭骨架之前，先用一句话写出全文的「主旨句」。骨架里的每一部分、每一个数据，都必须能说出它是「为这个主旨句服务的哪一面」。

**主旨句格式：**
`[时间段] + [主体] + 在[工作领域]方面 + [取得/面临][什么判断] + ，[核心数据/事实印证]`

**主旨句三项检验：**
1. **可证伪性**——换个单位、换个时段就成立的，不合格
2. **统率性**——每个分板块能否回答「我在为主旨句的哪一面服务」
3. **数据锚**——含至少一个具体数据或事实锚点

### 原则六：排列顺序与内容性质匹配（C-02）

| 内容性质 | 对应排列顺序 |
|---------|------------|
| 工作进展 / 历史回顾 | 时间顺序（过去→现在→未来） |
| 成效汇报 / 板块并列 | 重要性顺序（最重要的先说） |
| 问题分析 / 原因阐述 | 意义顺序（原因→结果；问题→措施） |

同一层级内不得混用不同排序逻辑。

## 二、不同文种的框架模板

### 工作会议讲话框架（三段式）
- 第一部分：总结工作成效（总体肯定+分板块+问题段）
- 第二部分：分析形势任务（总判断+2-4个角度）
- 第三部分：部署重点工作（总体要求+3-6项，含量化目标）

### 工作报告框架
- 开篇概述：200-300字
- 主要工作板块：每板块400-700字
- 存在问题：200-400字
- 下步安排：300-500字

### 专题汇报框架
- 背景与定位（300-500字）
- 核心内容（1500-3000字）
- 推进情况与成果（800-1500字）
- 存在问题（300-500字）
- 下步工作（500-800字）

## 三、句级框架设计方法

### 工作部署段的三元逻辑（D-02）

| 段落类型 | 必须包含 | 最低标准 |
|---------|---------|---------|
| 工作部署段（一要/二要/三要） | ②为什么+③怎么办 | 重要性1句 + 措施≥2句 |
| 问题分析段 | ①是什么+②为什么 | 说清问题 + 说清危害/原因 |
| 工作总结段 | ①是什么+③怎么办 | 说清做了什么 + 说清结果/数据 |

## 四、框架完成后的自查清单

```
主旨检查：
□ 已提炼主旨句，通过三项检验（可证伪性/统率性/数据锚）
□ 每个一级板块能回答「为主旨句的哪一面服务」
□ 主旨句核心判断词在开篇定性句、结尾呼应句各出现一次（主旨闭环）

结构检查：
□ 一级标题符合烟草系统格式（动词领起+判断句）
□ 同级标题MECE
□ 核心内容占比60%以上

创新点标注（D-05）：
□ 新提法：[首次使用的核心概念]
□ 新数据：[本期最新数据]
□ 新举措：[本期新增工作机制]
□ 若三项均无，须说明原因并考虑调整框架角度

论点检查：
□ 每部分核心论点唯一（不与其他部分重叠）
□ 结论先行（每部分第一句是结论）
□ 论从事出验证（A-4）：遮住结论句，只看支撑段，读者能否自然得出同一结论？

数据检查：
□ 成效部分有量化数据规划
□ 数据有对比基准（同比/目标完成率/行业对比）

逻辑检查：
□ 句间衔接逻辑已标注
□ 问题部分与下步部署一一对应
```

## 一、意思不流窜检查

同一个论点、同一块内容、同一个数据，在文章里出现超过一次即为流窜。

**检查方法：** 建立「论点地图」，标注每个核心论点只能出现的位置，全文完成后逐条核查。

---

## 二、逻辑层次检查

### MECE检查（同级内容）
将同级标题单独列出，逐对判断是否有内容交叉、是否有遗漏。

**层级归属验证——上下位概念并列识别（C-06）**

「任意两条互换测试」：对并列 N 个条目，逐对检查 A 是否是 B 的下位概念。若存在包含关系 → 层级混乱，须修复。

- ❌ 「一是党建引领；二是支部标准化建设；三是发展党员。」（后两项是第一项的下位概念）

### 总分数量精确对应检查（C-07）

**触发条件：** 文中出现「主要体现在X个方面」「重点做好X项工作」等数字化总括句时，须核查：
1. 下文分项数与总括数字严格相等
2. 每个分项语义与总括描述匹配
3. 无遗漏无多余

### 递进关系检查（上下级内容）
- 二级标题内容是否完全属于一级标题的范畴？
- 有无「跨级」描述？

### 结构比例检查（C-05）

**工作汇报/工作报告类文体：**

| 板块 | 占全文字数 |
|------|-----------|
| 成效/主要工作 | **40%–55%** |
| 问题/不足 | **10%–20%** |
| 下步打算/工作部署 | **25%–40%** |

注：仅适用于工作汇报/工作报告，不适用实施方案、讲话稿。

### 标题-内容对应性检查（B-1）

**双向验证：**
- 正向：标题核心词 → 正文内容是否均在其语义范畴内
- 反向：正文每句 → 确认归属哪个标题范畴，有无跑题

### 文种-内容侧重点检查（C-04）

| 文种 | 主导要素 | 内容比例要求 |
|------|---------|------------|
| 工作汇报/工作报告 | 果（成效+数据） | 「果」≥50%；「法」≤30% |
| 实施方案/工作方案 | 法（措施+时间节点） | 「法」≥60% |
| 专题分析/调研报告 | 因（原因分析） | 至少分析到第二层原因 |
| 发展规划/三年计划 | 类+法 | 目标分层+对应路径 |

## 三、烟草行业规范检查

### 政治表述顺序
习近平新时代中国特色社会主义思想 → 党的XX大精神 → 中央经济工作会议 → 全国烟草工作会议 → 省委省政府要求 → 国家局党组部署

### 公文格式
- 标题层级：一、→（一）→ 1. →（1），不得跳级，不得混用
- 百分数用阿拉伯数字；时间节点必须精确到月份

## 四、数据质量检查

### 必须有对比基准
每个数据必须说明对比基准（同比/目标完成率/行业排名）。

### 程度副词须有数字印证（A-2）

**高风险词表（出现即触发检查）：**
大幅、显著、明显、翻倍、跃升、大力、快速、有效、全面、大幅提升、显著改善

**检查：** 后3句内是否有具体数字支撑。无数字 → 补充数字或删除程度副词。

## 五、完成后通读检查

### 段头撮要检查（C-03/A-6）
只读所有段落首句——能否还原全文完整逻辑主线？段首句必须是判断句，不得是背景描述或过程描述。

### 单句信息量检查（A-3）
零信息句三特征：①重申型 ②过程型 ③可压缩型。执行「删除测试」——删掉后信息量不减少 → 删除。

### 文气通顺检查（D-04）
标记三类中断点：话题跳跃点 / 节奏断点（连续3句字数相近）/ 逻辑空白点。全文中断点清零为达标。

### 句法完整性检查（A-5）

| 句式模式 | 修复方法 |
|---------|---------|
| 「通过……，[提高/实现]……」 | 补充明确主语 |
| 「经过……，[取得/形成]……」 | 同上 |
| 「在……情况下，[省略主语]……」 | 确认是否可省略，不可省时补全 |

### 措施句完整性检查（A-1）

合格措施句须同时含：①责任主体 ②具体事项 ③时间节点或量化目标

格式：`[责任主体]于[时间节点]前完成[具体事项]，确保[量化目标]。`

### 首尾呼应检查（C-01）
摘出开篇核心定性句 + 结尾号召句，比对是否出现相同主题词或核心判断词。禁止使用可移植到任何文章的通用结尾。

### 套话可移植性测试（C-12）
将每段的单位名称、数字、具体事项替换为其他单位信息，若替换后仍成立 → 套话，须改写。
每段至少含一个「不可替换信息」（具体数字/专属事件/具体部门+具体行为）。

### 论从事出验证（A-4）
遮住结论句，只看支撑段，读者能否自然得出同一结论？不能 → 结论与支撑材料脱节，须补充落点。

## 一、开场格式规范

### 工作会议讲话开场（固定格式）
```
同志们：

今天[会议名称]的主要任务是，[动词][上级文件/部署]，[动词][具体事项]。下面，我讲[X]点意见。
```
禁止：称谓后加「大家好！」/ 感性铺垫 / 形势分析 / 超过200字

### 工作报告/专题汇报开场
```
[称谓]：[简短汇报背景1-2句]，[我代表XXX，就XX工作情况作一次汇报]。
```

## 二、标题格式规范

### 标题必须是结论句，不是话题句（B-6）

| 维度 | 话题句（❌） | 结论句（✅） |
|---|---|---|
| 给读者的信息 | 该段在谈什么 | 该段的核心判断 |
| 可证伪性 | 不可证伪 | 可证伪 |

典型对比：
- ❌ 「效能攻坚工作推进情况」 → ✅ 「效能攻坚整体进展顺利，指标完成率达85.7%」
- ❌ 「存在的问题」 → ✅ 「品牌大而不强的状况尚未根本改变」

### 标题与正文首句呼应（B-3）
正文首句必须包含标题的核心动词或核心名词，形成「主题词锚定」。

## 三、正文展开逻辑

### 工作成效段标准写法
```
[总体定性句，含核心数据]。
一是[成效名称]。[具体举措]+[数据支撑，必须有同比对比]。
二是……三是……
```
禁止：只有定性没有数字 / 数字没有对比基准 / 「从外部看……从内部看……」三维分析框架

### 【进阶写法】观点提炼级（D-08）
在总体定性句后，加一句规律性判断：
```
[总体定性句]。[实践证明/这说明]，[规律性判断（揭示机制，不重复数据）]。
```
规律性判断四项标准：鲜明 / 深刻 / 新颖 / 实用。全文2-3个重点板块使用，其余保持基础写法。

### 工作部署段标准写法
```
[总体要求，含量化目标]。
一要[动词+工作方向]。[具体要求，含时间节点和量化目标]。
```

## 四、禁用表述清单

### 禁用的咨询报告风格
「三重力量共同驱动」「底层逻辑」「顶层架构」「用一句话概括」「这正是……的根本出发点」

### 禁用的空洞套话（须替换为具体表述）
「高度重视」「进一步加强」「扎实推进」「持续深化」「切实提高」

## 五、禁用表述清单（数据密度）
- 工作成效段：每个条目至少含1个数据
- 数据必须含对比基准
- 全文数据口径必须统一

## 六、讲话稿 vs 汇报材料语体差异（D-09）

| 维度 | 讲话稿 | 汇报材料 |
|---|---|---|
| 句长上限 | ≤20字/句 | 25-40字/句 |
| 排比/对仗 | 多用 | 适度 |
| 数据呈现 | 口头化（约86%/将近三千条） | 精确数字含对比基准 |
| 提顿词 | 必须（同志们/下面/要特别注意） | 删除，改书面过渡语 |

---

## 七、讲话稿生动性与鼓动性（D-15）

**生动性：** 全文至少1处形象化表述（比喻/典故/身边案例）

**鼓动性三步：**
1. 明确听众身份
2. 找出听众关切
3. 把号召语锚定到听众关切（把「我们」换成具体听众群体，仍贴切 → 合格）

**通俗性：** 选1-2个关键数据用「相当于……」比较句辅助理解
