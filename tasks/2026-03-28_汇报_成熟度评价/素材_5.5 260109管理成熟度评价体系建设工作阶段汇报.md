# 管理成熟度评价体系建设工作阶段汇报

 

深入贯彻国家局管理提升三年行动工作部署，认真落实公司党组管理成熟度评价工作要求，着力构建河南中烟“6+1+1”管理成熟度评价体系，努力探索走出一条质量更好、效率更高、服务更优的管理提升新路径。现将有关情况汇报如下。

# 一、工作开展情况

在公司党组正确领导下，在各部门大力支持和共同努力下，围绕用好管理成熟度评价，持续提高整体绩效和管理能力，推动公司管理成熟度水平迈上新台阶的总体要求，启动成熟度评价体系全面建设，截至12月底，完成六大核心业务+综合管理+卷烟厂的评价条款初稿编制工作。

（一）坚持卓越导向，系统策划体系架构。**一是坚持卓越导向**。锚定打造一流现代化卷烟工业企业远景目标，对标世界一流企业管理理念、模式、方法，把握成熟度评价“持续改进、追求卓越”的深层内核，围绕“打牢基础、引领发展”的关键作用，召开动员部署会，积极引导公司干部职工，深刻领悟成熟度评价的征求认识，将关注焦点聚焦到今后一段时期的改进提升，打牢的共同思想基础。**二是明确建设依据**。秉承“以能力为核心、以评价促改进”的管理成熟度建设理念，参考国际、国内通行的成熟度模型构建方法，明确评价体系建设以中央关于国资国企改革等重大战略部署为遵循，服务企业发展战略和改革方向；以行业内外一流企业为标杆为引领，持续推动管理水平向先进看齐；以法律法规硬性标准，上级政策和公司制度体系为刚性约束与正向引导，将内外部要求融入评价体系。**三是策划体系架构**。聚焦核心业务、紧盯关键环节、突出重点能力，经多轮专题研讨、优化完善，系统设计形成“6+1+1”管理成熟度评价架构（即六大核心业务+综合管理+卷烟厂）。其中，六大核心业务主要聚焦企业价值创造过程，综合管理聚焦支撑企业运行的保障要素，卷烟厂评价主要围绕生产、质量、成本、管理、规范、安全等核心职能，整体架构具备聚焦关键、纵向贯通、横向协同的鲜明特点。按照不同作用，策划设计《管理成熟度评价准则 第1部分：构成及要求》等9份标准组成评价体系。

（二）坚持试点探路，深入开展评价实施。**一是精心组织试点评价。**聚焦价值创造关键环节，选取生产制造核心业务及南阳卷烟厂作为试点。制定专项实施方案，统筹内外部专家资源组建评价小组，开展培训宣贯，深入解读评价体系。综合运用制度审阅、资料查验、调研访谈、对标分析、现场核实等方法，对生产制造业务5个能力域、88项核心内容、279条评价条款，以及南阳卷烟厂6个能力域、144项核心内容、500条评价条款，全面开展成熟度评估。**二是系统梳理评价发现。**明确了当前所处管理阶段，精准识别出能力差距与关键短板，深入揭示了制度标准建设与执行中的薄弱环节，有效诊断出跨部门协同不畅、资源配置不协调等制约因素。共总结出制度体系管理颗粒度不足、执行监督不够严格、数字化转型进程滞后等8项系统性问题，提出改进机会42项、提升建议34项，为精准施策确立了主攻方向。**三是持续推动改进提升**。通过系统梳理业务现状、识别管理薄弱环节、研讨提升措施，有效激发业务单元自我完善与持续改进的内生动力。同时审视评价体系本身，发现存在等级递进关系不够清晰、评价队伍能力有待加强等问题，明确了“能力子域核心要素梳理—关键举措设计—评价条款展开—全面评价实施”的技术路线。

（三）坚持纲举目张，全面推进凝聚合力。**一是健全组织体系**。充分吸收生产制造核心业务、南阳卷烟厂试点评价经验教训， 2025年10月，制定印发《成熟度评价体系全面建设实施方案》，明确3个阶段17项具体任务，为整体工作有序推进提供路径指引。组建技术研发、原料保障、物资保障、生产制造、市场营销、物流管理、综合管理、卷烟厂8个专项业务组，配齐配强专业力量，形成分工合理、协同高效的推进格局。**二是实施挂图作战**。梳理形成8个步骤、25个关键活动的阶段任务图，明确各节点起止时间、责任部门和推进进度，实行挂图作战、按图推进，定期更新建设情况，确保体系建设按序落实、稳步见效。三**是强化能力建设。**组织84名编制人员开展集中实操演练培训，帮助全员快速建立对体系的整体认知，明确评价体系的基本框架和应用方法；结合业务差异分组开展核心要素、关键举措、评价条款3批24场次专项培训，推动编制人员深入理解评价标准、准确把握评价方法，为体系高质量建设奠定能力基础。

（四）坚持精益求精，初步搭建评价体系。**一是统一底层标准**。针对建设过程中能力子域层次不齐、关键举措颗粒度不一致、等级级别划分不统一、评价条款描述存在差异、同类业务要求不同等问题，建立《管理成熟度评价准则编制指南》《成熟度评价体系建设标准》《关键举措、等级特征、评价条款设置规范》，明确三级要达到行业中游偏上、四级要达到行业先进、五级要达到行业标杆等关键要求，为各业务组提供统一的编制指引，确保评价体系能够对各领域管理现状进行精准“画像”。**二是推进体系建设。**在能力域设计层面,划分43个相对独立的能力域,细化为165个可落地、可量化、可评估的能力子域;在评价要素层面,识别453个由关键活动构成的核心要素,制定X个分级关键举措,划分等级门槛;在评价标准层面,形成XX个评价条款初稿,明确各条款的判定标准和证据要求。**三是实施三级评审**。建立“业务组内部评审、建设办公室技术评审、多方综合评审”的三级审核流程，以“分层把关+多方协同”模式，确保审核责任清晰、专业把关充分、成果质量可控的效果；各部门负责人、业务分管负责人全程参与评审工作，广泛征求相关部门和条线意见，确保评价体系符合公司实际、具备可操作性。截至2026年1月7日，组织开展两轮次，30场次综合评审。

# 二、存在问题和不足

在肯定成绩的同时，我们也清醒地看到，体系建设工作中还存在一些问题和不足，需要认真加以解决。**一是认识需要加强**。部分单位和人员对成熟度评价的认识停留在表面，对其诊断提升、引领发展的功能理解不够全面，对评价体系跨部门协同、全流程贯通的要求认识不足，也不愿正视当前管理现状。**二是与一流企业要求存在差距**。评价条款对国家战略部署、行业要求、标杆实践举措的吸收借鉴不够，与一流卷烟工业企业远景相比还存在差距，部分能力域仍然存在等级划分不够科学，等级递进关系不够清晰的问题。**三是队伍能力需要加强**。评价体系建设人员对成熟度评价的理论体系、方法工具掌握不够系统，对行业标杆、管理规范理解不够深入，评价能力、证据识别能力等关键能力亟需提升。

# 三、下一步工作计划

紧扣2026年3月底前建成评价标准，2026年12月底完成试评价，2027年实现评价体系全面运用的建设目标，倒排工期、挂图作战，扎实推进体系建设各项工作，确保按期高质量完成既定任务。

**一是稳步推进评价标准建设。**开展评价条款两阶段评审，确保条款内容符合行业标准和公司实际，1月25日前完成第一阶段技术评审，重点审核评价条款的表述规范性、颗粒度一致性、内容完整性；2月10日前完成第二阶段综合评审，重点审核评价条款是否符合战略导向、对标一流、合法合规、系统集成的总体要求。3月底前，根据评价条款，结合前期建设经验，制定各专项评价准则，编制管理成熟度评价系列标准。

**二是扎实推进评价体系试运行**。总结试点评价经验，优化评价工具方法，建立统一规范的评价实施流程。4-5月完成试运行筹备工作，制定试运行实施方案，组建评价队伍并开展培训，全面部署试运行工作。6-10月分阶段开展成熟度评价，各核心业务、综合管理、各卷烟厂按照评价准则开展自我评价，建设办公室组织现场评价，形成评价报告和问题清单；各部门、单位召开专题研讨会，分析问题原因，制定改进措施，明确工作目标和责任人，将评价发现转化为效能攻坚任务，推动管理成熟度水平持续提升。

**三是推进评价体系全面应用**。组建公司级评价小组，全面开展公司成熟度评价，分析公司管理成熟度当前水平、发展趋势、主要问题，形成公司评价报告和改进计划。基于评价改进计划，融合衔接效能攻坚行动要求，持续推进项目攻关和改进提升活动。总结2025-2027年评价工作，提炼河南中烟特色的成熟度评价模式，持续优化管理能力提升路径；建立能力改进提升典型案例库，固化评价措施，形成长效机制。
