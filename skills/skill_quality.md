## 一、意思不流窜检查

### 什么是「意思流窜」
同一个论点、同一块内容、同一个数据，在文章里出现超过一次。

常见流窜模式：
- 开篇总结提了某项成绩→正文分板块又详细说→结尾再回顾
- 问题部分提了某个问题→下步部署的对应措施里又重复描述问题
- 背景部分说了政策要求→正文各部分反复引用同一个政策表述

### 检查方法：论点地图

展开全文之前，建立「论点地图」：

```
论点A：[XXX成效] → 仅在 第一部分（二）出现
论点B：[XXX问题] → 仅在 第三部分 出现
数据X：[23项指标提升率85.7%] → 仅在 第一部分开篇 出现
```

全文完成后，逐条检查：
- 每个论点是否只在标注的位置出现
- 每个数据是否只在标注的位置出现
- 发现重复→合并到最合适的一处，其余删除

## 二、逻辑层次检查

### MECE检查（同级内容）

将同级标题单独列出，逐对判断：
- A和B是否有内容交叉？（如「工作推进有力」和「任务完成符合预期」有重叠）
- A、B、C加在一起是否覆盖了全部应有内容？（有无遗漏）

常见问题：
- 把「结果」和「过程」并列（「成效显著」和「工作扎实推进」不是同一层级）
- 把「总体判断」和「具体内容」并列（「整体进展顺利」不能和「烟叶工作」并列）

**层级归属验证——上下位概念并列识别（消化 C-06 / CQ-003）**

**底层依据：** 上位概念与其下位概念并列，是逻辑层级错乱最隐蔽的形式，因为每条单独看都成立，只有放在一起才能看出包含关系。

**操作——「任意两条互换测试」：**
对并列的 N 个条目（一是/二是/三是，或（一）（二）（三））逐对检查：
> A 是否是 B 的下位概念？B 是否是 A 的下位概念？

若存在包含关系 → 层级混乱，须修复。

**两种修复方式：**
1. 将下位概念**移入**对应上位概念下作为子条目
2. 用**同层级概念替换**下位概念（提升抽象层级）

**典型错误模式（烟草公文高发）：**
- ❌ 「重点做好三项工作：一是党建引领；二是支部标准化建设；三是发展党员。」→ 后两项是「党建引领」的下位概念
- ❌ 「三大管理体系：一是质量管理；二是安全管理；三是ISO 9001认证。」→「ISO 9001认证」是「质量管理」的下位工具
- ✅ 修正方向：上位概念（党建引领/质量管理/安全管理）并列，各自下面展开子条目

### 总分数量精确对应检查（消化 C-07 / CQ-004）

**底层依据：** 「主要体现在三个方面」是对读者的承诺——读者会数分项是不是恰好三个，内容是不是与总括对应。数量或语义不符，立刻破坏可信度。

**触发条件：** 文中出现以下任意一类总括句时，必须执行此检查：
- 「主要体现在X个方面」
- 「重点做好X项工作」
- 「呈现以下X个特点」
- 「主要存在X个问题」
- 「从X个维度/方面/角度」

**检查三项：**
1. **数量精确一致**——下文分项数与总括数字严格相等（说三项，正文展开恰好三项，不多不少）
2. **语义匹配**——每个分项的核心内容与总括句中对应的描述语义匹配（总括说「体制机制、队伍建设、资源保障」，分项的标题或首句须分别对应这三个词）
3. **无遗漏无多余**——无「总括提到但正文未展开」，也无「正文有但总括未提及」

**示例：**
- ❌ 「工作主要呈现三个特点：一是推进有力；二是成效显著；三是基础扎实；四是机制完善。」（说三点，实际展开四点）
- ❌ 「重点做好两项工作：一是加强组织领导；二是强化资金保障。……（正文还有第三项：加强督导考核）」（说两项，实际展开三项）
- ✅ 「主要体现在三个方面：一是…… 二是…… 三是……」（总括数字与分项数量精确一致）

### 因果链完整性检查（消化 C-08 / CQ-002）

**底层依据：** 「由于改革创新……因此群众满意度提升」——从改革到满意度，中间缺了「服务质量提升」这个传导步骤。作者默认省略了中间过程，读者却会感到逻辑断裂。跳跃式因果在烟草公文中极其常见，须主动检查。

**触发条件：** 文中出现以下任意连接词时必须执行此检查：
`因此`、`由于`、`所以`、`从而`、`进而`、`为此`、`正是因为`、`基于此`

**三步验证：**
1. **直接因果验证**——连接词前的原因能否直接导致连接词后的结果？中间有无缺失的传导步骤？
2. **链条补全**——若不完整，须补充中间机制：
   - ❌ 「改革创新 → 群众满意度提升」（缺中间环节）
   - ✅ 「改革创新 → 服务质量提升 → 群众满意度提升」
3. **递进关系验证**——「从而」「进而」引导的递进结果，与前提之间是否有内在逻辑联系？不能直接跨越多个层级。

**典型错误（烟草公文高发）：**
- ❌ 「由于深入推进管理改革、加强科技攻关，因此质量效益持续提升。」（改革→质量效益，缺传导步骤）
- ❌ 「我们坚持精益管理，从而在行业综合评价中位次大幅提升。」（精益管理→位次，跳过了改善的具体指标）
- ✅ 「深入推进精益管理，生产效率提升21%、单箱消耗下降8%，最终带动综合评价得分提升至行业前三。」（完整传导链，有中间数据）

### 语句层逻辑检查（消化 D-01 / BG-007 领导公文逻辑七维·⑥语句逻辑）

**底层依据：** 领导批评「没有逻辑性」，有时不是框架问题，而是单句层面出了问题——主语不明确、谓语与主语语义不搭、同一概念在不同地方含义漂移。这类错误读者感觉「哪里不对但说不清」，在审阅阶段会被直觉打回。

**三项检查：**

**①主语明确**
关键判断句须有可识别的主语，不得依赖上下文推断。重点检查：
- 无主语命令句「要加强……」「须重视……」→ 补充「各业务部门要……」「分管领导须……」

**②主谓搭配验证**
谓语是否与主语在语义上兼容？
- ❌ 「方案颁布了成效」（方案不能颁布成效）
- ❌ 「改革创新了质量效益」（改革创新不是质量效益的动词）
- 修复：调整主语或换用与主语语义相符的谓语

**③概念前后一致**
全文同一词语不得在不同位置指代不同含义。
- 重点检查：「体系」「成熟度」「指标」「条款」等多义概念
- 检查方法：找到该词第一次出现时的定义（或隐含含义），逐一核查后续用法是否一致

### 递进关系检查（上下级内容）

- 二级标题内容是否完全属于一级标题的范畴？
- 正文内容是否完全支撑二级标题的论点？
- 有无「跨级」描述（一级标题下直接出现应该在三级才讲的细节）

### 结构比例检查（消化 C-05 / CQ-006）

**底层依据：** 问题段一句带过、部署段空洞、成效段占全文80%——这是「报喜不报忧」的比例失衡，读者感受是「不真实」。比例不是死规定，但偏离区间须有充分理由。

**工作汇报 / 工作报告类文体比例要求：**

| 板块 | 占全文字数 | 常见失衡方向 |
|------|-----------|------------|
| 成效/主要工作 | **40%–55%** | ❌ 超过60%：变成流水账，问题和部署被压缩 |
| 问题/不足 | **10%–20%** | ❌ 低于5%：一句带过，失去诊断价值 |
| 下步打算/工作部署 | **25%–40%** | ❌ 低于成效部分一半：「做了很多，但不知道下步怎么办」 |

**检查步骤：**
1. 全文完成后，粗略统计三个板块各自的字数
2. 判断是否在区间内
3. 超出区间 → 调整对应板块篇幅（成效段过长→压缩重复叙事；问题段过短→补充具体问题描述；部署段过短→补充时间节点和量化目标）

**注意：** 比例检查仅适用于「工作汇报/工作报告」文体；实施方案、讲话稿等文体有不同比例逻辑，不适用此表。

### 标题-内容对应性检查（消化 B-1 / CQ-007）

**底层依据：** 标题是该段内容的"对外承诺"。承诺写的是「组织领导保障」，正文却讲资金和时间节点，就是失信于读者。读者读完会感到"被骗"，对全文可信度产生怀疑。

**操作步骤——双向验证：**

**正向：标题→内容**
1. 摘取标题中的核心动词和核心对象
2. 检查正文中的关键句是否都属于这两个词的语义范畴
3. 不属于的句子 → 跑题，须移走或重写标题

**反向：内容→标题（内容归属验证）**
1. 把正文每句话的核心语义抽取出来
2. 逐句判断该句应归属哪个标题范畴
3. 若某句的语义明显属于另一个标题的范畴 → 该句移到对应标题下
4. 若找不到合适的标题 → 新增标题或调整现有标题范畴

**典型错误模式：**

```
❌ 标题：「（一）加强组织领导」
   正文：「成立专项工作组（√ 属于组织领导）。
          投入资金 230 万元（✗ 属于资源保障）。
          确保 2026 年 6 月底前完成（✗ 属于时间安排）。」

✅ 修正方案：
   或：扩大标题范畴 → 「（一）强化组织保障」（含组织+资源+时间）
   或：拆分为三个独立标题 → 「（一）加强组织领导」「（二）落实资源保障」「（三）明确时间节点」
```

**特别提醒**——烟草系统常见的"组织领导套话段"，往往把组织、资金、时间、考核四件事杂糅在一个"加强组织领导"标题下，全部都是失对应。须按业务实质拆分为「组织保障」「资源保障」「机制保障」「监督考核」四个独立小标题。

### 文种-内容侧重点检查（消化 C-04 / MT-006 类因果法）

**底层依据：** 每种文体有其专属的「内容重心」。写汇报把大篇幅放在过程描述（「法」）上、成效只一笔带过，是最常见的文种失焦错误。

**四类基本逻辑要素（类·因·果·法）的文种分配规则：**

| 文种 | 主导要素 | 内容比例要求 |
|------|---------|------------|
| 工作汇报 / 工作报告 | **果**（成效+数据） | 「果」≥50%；「法」（过程描述）≤30% |
| 实施方案 / 工作方案 | **法**（措施+时间节点+责任人） | 「法」≥60%；背景说明（「因」）≤20% |
| 专题分析 / 调研报告 | **因**（原因分析） | 「因」须有深度：现象→直接原因→根本原因，至少分析到第二层 |
| 发展规划 / 三年计划 | **类+法**（目标分类+实施路径） | 目标分层明确（类），每类目标有对应路径（法） |

**检查步骤：**
1. 确认文种
2. 对照上表判断主导要素
3. 粗略估算各要素段落字数占比
4. 若比例失调，按文种特性调整：汇报中过多「法」须压缩过程描述、扩充成效数据；方案中过多「因」须压缩背景，补充具体措施

**烟草汇报最常见失焦问题（须主动检查）：**
- 「一是/二是/三是」各条中，每条用2/3篇幅描述「我们做了什么」，只用1/3讲「取得了什么」→典型「法」喧宾夺主，须翻转比例：结果先说，做法一句带过

## 三、烟草行业规范检查

### 政治表述顺序检查

烟草行业政治表述有固定顺序，不得随意调换：

**指导思想引用顺序：**
习近平新时代中国特色社会主义思想 → 党的XX大精神 → 中央经济工作会议 → 全国烟草工作会议 → 省委省政府要求 → 国家局党组部署

**四个意识/四个自信/两个维护的固定组合：**
「树牢'四个意识'，坚定'四个自信'，坚决做到'两个维护'」
（不可分开使用，不可改变顺序）

**烟草行业常用政治套语（必须准确，不得改写）：**
- 「坚守发展和规范两条底线」
- 「担当奋进、主动作为、竞相发展」
- 「跳起摸高、争先进位」
- 「高质量发展」（不是「高质量的发展」）
- 「现代化建设」（不是「现代化的建设」）

### 政策引用单句层级顺序（消化 C-10 / CQ-023）

**底层依据：** 「根据我市要求，为贯彻落实国务院……」——地方要求在国务院前面，是严重的层级倒置错误，会被领导直接打回修改。

**规则：** 同一句话内引用多层级政策时，高层级在前、低层级在后。

**检查触发：** 凡出现以下结构时必须检查层级顺序：
- 「根据……，按照……，落实……」（多个介词引导的并列引用）
- 「为贯彻……，按照……的要求……」
- 「坚持……，落实……，推进……」

**层级顺序（由高到低）：**
习近平重要指示 → 党中央/国务院要求 → 全国烟草工作会议/国家局部署 → 省委省政府要求 → 省级烟草公司部署 → 本单位要求

**示例：**
- ❌ 「按照省公司的部署，为认真贯彻国家局党组决策……」（省公司在前，国家局在后）
- ✅ 「认真贯彻国家局党组关于……的决策部署，按照省公司……的工作安排……」（高层级在前）

### 言辞规范性检查（消化 D-07 / LR-002 十个不写·⑤大话·⑥不得体·⑦超范围）

**三类检查：**

**①大话检查**（言过其实）
以下重大程度表述须有数据或权威认定支撑；无支撑时须降级：

| 大话表述 | 降级替换 |
|---------|---------|
| 「历史性突破」 | 「取得重要进展」 |
| 「根本性转变」 | 「实现明显改善」 |
| 「质的飞跃」 | 「取得较大提升」 |
| 「彻底解决」 | 「基本解决/有效缓解」 |

**②语体匹配检查**（不得体）
- 汇报材料须陈述语气（「我们做了……，取得了……」），不得出现命令语气（「各部门要……」）
- 检查方法：通读时问「这句是'我们做了'还是'你们要做'？」汇报材料不应有后者

**③信息范围检查**（超范围）
核查全文是否包含以下类型；若有，须征询确认后再纳入：
- 尚未正式公布的人事变动
- 精确的内部财务数字（未经批准对外披露）
- 可能引发同业纠纷的竞争性分析

### 政策引用质量检查（消化 D-11 / LR-010 理论论据三要点·融会·得体·适度）

**底层依据：** 大段照搬上级文件是「有内容没思想」的典型表现——显示作者没有真正理解政策，只是在转发原文。好的政策引用是「引一句、展两句」：引用核心概念，用本单位具体实践来阐发。

**触发条件：** 连续引用上级文件/领导讲话/政策条文超过3句（约50字）时执行此检查。

**要求：** 引用段落后须紧接本单位结合性表述：
```
[引用上级精神1-2句关键内容]。结合[本单位实际/具体工作]，我们[做了什么/打算怎么做]。
```

**示例：**
- ❌ 连续4句照搬文件原文，无任何本单位阐发
- ✅ 「国家局明确要求推进管理工具与业务场景深度融合。我们结合实际，把这一要求落实为42个能力域的场景化评价标准，把条款写进卷烟厂班组日常操作规程。」（引用精简到核心，紧接本单位做法）

### 烟草专业术语检查

参考 `03_dictionary/tobacco_terms/` 的五个文件逐类核查：

**组织术语（01_组织术语.yaml）**
- 「省局（公司）」不是「省公司」
- 「直属单位」不是「下属单位」
- 国家局全称「国家烟草专卖局」，正式场合不简称「国家局」以外的其他写法

**业务术语（02_业务术语.yaml）**
- 「两烟」= 烟叶+卷烟（不是两种卷烟）
- 「万担」是烟叶计量单位（1担=100斤）
- 「箱」是卷烟计量单位（1箱=50条=500包）

**政策术语（03_政策术语.yaml）**
- 「计划经济」在烟草系统是合法表述，不需回避
- 「专卖」是核心制度，不是贬义词

**管理成熟度术语（04_管理成熟度术语.yaml）**
- 「成熟度评价」不是「成熟度考核」
- 「能力域」「能力子域」「核心要素」「关键举措」是专有术语，不得替换

### 公文格式检查

参考 `02_rules/rules_master.yaml` 的格式合规规则：

**标题层级规范（消化 C-09 / FC-022）：**

标准序号体系：一、→（一）→ 1. →（1）

**三项硬性要求：**
1. **不得跳级**——一级（一、）的下一级必须是（一），不得直接出现 1. 或（1）；（一）的下一级必须是 1.，不得直接出现（1）
2. **同层序号格式唯一**——全文同一层级只能使用一种序号格式，不得有的地方用（一）、有的地方用 1.
3. **全文一致性**——若某处用了（一），则全文同层级标题都应用（一），不得混用

**检查步骤：**
1. 列出全文所有标题，标注层级（一级/二级/三级/四级）
2. 检查相邻层级之间是否有跳级
3. 检查同层级是否混用了不同序号格式

**典型错误：**
- ❌ 一、→ 1.（跳过了（一）层）
- ❌ 同层出现「（一）……」和「1. ……」并存

**数字表述：**
- 百分数用阿拉伯数字：「85.7%」不是「百分之八十五点七」
- 序数词用中文：「第一」不是「第1」
- 金额：万元以上保留两位小数：「8663万元」

**时间表述：**
- 年份用阿拉伯数字：「2025年」
- 月份用阿拉伯数字：「1月」
- 时间节点必须精确到月份，不接受「年内」「近期」「适时」

## 四、数据质量检查

### 必须有对比基准
每个数据必须说明对比基准，否则无效：
- ❌ 「实现税利148.99亿元」
- ✅ 「实现税利148.99亿元，超额完成年度目标任务」
- ✅ 「一类烟销量占比17.89%，在19家中烟公司中排名第17位，低于行业平均水平38.57%」

### 程度副词须有数字印证（消化 A-2 / CQ-015）

**底层依据：** 程度副词是「无成本的夸大」——不用数据就能把成效说得很大。用了程度副词却没有数字，读者无从判断「大幅」是5%还是50%，实质上等于没说。

**高风险词表**（出现即触发检查）：
大幅、大幅度、显著、明显、翻倍、跃升、大力、快速、有效、全面、全方位、大幅提升、显著改善、明显好转、大力推进

**检查步骤：**
1. 全文搜索上述词语（逐一定位）
2. 对每处出现，检查其后 **3句内** 是否有具体数字支撑
3. 无数字 → 二选一：①补充数字（「大幅提升 → 提升23个百分点」）；②删除程度副词，改为可验证的表述（「大力推进 → 组建8个专项工作组推进」）

**示例：**
- ❌ 「管理水平大幅提升，各项指标显著改善。」（两个程度副词，零数字）
- ✅ 「管理成熟度试点评价得分从72分提升至89分，提升17分；生产制造核心业务条款符合率从61%跃升至84%。」

### 数据一致性检查
- 开篇引用的数据与正文各板块数据是否一致
- 同一指标在不同部分的口径是否统一（时间范围、统计范围）
- 问题部分的数据与成效部分的数据是否矛盾

### 数据来源检查
- 有无无来源的绝对数字（「管理成效14.36亿元」需说明统计口径）
- 行业排名必须说明参考范围（「行业第X位」需注明是「19家工业公司」还是「36家商业公司」）

## 五、完成后通读检查

### 通读节奏检查
朗读全文，标记以下情况：
- 连续3句以上没有数据→需要补充数据或删减
- 连续3句以上句式相同→需要调整句式
- 出现超过200字的无分条长段→需要拆分

### 段头撮要检查（消化 C-03 / A-6 / MT-008）

**底层依据：** 段首句即「无形的小标题」。读者快速浏览时，最先抓住的就是各段第一句；段首句不到位，全文逻辑主线就会被掩盖。

**检查方法**——通过「只读首句测试」验证：
1. 取出所有正文段落（无小标题领起的自然段也算），单独列出每段的首句。
2. **只读首句**——这些首句串联起来，能否还原全文的完整逻辑主线？
3. 不能还原，须修改对应段落的首句。

**段首句的合格标准：**
- 必须是**判断句**（含主语+谓词+宾语/补语，可判真假），不得是过程描述句、背景铺垫句、引言句
- 必须能**概括全段**——段内其余所有句子都是对首句的阐述、例证或数据支撑
- 段内若出现首句范畴以外的内容，二选一：①拆分为两段，各自有独立的概括句；②扩大首句范畴覆盖全段

**示例：**
- ❌ 「自 2022 年以来，公司持续推进管理体系建设。」（背景描述，不是判断）
- ❌ 「我们通过组建工作组、明确分工、定期通报的方式开展工作。」（过程描述，不是判断）
- ✅ 「两年来，管理体系建设已从框架搭建期进入能力跃升期，6 项核心指标在行业内排名前三。」（判断+依据）

### 段首句覆盖度检查（消化 A-7/B-7 / LR-011 意群概念与段落组织）

**底层依据：** 意群是内容的基本单元——一个意群一个段，一个段一个段首概括句。段首句覆盖不到全段内容，说明段内有两个意群，须拆分；两段内容讲的是同一件事，说明被人为拆开，须合并。

**检查两类问题：**

**①覆盖不足（须拆分）**
段内出现段首句范畴以外的句子 → 将该段拆为两段，各自有独立概括句。
- 检查方法：逐句判断是否属于段首句所定义的范畴；出现「属于另一件事」的句子即触发拆分

**②覆盖重叠（须合并）**
相邻两段的首句表达同一件事（只是措辞不同） → 合并为一段，取更概括的首句。

**验收测试：**
把所有段首句单独列出，问「只读这些首句，能否还原全文逻辑主线？」
- 能还原 → 段首句体系合格
- 不能还原（某处跳跃或某段首句不是判断句）→ 对应段落须修改

### 单句信息量检查（消化 A-3 / LR-002「废话」）

**底层依据：** 公文里的每一句都必须承载信息。一句话能被删掉而文章信息量不减少，这句话就是「零信息句」，必须删除或改写。

**零信息句的三个识别特征**——符合任一即判定为零信息：
1. **重申型**——这句话只是把上文已经说过的观点换种说法再说一遍
2. **过程型**——这句话只描述了行为过程（"我们认真组织……扎实推进……"），但没有说明结果
3. **可压缩型**——这句话用一个更简洁的短语完全可以替代

**检查步骤：**
1. 逐句通读，遇到疑似零信息句时执行「删除测试」——把这句删掉，重读上下文，文章信息量有无减少？
2. 无减少 → 删除
3. 有减少但减少的是修饰性内容 → 用更精简的短语替代
4. 有减少且减少的是关键判断 → 该句保留，但改写为含具体结果的实义句

**示例：**
- ❌ 「我们高度重视体系建设工作，认真组织各项任务推进，扎实抓好工作落实。」（典型过程型零信息句）
- ❌ 「这一举措的实施，对推动管理水平的提升具有重要意义。」（重申型——前文已讲清意义）
- ✅ 「体系建设投入工作日 1240 个，覆盖 42 个能力域，最终产出 2977 条评价条款。」（含主体+动作+具体数字）

### 精炼度检查——20%压缩测试（消化 D-10 / LR-006 简洁文风·压缩/合并/替代三法）

**底层依据：** 「每段删去20%的字而信息量不减」是简洁文风的操作化验证标准。绝大多数初稿都能通过此测试——初稿里总有冗余表达、同义重复、可压缩的修饰词。

**三步操作：**
1. **选取**全文最长的3个段落
2. **逐段执行三法：**
   - **压缩**：删除语义重复词（「非常十分重要」→「十分重要」）
   - **合并**：相邻两句讲同一件事 → 合成一句
   - **替代**：超过3个事项的叙述段改为①②③列举格式
3. **验收**：压缩后信息量是否保留？保留 → 执行；有损失 → 换更精炼方式重新表达（不可以信息损失换字数）

**目标：** 每段压缩 15–25%，信息量完全保留。若某段已无可删，说明该段本身已精炼，不强制执行。

### 文气通顺检查（消化 D-04 / SP-001 文气宜通）

**底层依据：** 文气是专业写手与初级写手的分水岭。文气通顺，全文读来一气呵成；文气中断，读者每隔几句就要"卡一下"，注意力被频繁打断。

**朗读全文，标记三类中断点：**

**1. 话题跳跃点**——前后两句话题突然切换，没有任何过渡
- 检查方法：相邻两段的首句、相邻两句之间，话题是否自然过渡？
- 修复方式：加一个过渡句，明确点出两段/两句之间的逻辑关系（递进/转折/并列/因果）

**2. 节奏断点**——连续 3 句以上字数相近（如全是 25 字左右的句子），单调感强；或长短句无规律乱排
- 检查方法：把段内每句的字数标出来，看是否出现"长长长长长"或"短短短短短"的连续串
- 修复方式：用一个明显的长句或短句打破节奏，形成"长—短—中—长"的错落

**3. 逻辑空白点**——读到某处感到"前面没铺垫，这个判断怎么来的"
- 检查方法：每个新出现的判断句、新出现的数据、新出现的概念，是否有前文铺垫？
- 修复方式：补充 1-2 句逻辑铺垫，让结论的产生过程可追溯

**达标标准：** 全文中断点清零（每类零次）。如果有任一类中断点 ≥3 次，须重新通读修订。

### 句法完整性检查（消化 A-5 / LS-009）

**底层依据：** 「通过……提高了」是公文最常见的语法陷阱——「通过」引导的介词短语不能做主语，导致句子主语缺失，读者不知道「谁提高了」。这类句式在烟草公文中出现频率极高，须主动排查。

**三类主语残缺句式（逐一排查）：**

| 句式模式 | 问题所在 | 修复方法 |
|---------|---------|---------|
| 「通过……，[提高/实现/达到/确保/推动]……」 | 「通过」介词短语不能作主语，谓语前主语缺失 | 在谓语前补充明确主语（「公司通过……，实现了……」） |
| 「经过……，[取得/形成/建立/完成]……」 | 同上，「经过」介词短语不能作主语 | 同上 |
| 「在……情况下，[省略主语][动词]……」 | 省略主语须可从上文明确推断，否则缺失 | 确认是否可以省略；不可省略时补全主语 |

**检查步骤：**
1. 全文搜索「通过」「经过」「在……情况下」「在……背景下」「在……推动下」
2. 对每处，检查其后第一个谓语前是否有明确主语
3. 无主语 → 补充主语（通常是「公司」「相关部门」「工作组」等）

**示例：**
- ❌ 「通过建立三级审核流程，有效确保了评价条款的质量。」（谁确保？主语缺失）
- ✅ 「公司通过建立三级审核流程，有效确保了评价条款的质量。」
- ❌ 「经过8个专项业务组历时6个月的编制，最终形成2977条评价条款。」（谁形成？）
- ✅ 「经过8个专项业务组历时6个月的编制，公司最终形成2977条评价条款。」

### 措施句完整性检查（消化 A-1 / CQ-012）

**底层依据：** 措施句是工作部署的基本单元。缺少责任主体，措施无人认领；缺少具体事项，措施无从执行；缺少时间节点或量化目标，措施无法验收。三要素缺一，该句就是「不可执行的空话措施」。

**三要素定义：**
- **①责任主体**——谁来做（哪个部门/哪个岗位）
- **②具体事项**——做什么（动词+对象，不得用「加强」「深化」等不可操作的动词）
- **③时间节点或量化目标**——做到什么程度/什么时候完成

**合格措施句格式：**
```
[责任主体]于[时间节点]前完成[具体事项]，确保[量化目标]。
```

**检查步骤：**
1. 定位全文所有措施句（「一要……二要……」「一是……二是……」「……负责……」「……须……」等）
2. 逐句检验三要素是否齐全
3. 缺少任一要素→视为不完整措施句，须补充

**典型不合格模式：**
- ❌ 「进一步加强组织领导，持续深化改革攻坚，不断提升工作效能。」（无主体、无时限、无量化目标）
- ❌ 「各部门要高度重视，切实抓好落实。」（「高度重视」无法量化，「切实抓好」无具体事项）
- ✅ 「企管部门于6月底前完成42个能力域评价标准的修订，确保每个子域三级特征描述达到'行业达标水准'的明确界定。」

**特别注意：** 方案文中「加强组织领导」「强化保障措施」「健全工作机制」等保障类段落，是空话集中区，须全部逐条核查。

### 语言可读性检查（消化 C-11 / LR-004 短实新）

**底层依据：** 「短实新」是公文语言的最高要求。能听懂、能记住、想继续读——这是接受者视角的语言标准。当前skill文件已覆盖「实」（数据密度）和「新」（套话可移植测试），本规则补充「短」（可读性验证）。

**三项可读性检查：**

**①25字一口气测试**
朗读全文时，找出需要换气才能读完的长句（通常超过25字）。超过者须拆分为两句，或用逗号断开。
- ❌ 「通过系统梳理和深入研究国家局关于企业管理成熟度评价体系建设的系列指导文件和政策要求，我们从中提炼出了适合本公司实际情况的评价框架。」（一句40+字，读者喘气才能跟上）
- ✅ 拆为两句：「国家局出台了企业管理成熟度评价体系建设系列指导文件。我们系统梳理政策要求，提炼出适合本公司的评价框架。」

**②核心句记忆测试**
全文最精炼的一句话（最适合被引用或传达的核心结论）是否不需要解释、听一遍就能记住？
- 检查方法：选出自认为的全文「金句」，读给未参与写作的人听一遍，问他能否复述大意。不能复述 → 提炼失败，须再精简。
- 参考标准：核心句在15字以内，不含专业缩写，含具体数字。

**③句式重复检查**
全文是否出现3次以上完全相同的句式或词组组合？
- 常见重复：连续多个「一是/二是」条目均以「坚持……」开头，形成单调感
- 修复：交替使用「坚持/突出/注重/深化/聚焦」等不同领起动词，打破单调

### 首尾检查

**格式合规检查：**
- 开场格式是否符合规范（见skill_style.md第一部分）
- 结尾是否简短有力（3-5句动员语，不超过200字）
- 结尾是否重复了正文内容（禁止）

**首尾呼应检查（消化 C-01 / SP-006 浑然一体原则）**

**底层依据：** 开篇定调、结尾收束，两者必须回应同一个核心判断。结尾如果可以套用到任何文章（「让我们携手共进、开拓创新」），说明它与本文主题脱节，是通用收束套话。

**操作步骤：**
1. 摘出开篇的**核心定性句**（通常是第1-2句中的判断句，含核心主题词）
2. 摘出结尾的**号召/结论句**（最后1-3句）
3. 比对：结尾句中是否出现了开篇核心定性句的**主题词或核心判断词**？

**合格标准：**
- 结尾须包含与开篇呼应的专属表述（本文特有的关键词/数字/概念）
- 结尾的动员方向须与全文核心主题直接相关
- 禁止使用可移植到任何文章的通用结尾

**示例：**
- ❌ 通用结尾：「让我们凝心聚力、担当作为，为公司高质量发展贡献力量！」（任何文章均可用）
- ✅ 呼应式结尾：「下一步，我们将以本次评审为契机，把2977条条款真正落到卷烟厂车间和综合管理部门，让'定性判断'走向'定量定级'，推动公司管理成熟度水平迈上新台阶。」（呼应开篇「从定性到定量」的核心判断，含专属数字）

### 工作总结类文体专项检查（消化 D-14 / WQ_MT_014 工作总结五忌）

**适用文种：** 工作总结、年度总结、汇报中的总结板块。

**五忌逐条检查：**

**①忌光摆工作**——全文须有至少1处「经验体会/规律性认识」：
「通过[XXX实践]，我们体会到/认识到……」
无此类表述 → 在最重要的成效板块末尾补充1-2句规律性认识。

**②忌套用计划**——对照年初工作计划，检查是否出现只改时态的表述：
- ❌ 计划「要加快推进…」→ 总结「加快推进了…」（套改时态）
- ✅ 正确写法：说实际结果+与计划对比（「完成全部条款编制，比计划提前2个月」）

**③忌上下不分**——
- 上报材料（向上级）：须提炼规律性认识，而非只是流水账
- 下发材料（向下属）：须含自我批评，不宜全是成绩

**④忌面面俱到**——总结不是工作日志。3-5项核心成效重点写，其余一句带过。
检查：是否每项工作均等篇幅描述？若是，须选出2-3项最具代表性的重点展开。

**⑤忌老调旧腔**——「领导重视」「层层落实」「健全制度」「扎实推进」等套话须结合本年度具体做法后才可保留，不得单独成句，不得作为独立成效条目列出。

### 删除清单
通读时遇到以下情况直接删除：
- 所有「用一句话概括……」「简而言之……」类引导语
- 所有「这正是……的根本原因/出发点/所在」类总结句
- 所有「我们也清醒地认识到，……这一问题如果得不到解决……」类过度铺垫
- 所有「诚意所在」「深度参与」「拨冗莅临」类文艺化表述（正式公文不用）

### 标题四戒专项检查（消化 B-2 / WQ_LR_005）

**逐标题对照四戒：**

**①戒不准确**——将标题与其下正文第一句（核心结论句）语义比对，不一致时修改标题。

**②戒不具体**——标题须含至少一个实质性名词（可量化的工作对象）和一个动词（描述方向或成效）：
- ❌ 「存在的问题」「工作背景」「相关情况」（纯虚词标题）
- ✅ 「管理体系建设仍有短板待补」（有名词+有判断）

**③戒不精炼**——一级标题建议 16 字以内，二级标题 12 字以内；超过者删去非核心修饰词。

**④戒不规范**——一级标题须动词领起（格式 A/B/C/D 参见 skill_style.md 第二节）；标题末尾不加标点。

### 套话可移植性测试（消化 C-12 / LR-012 奥卡姆原则）

**底层依据：** 套话的本质是「可以换给任何单位用的通用内容」。一段文字如果把本单位名称、数字、具体事项替换掉之后，换给另一个单位还能用，说明这段文字缺乏针对性，是套话。

**可移植性测试操作：**
1. 取出文中每一段或每一个条目
2. 执行替换：将其中的单位名称、数字、具体事项替换为任意其他单位的对应信息
3. 若替换后该段/条目仍然成立、仍然通顺 → 判定为套话，须改写
4. 若替换后明显不成立（因为包含了本单位专属信息）→ 合格

**改写要求：** 每段至少含一个「不可替换信息」：
- 具体数字（2977条、42个能力域、93.5分）
- 专属事件（生产制造核心业务试点评价、南阳卷烟厂）
- 具体部门+具体行为（企管部门组建8个专项业务组、建立三级审核流程）

**典型可移植套话（直接删或改写）：**
- ❌ 「我们高度重视，认真组织，切实抓好各项工作落实。」
- ❌ 「要进一步强化责任担当，以更实的举措推动工作落地见效。」
- ❌ 「全体干部职工要统一思想、凝聚共识，为公司高质量发展贡献力量。」
