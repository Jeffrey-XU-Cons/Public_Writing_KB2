## 一、开场格式规范（最高频问题）

### 工作会议讲话开场

**固定格式：**
```
同志们：

今天[会议名称]的主要任务是，[动词][上级文件/部署]，[动词][本次会议的具体事项1]，[动词][本次会议的具体事项2]，[动词]公司上下[目标表述]。[简短补充说明其他议程，如"刚才XXX同志汇报了……我完全同意"。]下面，我讲[X]点意见。
```

**实例参考：**
「今天会议的主要任务是，认真贯彻落实公司管理效能攻坚三年行动工作部署，总结效能攻坚工作开展情况，分析存在问题，安排部署下一步重点工作，动员公司上下进一步凝聚攻坚共识，奋力完成效能攻坚各项工作任务。……下面，我讲三点意见。」

**禁止：**
- 禁止开场称谓后加「大家好！」
- 禁止开场有感性铺垫（「本次会议意义重大……」）
- 禁止开场进行形势分析
- 禁止开场超过200字

### 工作报告/专题汇报开场

**固定格式：**
```
[称谓]：
[简短说明汇报背景，1-2句]，[我代表XXX，就XX工作情况作一次汇报/报告]。[如需说明汇报结构，列出几个部分]。
```

**实例参考：**
「各位代表，同志们：这次会议的主要任务是……下面，我代表公司向大会报告工作，请予审议。」

**禁止：**
- 禁止开场有「坐标系」「历史里程碑」等比喻性表述
- 禁止开场解释「为什么要做这件事」（这属于正文内容）

### 工作报告/专题汇报开场升级用法：SCQA框架（消化 D-12 / MT-001）

**适用场景：** 汇报有特殊背景（重要节点/攻坚克难情境/全面总结年度）时，用SCQA框架升级开场，比纯陈述式开场有更强带入感。

**SCQA四要素：**
- **S（稳定情境）**：描述既有基础或过往工作——「公司已连续X年坚持……」
- **C（冲突/挑战）**：点出矛盾或挑战——「然而，面对……新形势，……任务更加艰巨」
- **Q（隐含疑问）**：不显式写出，让听众心里产生「那怎么办？」
- **A（直接给出核心结论）**：正面回答，核心数据入场——「全年工作取得了……成效」

**示例对比：**

```
❌ 普通开场：
「[领导]：下面，我代表公司就2025年管理成熟度评价体系建设工作情况作汇报。」

✅ SCQA升级开场（约120字）：
「[领导]：从2022年启动体系建设到今天，公司走过了三年探索历程。今年是三年行动的收官之年，面临从试点评价走向全面推广的关键一跃。年初我们曾担心——条款写好了，能不能真正走进卷烟厂的日常管理？这一年，我们用2977条条款、42个能力域的全面评价，给出了答案。下面，我代表公司作汇报。」
（S：三年基础；C：收官年挑战；Q：能否落地；A：给出了答案）
```

**注意：** SCQA开场控制在 100–150 字，不超过200字；C须是真实挑战（不能用「面临新形势新任务」等套话代替真实冲突）。

## 二、标题格式规范

### 一级标题

**烟草系统惯用格式（四选一）：**

格式A：「动词+工作领域+成效判断」
- 「充分肯定管理提升工作取得的积极成效」
- 「准确把握形势，要继续坚定突围破局的决心」

格式B：「动词+目标+结果」
- 「全面完成管理体系优化提升工作目标任务」
- 「锚定目标任务，要继续坚定笃行不怠的恒心」

格式C：「聚焦+领域+方向」（年度报告常用）
- 「强化党建引领，坚定不移全面从严治党」
- 「突出市场导向，全力攻坚品牌千亿目标」

格式D：「时间+工作内容+定性」（总结报告常用）
- 「2024年主要工作」
- 「公司发展面临的形势任务」

**禁止：**
- 禁止纯名词短语标题（「工作背景与总体思路」「存在的问题」）
- 禁止咨询报告式标题（「顶层架构：六大核心业务的分类逻辑」）

### 标题必须是结论句，不是话题句（消化 B-6 / LR-001 SPA 原则）

**底层依据：** 标题是「全文的终极提炼」，读者读完一个标题就该知道该部分的核心判断。仅给出话题（在谈什么）而不给出立场（判断是什么），等于让读者读完全段才知道你想说什么——这违背了"结论先行"原则。

**结论句 vs 话题句的区分：**

| 维度 | 话题句（❌ 不合格） | 结论句（✅ 合格） |
|---|---|---|
| 给读者的信息 | 该段在谈什么 | 该段的核心判断是什么 |
| 是否可证伪 | 不可证伪（仅是范围） | 可证伪（含明确判断） |
| 读者读完是否需要继续读 | 必须继续读才知道立场 | 仅看标题已掌握核心 |

**典型对比：**

```
❌ 话题句：「效能攻坚工作推进情况」
✅ 结论句：「效能攻坚工作整体进展顺利，主要指标完成率达 85.7%」

❌ 话题句：「存在的问题」
✅ 结论句：「品牌大而不强的状况尚未根本改变」

❌ 话题句：「下一步工作打算」
✅ 结论句：「锚定 2027 年目标，再用三年时间打牢成熟度评价体系基础」

❌ 话题句：「成熟度评价体系的整体设计」
✅ 结论句：「构建'6+1+1'分层评价体系，全面覆盖公司管理诊断范围」
```

**判定测试：** 把标题单独抄出来，问"这句话有没有可能是假的？"——能成立或推翻的才是判断句，无法判真假的就是话题句。

### 标题与正文首句呼应规则（消化 B-3）

**底层依据：** 标题用的词和正文首句用的词若不重合，读者会感到割裂——"标题说 A，正文谈 B"。两者必须用同一个核心词形成"主题词锚定"，让标题和正文成为一个有机整体。

**操作要求：** 每个有标题的段落，其正文首句（核心结论句）必须包含标题的**核心动词**或**核心名词**。

**示例：**

```
✅ 标题：「（一）坚持思想破冰，有力推动干部职工观念转变」
   正文首句：「思想是行动的先导。两年来，我们把破除思想障碍作为效能攻坚的起点……」
   （首句含"思想"，与标题核心词呼应）

✅ 标题：「（二）构建'6+1+1'分层评价体系」
   正文首句：「'6+1+1'分层评价体系的核心是用差异化标尺评估三类对象。」
   （首句含"6+1+1"和"分层评价"，与标题完全锚定）

❌ 标题：「（一）坚持思想破冰，有力推动干部职工观念转变」
   正文首句：「自 2024 年以来，公司围绕管理体系建设开展了系列工作……」
   （首句既无"思想"也无"观念"，与标题脱节）
```

**检查方法：** 把全文所有标题和其下正文首句单独列出，逐对进行关键词比对。任何一对关键词不重叠的，须修改正文首句使之与标题形成呼应。

### 二级标题

**烟草系统惯用格式：**

「（一）坚持[核心做法/方法]，[动词+成效判断]」
- 「（一）坚持思想破冰，有力推动了广大干部职工思想观念和行为习惯的转变」
- 「（一）攻坚路径清晰明确」
- 「（一）任务推进高质高效」

**禁止：**
- 二级标题不得全部使用纯数据或纯现象描述（「评价标准的科学性有待提升」这类可以，但不得全篇如此）

## 三、正文展开逻辑

### 工作成效段的标准写法

**结构：总-分（一是/二是/三是）**

```
[总体定性句，含核心数据]。
一是[成效名称]。[具体举措/做法]+[数据支撑，必须有同比对比]。
二是[成效名称]。[具体举措/做法]+[数据支撑]。
三是[成效名称]。[具体举措/做法]+[数据支撑]。
```

**实例参考：**
「公司23项攻坚指标提升率达到85.7%，各厂13项指标提升率达到83.33%，工作整体成果显著、质效兼优。生产管理部围绕核心指标争先进位……在总产量同比增加2.4万箱的情况下，卷烟厂生产作业天数平均下降11天。」

**禁止：**
- 禁止只有定性没有数字（「工作取得积极成效，各项指标稳步提升」）
- 禁止数字没有对比基准（不说「完成XX万箱」，要说「同比增长X%」或「超额完成目标X万箱」）
- 禁止「从外部看……从内部看……从实践看……」的三维分析框架（这是咨询风格）

**【进阶写法】观点提炼级——从叙事到分析（消化 D-08 / SP-011）**

在「总分+数据」基础写法达标后，可进一步升级为「分析级」写法：在总体定性句之后，用一句话提炼本板块工作的规律性认识。

**格式：**
```
[总体定性句，含核心数据]。[从这些成效可以看出/实践证明/这说明]，[规律性判断]。
一是……二是……三是……
```

**规律性判断的四项标准：**
- **鲜明**——立场清晰，不模棱两可
- **深刻**——揭示数据背后的机制或本质，不是重复数据
- **新颖**——有本单位特有的见解，不是人云亦云的套话
- **实用**——对后续工作有指导价值

**示例对比：**
- ❌ 基础写法（叙事层）：「2977条评价条款全部完成编制，42个能力域、161个能力子域实现全覆盖。」（有数据，无洞察）
- ✅ 分析级写法：「2977条评价条款全部完成编制，42个能力域、161个能力子域实现全覆盖。这说明，**只有把管理评价工具扎根到具体业务场景而非套用通用框架，标准化才能真正落地、评价才能真正有效。**」（数据+揭示机制的规律性判断）

**使用时机：** 汇报重点板块（全文2-3个最核心的成效板块）使用分析级写法，其余板块保持基础写法，避免全文都在讲「这说明……」导致说教感过重。

### 问题段的标准写法

**结构：直接列举，不展开分析**

```
在肯定成绩的同时，我们也清醒地看到问题和不足。一是[问题名称]，[一句话描述]。二是[问题名称]，[一句话描述]。三是[问题名称]，[一句话描述]。[结尾一句：这些问题公司上下务必要引起高度重视，认真加以解决。]
```

**实例参考：**
「一是管党治党需进一步加强，正风肃纪反腐还需强化，企业党建基层基础仍需夯实。二是发展质量需进一步提升，品牌大而不强的状况尚未根本改变。」

**禁止：**
- 禁止在问题段大篇幅分析原因（原因分析是专题汇报的内容，不是工作报告/讲话的惯例）
- 禁止用「我们清醒认识到，体系建设中还存在一些值得高度重视的问题和不足。这些问题，既是……也是……」这种反复铺垫的咨询式表述

### 工作部署段的标准写法

**结构：总体要求+分条（一要/二要/三要）**

```
[总体要求，1-2句，含量化目标]。
一要[动词+工作方向]。[具体要求，含时间节点和量化目标]。
二要[动词+工作方向]。[具体要求]。
三要[动词+工作方向]。[具体要求]。
```

**实例参考：**
「一要围绕"稳、优、转"，打好三大攻坚战。严格按照全国、全省烟叶工作会议安排部署，搞好控稳结合，确保圆满完成397.9万担的计划任务，严禁超产超收。」

## 四、常用句式规范

### 引用上级精神的标准句式
「认真贯彻落实[上级会议/文件]精神」
「深入落实[领导姓名][职务]关于[内容]的重要[讲话/指示/批示]」
「聚焦[行业要求]，围绕[公司目标]」

**禁止：**
- 「国家局党组深入贯彻党中央关于建设世界一流企业的战略部署，在烟草行业全面启动……」（不用第三方视角描述上级行为，应改为「认真贯彻国家局……部署要求」）

### 成效表述的标准句式
「[工作领域][动词][成果]，[数据]」
「在[条件]的情况下，[成效]+[数据对比]」
「[指标名称]同比[增长/下降][X%/X个百分点]，[位次说明]」

### 问题表述的标准句式
「[工作领域]需进一步[动词]，[具体表现]」
「[指标名称]与[对标对象]相比仍有差距，[数据说明]」
「[问题]的问题尚未根本改变」

### 部署要求的标准句式
「各部门、各单位要[动词][工作要求]，确保[量化目标]」
「要[动词][具体举措]，力争[时间节点]完成[可量化目标]」
「[主责部门]要[动词][职责]，[其他部门]要[动词][职责]」

## 五、禁用表述清单

### 禁用的咨询报告风格表述
- 「三重力量共同驱动」「三个维度」「三个层面」（拆分为「一是/二是/三是」）
- 「核心价值体现在三个方面」（直接说「主要体现在：一是……二是……三是……」）
- 「用一句话概括：……」（直接表达，不需要这种引导语）
- 「这正是我们建设这套体系的根本出发点」（多余的总结句，删除）
- 「底层逻辑」「顶层架构」「核心框架」（改为「基本思路」「整体架构」「主要框架」）

### 禁用的空洞套话（需替换为具体表述）
- 「高度重视」→ 说明具体重视了什么、做了什么
- 「进一步加强」→ 说明加强到什么程度、达到什么目标
- 「扎实推进」→ 说明推进了什么、达到什么结果
- 「持续深化」→ 说明深化了什么、有什么变化
- 「切实提高」→ 说明提高到什么数值

### 禁用的主观判断语
- 「来看，应当」「显而易见」（改为直接陈述事实）
- 「值得高度重视的问题和不足」「诚意所在」（删除，直接陈述问题）

## 六、段落节奏规范

### 长段落控制
- 正文段落一般不超过300字
- 超过300字时必须用「一是/二是」分条展开
- 禁止出现超过500字的无分条长段落

### 数据密度要求
- 工作成效段：每个「一是/二是/三是」条目至少含1个数据
- 数据必须含对比基准（同比/目标完成率/行业排名）
- 全文数据口径必须统一（时间范围、统计口径）

## 七、讲话稿 vs 汇报材料的语体差异（消化 D-09 / LR-004 量体裁衣原则）

**底层依据：** 讲话稿是讲给听众听的，汇报材料是给领导看的。听众靠耳朵实时接收，没有回看机会，所以讲话稿必须短句、口语、有提顿；阅读者可以反复看，汇报材料须严谨、书面、完整。同一份素材改造成讲话稿和汇报材料，语体差异很大，不可一稿两用。

### 句式差异

| 维度 | 讲话稿 | 汇报材料 |
|---|---|---|
| 句长上限 | 建议不超过 20 字/句 | 25-40 字/句皆可 |
| 长句拆短 | 必须 | 视情况 |
| 排比/对仗 | 多用，增强节奏 | 适度，不堆砌 |
| 从句嵌套 | 避免 | 允许 |

**实例改造：**

```
汇报原句（40 字，含从句嵌套）：
「公司围绕落实国家局推进高效能治理战略部署、坚持系统性管理能力提升的总体要求，
扎实开展了管理成熟度评价体系建设工作。」

改造为讲话稿（拆成 3 个短句）：
「同志们，国家局明确提出推进高效能治理。这是行业的总方向。
公司要把这个方向落到实处，靠什么？靠管理成熟度评价体系。」
```

### 数据呈现差异

- **讲话稿**：数据须口头化处理，便于听众即时理解
  - 「85.7%」→ 可说成「超过八成五」或「约 86%」
  - 「2977 条」→ 可说成「将近三千条」
  - 「同比增长 38.57%」→ 可说成「比去年增长了将近四成」
- **汇报材料**：数据保留精确数字，含对比基准
  - 「指标完成率 85.7%，同比提升 12.3 个百分点」

### 提顿词差异

- **讲话稿允许且应当使用：** 「同志们」「刚才」「下面」「今天我重点讲」「要特别强调」「这一点很重要」「为什么这么说」「举个例子」
- **汇报材料必须删除提顿词**，改为书面化过渡语：「下面」→「以下」；「我重点讲」→「重点报告」；「为什么这么说」→「主要依据如下」

### 第一人称差异

- **讲话稿**：可用「我」「我们」「同志们」混合，强化现场感
- **汇报材料**：以「我们」「公司」「企业管理部」为主，少用「我」（除"我代表 XX 作汇报"开场外）

### 互改清单

写完讲话稿后，若需改造为汇报材料：
1. 删除所有提顿词
2. 长句合并：每 2-3 个短句合并为一个完整书面句
3. 数据精确化：把"将近八成"改回"79.6%"，把"约三千条"改回"2977 条"
4. 删除「同志们」「下面」「我重点讲」类口语标记
5. 删除现场互动语（「大家看一下」「请记住这一点」）

写完汇报材料后，若需改造为讲话稿：
1. 长句拆短：所有超过 25 字的句子拆为 2-3 句
2. 复杂从句改为陈述：「公司围绕……开展了……」→「公司开了什么会？做了什么事？」式提问+回答
3. 数据口头化：精确数字改为大致比例
4. 加提顿词：在板块切换、重要判断前加「同志们」「下面我讲」「要特别注意」
5. 加感叹/疑问句：每个板块至少有 1 处带情感的句式

## 八、讲话稿的生动性与鼓动性（消化 D-15 / WQ_MT_011）

**底层依据：** 讲话稿在结构和数据准确的基础上，还要让听众"听得进去""听完想做"。这两个目标对应两个能力——生动性（让人听得进去）和鼓动性（让人听完想做）。

### 生动性要求

**全文应有至少 1 处形象化表述。** 形式可以是：

- **比喻**：把抽象概念比作具体事物
  - 例：「管理成熟度评价就像企业的体检——不是为了得高分，是为了知道哪里需要治。」
- **典故/成语**：恰当引用，画龙点睛
  - 例：「'临渊羡鱼，不如退而结网'，我们不能光看别人的成绩，要动手去做。」（付生华工作报告原句）
- **身边案例**：用本系统、本单位的真实小事说明大道理
  - 例：「玉溪卷烟厂用 8 步改善法解决分类对标问题，这就是把笼统的'对标'做到了'对得精准'。」

**检查方法**：通读全文，标出所有完全可以替换成"加强/推进/落实"等通用动词而意思不变的段落——这些段落缺生动性，须挑 1-2 处补一个比喻或案例。

### 鼓动性要求

**鼓动性 ≠ 喊口号。** 真正能调动听众的是"找到与听众的共同点"。

**操作三步：**

1. **明确听众身份**——这场会的听众是谁？一线职工？中层管理？卷烟厂厂长？
2. **找出听众的关切**——他们最担心什么？最在意什么？最想得到什么？
3. **把号召语锚定到听众关切**——号召语必须能让听众感到"这是在跟我说话"

**检验方法**——把号召段中的「我们/大家」替换为具体听众群体（如「一线职工」「中层管理人员」），判断是否仍然贴切：
- 若仍贴切 → 号召语锚定到位
- 若变得不通顺或不准确 → 号召语泛化，须改为针对本次听众的专属表述

**示例：**

```
❌ 泛化号召（替换后不贴切）：
「让我们携手共进，开拓创新，为公司高质量发展贡献力量。」
（把"我们"换成"一线职工"或"卷烟厂厂长"都通顺——说明这句话谁都能说，没有锚定听众）

✅ 锚定号召（针对卷烟厂厂长）：
「各位厂长，你们手里管着一年几十亿的产值，今天的攻坚就在你们手上。
明年这个时候我们再开会，看看哪个厂的指标真正提升了。」
（把"各位厂长"换成"一线职工"立即不通顺——说明这段话只对厂长成立，锚定了）
```

### 通俗性要求（让抽象道理变浅显）

选取全文 1-2 个关键数据或抽象概念，用「相当于……」的比较句辅助理解：

- 「85.7%——相当于每 20 项指标中有 17 项完成了攻坚目标。」
- 「2977 条评价条款——平均每个能力域有 18 条具体的'体检指标'。」
- 「降本增效 36 亿元——相当于一个中型卷烟厂一年的利润总和。」

通俗性表述能让听众的脑海里立刻浮现具体画面，比单纯报数字的接收效率高 3-5 倍。
