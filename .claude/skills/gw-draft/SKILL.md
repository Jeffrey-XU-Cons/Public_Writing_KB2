## W1 思维准备 → 意图卡 → 确认点 1

**W1-1 研情**：盘点四情（上情政策/内情本单位实际/下情基层执行/外情同类单位）和四要素（事/人/体/景）。

**上级部署逐条核对（传达贯彻类必做）**：讲话、部署、方案凡要“贯彻落实”上级会议或文件的，把上级部署按条（一级、二级标题各算一条）列进 outline“上级部署对照表”，每条标“取用（落在哪一节）／弃用（理由）”。没列进表的上级部署，等于悄悄漏掉。
> P4 第 5 轮教训：讲话传达省局企管会，省局部署的“提升核心竞争力”“高质量发展与‘十四五’编制”两条既没写也没登记弃用，弃用清单只管素材内容块，管不到上级部署有没有落地。
**内情、下情拿不到的，明确写"这两块必须由你提供"——不许用通用表述糊过去。**

**素材时点核查（阻断项）**：列出每份素材的日期，比对最新素材截止时点与材料使用时点（开会/报送日）。两者之间若隔着会改变核心数据的节点（评审、修订、发布、年度结算），就是**时点缺口**。主旨句数据锚或全文核心数据落在时点缺口里 → 确认点 1 必须向用户要最新数据，**不得用删节或 `[待补]` 绕过去继续写**。
> P4 教训：评审会汇报用了评审前 2 个月的初稿数（5,902 条），实际评审时已修订为 2,977 条；压缩本身就是全文最强的证据，稿子却完全缺失。

**W1-2 立意（硬闸，本节常驻，不是按需参考）**

先回答立意三题，答不出说明素材不足，回 W1-1 补：

1. **时**——本文须贯彻/呼应的最新上级部署是什么？写 1–2 句，精确到文件名或会议名。
2. **事**——核心工作做了什么、卡在哪、本质矛盾是什么？写 3–5 句。
3. **势**——本文判断是否顺应行业/本单位发展方向？确认一句。

再写**主旨句**——一句判断，不是标题。格式参考：

```
[时间段] + [主体] + 在[工作领域]方面 + [取得/面临][什么判断] + ，[核心数据/事实印证]
```

- ✅「〔时间段〕以来，公司在〔某项工作〕上完成了从〔起点〕到〔具体成果+数量〕的落地，〔一句本单位专属判断〕。」
- ✅「〔工作〕三项指标达标的关键在于〔具体做法〕。」
- ❌「关于加强〔某工作〕的思考」——话题句，后面怎么写都行
- ❌「〔某工作〕取得显著成效」——无判断、无数据、换个单位照样成立

**主旨句三项检验，逐条过**：
1. **可证伪**——有没有可能是假的？换个单位、换个时段也成立 = 没提炼出本文专属判断。
2. **统率**——骨架每个板块都能回答"我为主旨句的哪一面服务"？答不上的板块删或重组。
3. **数据锚**——至少一个具体数据或事实锚点；纯定性（"成效显著"）不合格。

主旨句是"靶心"，不直接出现在文中；主标题、开篇定性句、结尾呼应句都是它的不同表达，三处形成主旨闭环（结尾专属呼应这道门禁由此落地）。

**W1-3 意图**：写 WA——W 说服谁（具体到层级，不写"领导"）、A 希望对方做什么（批准/认同/部署，不写"了解情况"）。摘出领导反复讲的词句，留给 W2-5 用进标题/帽段。

**定汇报立场（立场未定不出主旨备选）**：

| 立场 | 判据 | 问题怎么写 |
|---|---|---|
| 送审/报成果 | 请对方认可、通过、批准**自己的成果**（体系送审、方案评审、验收汇报） | 克制：问题转写为“下步完善方向”或“提请评审确认事项”，**不得自曝否定成果成立的判断**，不以“问题/不足”为主旨 |
| 报问题/求决策 | 请对方就问题拍板、给资源、给政策 | 问题是主体，析原因、给选项 |

主旨备选必须与立场一致。依据 A1：公文是权力的书面运行，送审方自己说“还不准”，等于替评审方否定了送审件。
> P4 教训：体系评审会上，送审方的汇报以“准不准、三处需把关”为主旨，站位错；Jeffrey 的交付版是“为什么建—怎么设计—怎么用”的设计说明，不设问题段。

**W1-4 定种**：读对应 `references/wenzhong/`，取要件清单、骨架、比例区间、字数区间、行文方向。

**意图卡（≤12 行）**：文种（依据）/场景/受众/行文方向/字数/基调/主旨句/WA/**汇报立场**/素材缺口（含**素材时点**：最新素材日期 vs 使用日期） → 交 gongwen 呈报**确认点 1**。有时点缺口时确认点 1 不放行。

## W2 结构设计 → outline.md → 确认点 2

构建方向由场景定：
- **F1 自下而上**：先做 W3-3 素材归堆（先摞全部素材→按"为什么/是什么/怎么办"归堆→通读审缺项），从素材向上概括出主旨，再搭框架。
  - **弃用按内容块登记，禁止整份弃用**：弃的单位是一节、一张表、一段论证，不是一个文件。每块写理由，登入 outline.md“弃用清单”。
  - **能支撑文种要件的内容块不得弃用**：先按 `references/wenzhong/` 取要件清单，逐项在素材里找支撑，找到的必须用。
  > P4 教训：两份培训讲稿因为“口语化”被整份弃用，里面恰好有评价方法（五档评分、等级区间）和必要性论证（三类问题），这两块是送审汇报的要件。
- **F2 自上而下**：主旨→设想读者疑问→逐层回答→缺的素材标 `[待补:XX]`。

**W2-0 范文对照（库里有同类范文时必做，目前讲话稿已建 20 篇）**：搭骨架前，按子类（工作会议讲话／现场会讲话／启动部署讲话／推进会讲话／培训动员讲话／总结讲话）列出同类范文的要件：
```
python3 -c "import json,sys;[print(r['id'],r['grade'],r['org_level'],r['title'][:40],*['  - '+m for m in r['must_haves']],sep='\n') for r in map(json.loads,open('20_knowledge/articles/articles.jsonl',encoding='utf-8')) if r['subtype']==sys.argv[1]]" 启动部署讲话
```
取 2—3 篇（A 级优先，层级相近优先），把 `must_haves` 合并去重，填进 outline“范文对照表”，每条标“具备（落在哪一节）／不适用（理由）”。要件带适用条件的（如“方案已由他人解读时，讲话只点名不复述”），先核本稿是否满足条件，不满足标“不适用”。拿不准写法时读该篇 `why_good`，需要看原文按 `source_path` 打开（本机脱敏批次，不外流）。
> 为什么：P4 第 5、6 轮 F1 起草的缺陷——漏传达上级部署、讲话复述方案、漏写领导责任——单看稿子都自洽，所有门禁打 ✅；拿同类成品一对就看出来。范文对照就是把“拿成品对一对”变成固定动作。只学写法，不搬范文的数据与提法。

步骤：
1. **W2-1 结论先行**：开头三句单独抄出来，读者能否知道要说什么？不能就回 W1-2。
2. **W2-2 入口**：选 SCQA 变体（标准/开门见山/突出忧虑/突出信心）；开头四戒（背景过多、套话、引据过多、叙述过细）。
3. **W2-3 纵向**：so what 向上概括、why so 向下追问，两遍都走通。
4. **W2-4 横向（硬闸）**：同级 MECE——不重不漏；**互换测试**——两个同级标题互换后读起来无差别 = 分类维度不成立；同层只用一种排序（时间/结构/重要性）。
5. **W2-5 提纲物化（硬闸：不可跳过）**：按 `templates/outline.md` 写 `outline.md`——主旨句、三级骨架（每节：标题/核心判断/素材编号/字数）、**论点地图（每个论点只登记一个位置）**、**弃用清单（按内容块）**、缺口。

机检，**0 block 才能呈报**：
```
python3 30_engine/tools/draft_lint.py 50_tasks/…/outline.md --outline 50_tasks/…/outline.md
```
（查主旨句是否判断句、同级标题互换/空泛、论点地图是否填写、一个论点是否登记多处。Windows 用 `python`。）

交 gongwen 呈报**确认点 2：确认即冻结**。呈报时**弃用清单必须列出**，让用户看到丢了什么。之后任何偏离都在 outline.md"冻结后偏离记录"里写明原因。

## W3 内容填充 → v1_初稿.md

**大纲未确认，不展开正文。**

- **逐板块写**，防长文漂移；每个板块只写 outline 里登记给它的论点——**不在别处重复**（论点流窜是 W5 站位审的否决项）。
- **W3-1 意群**：以"观点+支撑"为单位组织，不以自然段为单位。
- **段落结构**：开篇、帽段、做法条、成效、问题、体会、结尾各按文种指南“段落结构”节的句序模板和实测长度写（`references/wenzhong/` 各文件，数据来自 r8 真实成稿）。开篇尤其注意：工作量、过程量数字不进开篇，下沉到对应做法条末句（P4 第 2 轮因此被退两次）。
- **W3-2 论据三元素（硬闸）**：观点 + **概括叙述** + 典型事例。缺概括叙述 = "两元断层"。**数据必须有对比基准**（同比/历史最好/超目标三选一）；"大幅提升""显著改善"后面必须有数字。
- **缺数据写 `[待补:XX]`，绝不编造**数字、比例、金额、单位、人物、案例。
- **W3-3 素材**：每个 A 级素材要么用上、要么在 outline 弃用清单里按内容块写明弃用理由（整份弃用违规）。
- **W3-4 详略**：按文种比例区间（见 wenzhong/）调整；超区间压缩、不足补。
- 遇"指导思想/工作目标/保障措施"等模块，先读 `references/modules/` 对应要点卡再写。
- 行业语体按 `references/tobacco-style.md`；中文引号 “” ‘’。

写完存 `v1_初稿.md`，跑一遍机检（非终稿模式，`[待补]` 暂不拦）：
```
python3 30_engine/tools/draft_lint.py 50_tasks/…/v1_初稿.md --outline 50_tasks/…/outline.md
```
W3 能改的 block（数据无基准、程度副词无数字、序号）先改掉，再交 gw-review。

## 硬规则

- 不编造；`[待补]` 不进终稿。
- 跨客户素材只学方法，不搬他方数据与名称。
- 大纲冻结后，改动若增删论点，必须同步 outline.md 的论点地图并写偏离记录。
- 同一闸连续 3 次过不了 → 停下报告卡在哪，不硬撑。
