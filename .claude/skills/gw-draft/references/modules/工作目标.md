# 模块写法要点卡：工作目标

> 11 章 P1.6 首批 3 张之一。2026-09-24 手工起草，素材来自文种指南（实施方案模块5"目标量化三法"、
> 发展规划模块4"目标指标体系"）。P5 用真实萃取材料校准扩充。

## 功能定位

工作目标段回答"做到什么程度算完成"，是全文唯一的可考核锚点——没有这一段，后面的任务和保障都无从验收。对应 A4 公理（说服力来自证据链而非形容词）在目标层面的落点：目标必须可证伪、可验收，不能是感受性描述。

## 标准结构

```
总体目标（1句定性）：到[时间节点]，[本单位/本领域]实现[战略/状态判断]。
具体目标（分项，1-N条）：[指标名称] 从/由 [基数] 提升/降低至 [目标值]，[完成时限]。
```
方案类：目标≥1条须量化到数字或产出物；规划类：需完整指标表（指标名｜基数｜目标｜年均增速）。

## 常用句式领起词

「到……年，实现……」「……指标达到……」「确保……完成率不低于……」「形成……（产出物）」。

## 好坏对照

❌「管理水平大幅提升，各项指标显著改善。」（quality-checklist.md Q-021/Q-035 典型反例：程度副词无数字支撑）
✅「到2027年底，管理成熟度评价体系覆盖率达到100%，核心指标达标率由72%提升至89%以上。」

## 易错点（目标量化三法，至少占一项，杜绝纯定性）

1. **只有定性无数字**——"基本实现""明显提升""大幅增强"这类表述不可验收，须换成①数字化（完成率≥X%）②产出物化（形成1套办法）③时限化（X月底前）三选一以上。
2. **数字无基准**——只写目标值不写基数/对比，读者无法判断进步幅度（对应 quality-checklist.md Q-005/Q-034）。
3. **目标与任务脱节**——写了目标却在"重点任务"里找不到对应的落地举措（发展规划模块4"指标↔任务双向锚定"）。
4. **把讲话/汇报的"果"误写成目标**——目标是面向未来的承诺，不是回顾已完成的成绩，两者时态不能混。
