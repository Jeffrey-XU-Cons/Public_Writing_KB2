# 模块写法要点卡：指导思想

> 11 章 P1.6 首批 3 张之一。2026-09-24 手工起草，非 M1 萃取产出——素材来自本次分拣整理的
> 文种指南（实施方案/发展规划）+ rhetoric-guide 表一（政治表述固定写法）。P5 遇到技巧汇编/范文里
> 讲"指导思想怎么写"的篇目时，用那批真材料校准、扩充本卡，不是从零重写。

## 功能定位

指导思想段回答"这项工作在什么理论/政策旗帜下展开"，是全文政治正确性的锚点，不是可以随意改写的自由发挥区——错一个提法或顺序就是硬伤（对应 05 章红线 1「政治表述顺序与固定套语零差错」）。它出现在方案/规划/工作报告的"总体要求"部分，不单独成一级标题。

## 标准结构（1-2 句，不展开论证）

```
以[最高层级指导思想]为指导，深入贯彻[党的最新大会/全会精神]，
认真落实[中央/国家局层面部署]，紧扣[本单位工作主线]，[本段收束句：为……提供……]。
```
层级顺序不可打乱（见易错点）；不照抄政策原文大段引用，引够定位即止（详见 quality-checklist.md Q-024）。

## 常用句式领起词

「以……为指导」「深入贯彻」「认真落实」「紧扣……主线」「为……提供根本遵循/有力支撑」。

## 好坏对照

❌「深入贯彻党中央关于建设世界一流企业的战略部署，在烟草行业全面启动……」（第三人称描述上级行为，不是本单位在贯彻，属于 rhetoric-guide 表四"咨询味"同类问题的变体）
✅「以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大精神，认真贯彻落实国家局党组决策部署，紧扣公司高质量发展主线，为管理体系建设提供根本遵循。」

## 易错点

1. **层级顺序倒置**——上位政策放后面、下位部署放前面，命中 quality-checklist.md Q-020（政策引用单句层级顺序），必须高层级在前。
2. **用第三方视角描述上级行为**而非本单位的贯彻动作（见"好坏对照"反例）。
3. **展开成大段论证**——指导思想只定位不展开，展开的内容应该进正文对应板块，不要在这一两句里堆砌。
4. **漏"党的"二字**——"二十大精神"须写全"党的二十大精神"（rhetoric-guide 表一政治表述固定写法）。
