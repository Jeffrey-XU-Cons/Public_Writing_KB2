# 文种指南：调研报告

> 来源：`公文写作体系/文种_05_调研报告/SKILL.md`，按 06 章§6.5 分拣为精华指南。2026-09-24 分拣，P1.5。举例已脱敏。

## 文种定位

调研报告＝「用事实和数据说话，发现真问题、挖深层原因、提可行对策」的分析性公文。三条硬特征：
- 不是工作总结：落点是"问题—原因—对策"，成效只是铺垫
- 不是工作汇报：必须有"调研方法交代"——座谈了谁、发了多少问卷、看了哪些数据
- 不是方案：对策建议只到"方向+举措"层，不展开到任务分解

一句话判据：**问题不是调研得来的、原因停在"重视不够"、对策只是"加强领导"，就不是合格的调研报告，只是套壳的工作汇报。**

## 标准骨架（五段式）

1. 调研背景与方法——为什么调研+怎么调研的
2. 现状与成效——客观摆事实亮数据，不加主观评价
3. 存在问题（分类）——基于调研事实，分类列举真问题
4. 原因剖析（深层）——由表及里挖到根因，逐条对应问题
5. 对策建议（可操作）——逐条对应原因，方向+举措落地

## 方法论模块

### "问题—原因—对策"层进逻辑（地基）
三块是一条"现象→原因→解决方案"的演绎链，不是三个并列罗列的筐。操作：问题逐条编号→每条问题追问"为什么"挖出对应原因→每条原因追问"怎么解"给出对应对策→三列对齐成表，**任何一行缺项都不合格**。

### 问题要真，且分类呈现
"问题真"三条标尺：基于调研事实（能指出座谈/问卷/数据来源）、具体可指（不写"管理水平有待提高"）、不回避（真卡点照写）。分类操作：按维度归堆（认识层/机制层/能力层/数据层，或按业务条线），同层MECE。

### 原因有深度（由表及里）
三层下挖：表层（直接现象）→中层（机制/制度）→根层（能力/认识/资源）。无效原因（禁用）：重视不够、落实不到位、执行力不强——这是结论不是原因。有效原因五类：制度/机制/资源/能力/客观条件。

### 对策可操作，且与原因一一对应
"对策实"三条：对应原因（编号对齐）、可操作（含明确责任主体/动作/抓手）、方向到举措（精确到时间节点/任务分解的活交实施方案文种）。做"原因—对策对应表"逐行核对。

### 调研方法交代（可信度地基）
要交代：调研主体、调研对象、调研方式（≥2种：座谈/问卷/数据分析/实地走访/内部研讨）、调研时段。正文关键处要能回指调研来源（"7家单位座谈中均反映""问卷显示X%受访者认为"）。

## 质量 Rubric（满分21）

| 维度 | 判据 |
|---|---|
| 文种规范 | 五段骨架完整、落点在问题—原因—对策 |
| 问题基于事实 | 每条问题可回指调研来源，具体不回避 |
| 原因有深度 | 逐条由表及里到根因，归得到五类之一 |
| 对策可操作 | 每条含主体+动作+抓手，能落地 |
| 对策对应原因 | 编号逐行映射，无漏无空 |
| 数据支撑 | 关键判断均有数据，含口径与对比基准 |
| 调研方法交代 | 主体/对象/方式(≥2种)/时段齐全 |

PASS≥16｜WARN 13-15｜MAJOR 9-12｜REWRITE<9

## 反模式

1. 问题泛泛、主观臆断（无调研依据）→ 补调研出处，写不出的删或下沉为推测
2. 原因停在表面（"重视不够"式）→ 三层下挖到机制/能力/资源层
3. 对策空喊口号（"加强领导"）→ 补"谁来做+做什么+靠什么抓手"
4. 对策与原因两张皮 → 建对应表逐行核对
5. 无调研方法交代 → 补齐主体/对象/方式(≥2种)/时段
