## 文种定位——总结是什么、不是什么

总结是“回顾既往”的文体——立足已发生的一个周期，用数据和判断说清：**做了什么（成绩）、差在哪（问题）、下步怎么干（打算）**。三个动作：摆事实（数据落地）、下判断（提炼规律性认识）、接未来（问题与下步一一对应）。

**总结 vs 汇报（关键区别）**：
- 时态与目的：总结回顾整个周期、对全局负责；汇报通报某段进展或某专项、对当下负责，常含请示。
- 完整性：总结须三块齐全、覆盖全周期全板块（4-8板块）；汇报可只讲2-4个板块，不求穷尽。
- 数据密度：总结成绩段每条都要有数据且带对比基准；汇报数据可略松。
- 问题段：总结克制列举、不展开原因；专题汇报须析原因。
一句话：**总结是“一个周期的成绩单+体检报告+作战图”，汇报是“一件事的进度条”**，不可一稿两用。

## 标准骨架——“成绩/问题/打算”三块式

```
开篇·总体评价（5%-10%）：周期＋贯彻＋抓手＋机制，一段，可带一句可证伪定性，不放数字；核心数据放进成效节——成效单设一节，节帽段一句定性，数据（带基准）进各成效条（2026-10-03 Jeffrey 裁定按语料改：周期总结 2/2 开篇无数字，与汇报、经验交流开篇规律一致）
主要工作（4-8板块，50%-65%）：对仗小标题+总分结构+每条带数据
存在问题（3-5条，5%-15%）：列举式，不展开原因，收口“必须切实加以解决”
下步安排（3-5条或并入部署，20%-35%）：量化目标+时间节点，与问题逐条对应
```

两个子文种差异：部门/年度总结（1500-4000字，“综合部就…总结如下”，可省指导思想）vs 单位工作报告（4000-10000字，“我代表X党委作工作报告”，必含指导思想引用+形势分析层占15%-20%）。

## 方法论模块

### 主要工作板块写法
小标题做结论句（“坚持X、有力Y”格式，禁纯名词短语和话题句）；板块首句点“聚焦”并复现标题核心词（标题-正文锚定）；正文一是/二是/三是分条，每条=举措+成效数据；重点板块（全文2-3个）可升级“分析级”加规律性判断。

### 排序——同层不混
主要工作板块按重要性或固定业务结构顺序；进展/历程类内容按时间顺序；下步安排与存在问题同序对应。硬规则：同层只用一种排序逻辑。

## 反模式

1. 成绩段只定性无数字 → 补同比/完成率/排名
2. 流水账无主次 → 定重要性排序，次要工作一句带过
3. 问题与下步两张皮 → 下步逐条认领问题，编号对应
4. 打算无量化目标（“进一步加强”）→ 换成“到X月完成X，使X指标达到X”
5. 把总结写成汇报（只讲一两件事、夹带请示、缺问题段）→ 补齐全周期板块、删请示、补三块
