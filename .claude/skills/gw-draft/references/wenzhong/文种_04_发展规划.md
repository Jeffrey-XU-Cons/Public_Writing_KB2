# 文种指南：发展规划

> 来源：`公文写作体系/文种_04_发展规划/SKILL.md`，按 06 章§6.5 分拣为精华指南。2026-09-24 分拣，P1.5。指标示例用占位符（[上期值]/[目标值]），非真实数据。

## 文种定位——三句话

规划＝面向中长期的战略设计，不是年度部署，不是操作手册。
1. **立意要高**：从国家/行业大势切入，把本单位放进“两个大局”里定位，不从“我单位去年干了啥”起笔。
2. **目标要远**：着眼规划期末（5-10年）远景，给可衡量的目标状态。
3. **路径要清**：从总目标到分领域任务到保障，“目标—任务—保障”一条线贯通。

常见错误：通篇是工作总结+工作打算的拼盘，没有“中长期战略设计”的骨相。

常见错误：缺“形势”段直接进目标（立意立不住）；缺指标专栏（目标空心）；保障写成口号；保障只写组织和资金，没写规划怎么落到年度计划、期中怎么评估。

**发展思路的提法要对得上篇章**：思路用了数字化提法的（“确立一个目标、推动‘三高’、建成‘六大体系’、实施‘五项工程’”这类），其中表示任务板块的项（“六大体系”“五项工程”）要在任务篇章找到对应的篇或章，数目相同、用词对得上；目标、理念类的项（“一个目标”“三高”）不必单设篇章，在目标或指导思想里落实即可。AR-0301“六大体系”“五项工程”各成一篇，每个体系、每项工程各一章；AR-0302“六大体系”“四化协同”“五大保障”各成一篇，每项各一章。反例：AR-0303 的“1235”蓝图，“五个支撑”在正文只写出三个层面。范文实测（AR-0301、0302 正例，AR-0303 反例，n=3）。不要求非用数字化提法。

**层级体例**：篇幅大的综合规划可用“第X篇／第X章／第X节”三级（AR-0301 地市级、AR-0302 省级，n=2）；国家局行业规划直接用“一、二、三”章（AR-0305）。选定后全篇统一，篇名、章名各自句式统一。

## 方法论模块

### 立意三字经——定准战略高度
时（时代背景/上级规划）×事（本单位实际）×势（发展趋势）取交集，得出“这份规划在这个时代、为这个单位、应对这个趋势，要解决的核心命题”，即战略定位。常见错误：只有“时”（满篇套话看不出是哪个单位）；只有“事”（就是工作总结，无战略高度）。

### 目标指标体系——规划之眼
两段式：定性总目标（1段战略定位句）+分领域具体目标（排比领起）；定量指标表（指标名｜上期基数｜规划期末目标｜年均增速，四要素齐全）。**指标↔任务须双向锚定**——每个量化指标必须能在重点任务里找到对应落地任务。

### 形势分析——机遇挑战辩证成对
挑战（先抑，层层收到本单位短板，每个配“更加需要……”应对方向）→机遇（后扬，层层落到本单位有利条件）→综合判断（收口定调）。常见错误：通篇“百年未有之大变局”却不落到本单位。

### 规划 vs 方案——判定红线
规划出现“责任分工表”“时间节点表（X月X日）”“牵头/配合部门”到动作级，即已写成方案，须上提为方向性表述。规划任务停在“方向+阶段性目标”层。
范文印证：AR-0301 正文不列分工表，实施篇要求另行“制定分工方案”；AR-0303 把平台项目的分工交给另行制定的实施工作方案。

| 上级规划对接 | 对接且把上位要求转化为本单位任务 |

## 反模式

1. 就事论事无高度 → 用立意三字经重写开篇
2. 目标无量化指标 → 补定量指标专栏（基数-目标-增速）
3. 形势分析套话 → 挑战收到本单位短板，机遇落到本单位条件
4. 任务与目标脱节 → 做指标↔任务双向锚定表
5. 规划写成方案（出现X月X日式动作级分工表）→ 上提为方向+阶段性目标
