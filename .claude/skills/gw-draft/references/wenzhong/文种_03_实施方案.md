# 文种指南：实施方案

> 来源：`公文写作体系/文种_03_实施方案/SKILL.md`，按 06 章§6.5 分拣为精华指南。2026-09-24 分拣，P1.5。举例已脱敏。

## 文种定位——方案是“面向未来的行动设计”

方案写的是“将要怎么做”，不是“已经做了什么”。一句话测试：把每条内容单抄，问“这是承诺一个未来动作，还是陈述一个过往成绩？”是过往的就是混进了总结/汇报。

**三可标准**：可操作（每项任务有明确执行路径）、可落地（有明确责任主体和时间节点）、可考核（有量化或产出物标准）。

常见错误：通篇讲意义要求无具体动作节点（写成动员讲话）；通篇回顾成绩（写成工作总结）。

## 标准骨架——开篇＋四部分

（2026-10-07 更正：原称“五段式”，第 1 段为“背景与目的”，与下方“段落结构”节的一句话开篇不一致。范文 8 篇中 6 篇开篇只用一句话交代依据和目的，不单设背景段（另 2 篇是项目方案、建议书，见变体）；r8 段落结构表的开篇行同样是 1 句。按实测改。）

0. **开篇（依据与目的）**：一句话，“为〔贯彻/落实〕……根据〔依据〕……特制定本方案”，不写形势和意义，不照抄政策原文；长度见“段落结构”节开篇行
   - （可选）**编制依据**单列一节：依据有多项（法律法规、上级政策、企业制度标准、评价准则、标杆实践）时分条列；只有一两项的写进开篇句即可。范文实测（AR-0202、0204、0205，n=3）
1. **总体要求**：指导思想（1-2句）+基本原则（2-4条，须有实质约束非口号）+工作目标（**必含量化指标**）
2. **重点任务**：分项3-8条，每条=任务内容+实施路径+完成标准+完成时点（任务名后括注月份）；分工不逐条写，统一写在组织架构段（见下方“分工写法”）
3. **实施步骤**：分阶段（不少于两阶段），每阶段标起止月份+主要工作+**阶段产出物**（标志性成果、交付文件）。范文实测（AR-0203 各阶段末写“标志性成果”、AR-0206 工作包写“输出”；AR-0201、0204、0208 在任务条里写明产出文件，如评价准则与系列标准、评价检查表与评价报告、诊断调研报告与流程清单，n=5）
4. **保障措施**：组织+资金/资源+考核保障，每条有具体机制

**重点任务与实施步骤可以合并**：按阶段排任务，阶段标题标起止月份、任务条括注月份，不另设“实施步骤”一节（AR-0201 写进“主要内容”，AR-0203、0208 任务写在“实施步骤”各阶段下）。判骨架完整看要件——任务、时间、产出物、责任——是否齐全，不数节数。范文实测（AR-0201、0203、0208，n=3）。

子类差异：实施方案（要件最全）｜工作方案（可合并总体要求；任务与步骤常合并）｜活动方案（弱化指导思想，强化流程+时间+分工）｜评价／诊断类实施方案、项目方案／项目建议书（见下方两个变体）。
常见错误：只有“总体要求”和“保障措施”两头，中间缺“重点任务”和“实施步骤”这个执行核心（合并成一节不算缺）。

## 变体：评价／诊断类实施方案（2026-10-07，范文实测）

为一次评价或诊断写的实施方案，读者是评价方和被评对象双方。任务不是“建什么”，而是“按什么评、评谁评到多细、谁取证、评完怎么改”。

| 段 | 核心功能 | 写法 |
|---|---|---|
| 开篇＋目的 | 为什么评、评完要得到什么 | 一句依据和目的，目的写出评完要得到什么（AR-0204 单设“评价目的”，AR-0205 写在“总体要求”） |
| 评价／诊断依据 | 按什么评 | 单列分条：法律法规、行业规范、企业制度标准、评价准则、标杆实践（AR-0204、0205；建设类的 AR-0202 同样单列） |
| 对象、范围与重点 | 评谁、评到多细 | 对象写到部门或单位层级；范围写到能力域或业务领域（AR-0204 写到能力域，AR-0205 写七个领域并列重点三条） |
| 组织与职责 | 评价方、被评方各干什么 | 评价工作组（或专家组）与被评单位分写职责（AR-0204 工作组下设两个评价小组；AR-0205 组织方、被诊断单位、试点单位、专家组各承担环节） |
| 安排 | 分阶段、有时点、有产出物 | 准备、自评、现场评价、反馈或改进分段，标起止日期；产出物写到评价检查表、自评结果、评价报告（AR-0204 写到日；AR-0205 自查报告、现场诊断、总报告、通报会均有日期） |
| 改进闭环 | 评完怎么改 | 按评价结果制定改进措施并组织实施（AR-0201、0203、0204、0205，n=4）；措施要明确责任人（AR-0201、0203、0205）和时限（AR-0201、0205），并有跟踪督办或整改验证（AR-0201 督办、AR-0205 整改验证）。AR-0204 只写到“制定改进措施，组织改进实施”，是短板不是写法 |
| 要求 | 纪律 | 对评价工作提纪律和质量要求（AR-0204“评价要求”三条；AR-0205“相关要求”分对试点单位、对专家组写） |

**判据**：起草前能回答“评价报告由谁在什么时点交给谁，报告里的问题由谁在多长时间内改完”。答不出，方案还停在“开展评价”的口号层。
**证据**：主样本 2 篇（AR-0204 试点评价、AR-0205 管理诊断），改进闭环另有 AR-0201、0203。资料清单、报告要素、保密要求只有 AR-0205 写了，试点目的写明检验准则只有 AR-0204，均列在文末“待定”。

## 变体：项目方案／项目建议书（2026-10-07，范文实测）

用项目管理体例：交付成果和工作包取代“重点任务”，进度计划取代“实施步骤”。

| 段 | 核心功能 | 写法 |
|---|---|---|
| 需求／背景与必要性 | 为什么立项 | 项目方案写需求（AR-0206 分三层），建议书写背景加几条必要性（AR-0207 四条）；这里可以展开，不受上文一句话开篇的限制 |
| 目标 | 做成什么样 | 总体目标一段＋具体目标分条（AR-0206 设“可测量目标与成功标准”专节，AR-0207 总体＋四条具体）。两篇正文都是定性表述，量化要求按本指南“目标可量化”执行，不照学 |
| 组织机构 | 谁来做 | 领导组、工作组（或建设办）、项目办公室，职责分写（AR-0206、0207） |
| 范围与内容 | 做哪些事 | 按工作包或建设内容分项（AR-0206 五个工作包逐项写责任人、参与人、输出；AR-0207 三阶段 13 步） |
| 进度计划 | 什么时候 | 分阶段标起止日期（AR-0206）或相对月份（AR-0207，立项前用“第 X 月”） |
| 风险与应对 | 可能卡在哪 | 分类写风险和应对（AR-0207 四类）；设了节就要写实，AR-0206 风险节为空是反例 |

## 方法论模块

### 5W2H 落地检验
Why(依据/目的)、What(任务)、Who(责任机构/工作组，在组织架构段统一写)、When(时间节点)、Where(范围对象)、How(路径方法)、How much(量化目标/资源)——任一空白即回去补素材。任务级三问：谁做→何时→做到什么程度，三问全答出才算可执行。

### 任务分解 MECE + 责任到部门
拆分维度三选一且全程一致：业务条线／问题导向／流程阶段。拆出3-8项，两两不重叠、合起来不遗漏；分工写法（2026-10-03 Jeffrey 裁定，以本人推进方案为准）：在组织架构段写清机构设置与各组职责（如建设办＋若干业务组，每组管哪几项任务），任务条只标月份和产出物，不逐条写“牵头”。判据是每项任务都能在组织架构段对上一个负责的组或部门；对不上、或只写“相关单位/各部门”的，仍算无责任主体。r8 方案 8 份中只有 1 份逐条写“牵头”。

### 目标可量化 + 步骤有时间节点
目标量化三法（至少占一项）：数字化、产出物化、时限化，杜绝“基本实现/明显提升”。步骤标精确月份起止，不用“上半年/年内/适时”。
范文 8 篇只有 AR-0201、0202 写了数量或时点目标，其余是定性目标。这是样本短板，不降低本条要求；审校时不能拿“范文也没量化”放行（gw-review pass3 已写明）。

## 反模式

1. 目标空泛无量化（“基本实现/大幅增强”）→ 换数字/产出物/时限
2. 任务无责任人（“各单位/相关部门”）→ 在组织架构段写清各组职责，让每项任务对上一个组或部门
3. 只有要求没有步骤 → 补“实施步骤”段，分阶段标精确月份
4. 保障措施套话（“加强领导、提高认识”）→ 写清谁牵头督查、什么频次、结果怎么用
5. 方案写成总结或汇报（通篇“已完成/取得成效”）→ 全部改未来式
