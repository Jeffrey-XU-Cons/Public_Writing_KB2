## 模式 A · 常规审校（F1/F2 初稿 → 终稿）

输入：任务目录下的 `v1_初稿.md`、`outline.md`（已冻结）。按顺序走，**每个 pass 最多 3 轮**，轮次记在 review_report 第一节。

**pass1 格式审（W5-1，先筛，不过不进后续）**
```
python3 30_engine/tools/draft_lint.py 50_tasks/…/v1_初稿.md --outline 50_tasks/…/outline.md
```
`[block]` 全部改掉才进 pass2；`[warn]` 逐条过目，确认后可保留并在报告里说明。再用 LLM 补判：文种要件齐全、行文规则、标题四戒。

**pass2 措辞审（W4-3/W4-4 + W5-2）**：措辞分寸（请示"恳请"≠"要求"）、大话降级、程度副词须有数据、主语残缺、零信息句、烟草术语与搭配（查 `20_knowledge/terms/terms.jsonl`）。**句级改写在本 pass 内立即复检**，防改出新问题。

**pass3 站位审（W5-3）**：政治表述顺序与固定套语、政策引用层级（高在前低在后）、**论点地图核销**（逐条核对每个论点只在登记位置出现，出现在别处 = 流窜）、板块比例、首尾呼应。**严重失分退 W2**（见退回规则）。

**pass4 润色（W4-1/4-2/4-5）**：标题结论化、结尾专属呼应（能原样搬到别的文章 = 不合格）、文气中断点、最长 3 段压缩 20%、核心句锤炼。**金句只从库里定向调取，不编。**产出润色对照表（改前/改后）。

**W5-4 终验**：按 `templates/review_report.md` 写 `review_report.md`，20 条门禁逐条 ✅/❌+定位，待人工裁决项（内部数据、敏感表述——只标记，由用户裁决），知识库贡献分与检索缺口。然后：
```
python3 30_engine/tools/draft_lint.py 50_tasks/…/终稿.md --outline 50_tasks/…/outline.md --report 50_tasks/…/review_report.md --final
```
0 block → 交 gongwen 呈报**确认点 3**。

### 退回规则（最容易做错）

```
失分能靠改句子解决吗？
  能   → W4 就地改（主语残缺、术语用错、措辞分寸、零信息句）
  不能 → 退 W2 重排，再顺次走 W3/W4（站位问题、论点流窜、结构比例失衡）
```
- 站位/流窜/比例三类在句子层修补是徒劳，**退错判失败**；主语残缺、术语用错退到 W2 是小题大做，**退过头也判失败**。
- 某 pass 满 3 轮仍未过 → **暂停上报用户裁决**，不降级放行（问题多半在上层）。

## 模式 B · 诊断模式（F5 他人来稿/旧稿整体改造）

**反着走**：先跑 pass1 机检 + pass2/pass3 的判断，出"失分维度定位"（哪几条门禁失分、根源在 W1/W2/W3/W4 哪层），交 gongwen 回派：
- 根源在 W2（结构/流窜/比例）→ gw-draft 大纲模式重出 outline，重走确认点 2；
- 根源在 W3（无支撑/无基准）→ 补素材，结构不动；
- 根源在 W4（措辞/句子）→ 本 skill 定点改。

**不重写无关板块。**

## 模式 C · 定点修改（F4，口语触发，不走完整主干）

| 用户说 | 操作 | 要点 |
|---|---|---|
| "标题不行""给几个标题" | 标题操作 | 标题四戒 + 文种标题规范；**一次出 3 个候选，做成选择题**；技法见 title-guide |
| "这段太乱""重排这段" | 段落结构操作 | 段首撮要、总分对应、MECE 重排、补过渡 |
| "这段太虚""加点实的" | 内容修辞操作 | 大话降级、具象化（数字/场景锚定）、清零信息句；**没有真实数据就写 `[待补:XX]`，不编** |
| "这句拗口""排比整齐点" | 语句修辞操作 | 25 字断句、主语补全、排比节奏、领起词交替（防"一是坚持…二是坚持…"） |
| "结构不对""大纲重新搭" | **不在本 skill 改** | 退 gw-draft 大纲模式，重走确认点 2 |

产出纪律：**一律附前后对照**（只列改动的句/段），不整稿重发；改动若增删论点，声明并同步 outline.md 的论点地图。

## 硬规则

- 不编造数字、案例、金句；缺就 `[待补:XX]`，终稿前必须清零。
- 跨客户素材只学方法，不搬他方数据与名称。
- 中文引号 “” ‘’。
- `review_report.md` 不生成，不得呈报终稿。
