## 选类速查

| 主题/场景 | 首选技法 | 备选 |
|---|---|---|
| 党建/干部/精神状态 | 比喻类、引用类 | 重复类、提问类 |
| 系统部署/多板块并列 | 数字类、对称类 | 重复类 |
| 经济运行/指标汇报 | 单字类、数字类 | 对称类 |
| 教育整顿/批评与自我批评 | 提问类 | 谐音类（仅书面） |
| 仪式致辞/寄语/欢送 | 引用类（温情）、复合类 | —— |
| 整改落实/专项行动 | 比喻类、数字类 | 对称类 |

一篇通常主用1类、点缀1类，避免技法打架。**讲话稿禁用谐音类及一切靠看字辨义的技法**（对应文种指南「文种_06_现场会讲话」的边界约束）。

## 九类技法

**一、比喻类**——动宾引号式「筑牢制度『防火墙』」；这个/这条强调式；工具+双侧重式；四并列体系式（同组四并列须意象差异化）；拟人形象式（多用党建/干部状态）。要点：比喻词加引号，与主题意象相关。

**二、数字类**——数字成语串联式；「X个X」+比喻式；递增数字并举式（由小到大体现层次）；梯进总分式（适合系统部署）；分步落实式（配括号注释）。要点：数字须真有N条对应内容。

**三、重复类**——同句式排比式（换核心词）；标准+选用式；聚焦让X动起来式；从特别能X感悟式。要点：重复词须有强调价值，各条须并列或递进不凑数。

**四、引用类**——汲取X之力式；古诗起句式（适合重要场合）；涵养X底气式（三词递进）。要点：引用放引号、与主题高度契合。

**五、对称类**——动宾对仗式（字数同、词性对）；双比喻对称式；之笔绘线式。要点：前半做法后半成效，字数4-8字为宜。

**六、谐音类**（⚠仅书面材料，讲话稿严禁）——谐音对比式；谐音核心字式；同字镶嵌系列式。要点：谐音须精准且意义对立。

**七、复合类**——引用+比喻式；温情寄语式（限仪式场合）。要点：易堆砌，一篇至多1-2处。

**八、提问类**——自我审视式（适合教育整顿）；三问部署式（为什么/怎么干/和谁干）；二元对比式。要点：问完必须答。

**九、单字类**——维度+单字式；单字+效应式；从X看单字态势式（适合经济汇报）；在单字一线增强能力式。要点：单字须高度概括对应维度核心，常括注说明。

## 复合改造示例

数字×比喻：「实施『三大工程』（数字），唱响『主旋律』（比喻）」
引用×比喻：「以『千磨万击还坚劲』的作风（引用），弘扬艰苦奋斗的『传家宝』（比喻）」
对称×单字：组内每条用对称骨架，核心位嵌系列单字
