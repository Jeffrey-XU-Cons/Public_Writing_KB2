```markdown
## 模式一：框架优先生成全文

### Step 1：准备工作
读取以下内容（按顺序）：
1. 当前任务文件夹内所有文件（素材）
2. 必读知识库文件（规则、骨架、词典、术语、金句、段落）
3. 对应文种高分范文 3-5 篇

### Step 2：确认任务参数
询问：文种 / 主题与核心内容 / 字数要求 / 受众

### Step 3：输出逻辑框架（固定格式）
- 文种 + 主题 + 预计字数
- 每个一级标题下：（一）小标题 + 第N句 [作用]——[内容方向] + 句间衔接
- 意思分布检查：每个论点→仅在某节出现

输出后说"框架已完成。请确认（说\"确认\"继续展开全文），或直接告诉我要改什么。"

### Step 4：等待确认 — 不得在你确认之前展开全文，这一步不可跳过

### Step 3.5：提纲逐句打磨
对框架里每一句的内容方向，逐句细化为三个要素：
1. 主体：这句话写的是谁
2. 动作：这句话的核心动作
3. 支撑点：这句话的落脚依据（数据/政策依据/对比基准）

如某句暂无支撑数据，标注「[待补充：需XX类数据]」，不得用模糊表述占位。

### Step 5：等待二次确认

### Step 6：展开全文
按确认后的框架逐部分展开，每展开一个部分执行质量检查：意思流窜检查 / 术语检查 / 逻辑检查
全文完成后：1. 输出完整全文；2. 保存到 v2_全文.md；3. 说明引用了哪几篇范文
```

### 6.1 skill_style.md v1.3 — 烟草行业语言风格规范

#### 一、开场格式规范

**工作会议讲话开场固定格式：**
```
同志们：
今天[会议名称]的主要任务是，[动词][上级文件/部署]，[动词][本次会议的具体事项1]，[动词][本次会议的具体事项2]，[动词]公司上下[目标表述]。[简短补充说明其他议程……]下面，我讲[X]点意见。
```

禁止：称谓后加「大家好！」/ 感性铺垫 / 形势分析 / 超过 200 字

**工作报告/专题汇报开场固定格式：**
```
[称谓]：
[简短说明汇报背景，1-2句]，[我代表XXX，就XX工作情况作一次汇报/报告]。
```

#### 二、标题格式规范

**一级标题烟草系统惯用格式：**
- 格式A：动词+工作领域+成效判断（「充分肯定管理提升工作取得的积极成效」）
- 格式B：动词+目标+结果（「全面完成管理体系优化提升工作目标任务」）
- 格式C：聚焦+领域+方向（「强化党建引领，坚定不移全面从严治党」）
- 格式D：时间+工作内容+定性（「2024年主要工作」）

**标题必须是结论句，不是话题句（B-6）：**

| 维度 | 话题句（❌） | 结论句（✅） |
|---|---|---|
| 给读者的信息 | 该段在谈什么 | 该段的核心判断 |
| 可证伪性 | 不可证伪 | 可证伪 |

典型对比：
- ❌ 「效能攻坚工作推进情况」 → ✅ 「效能攻坚整体进展顺利，主要指标完成率达 85.7%」
- ❌ 「存在的问题」 → ✅ 「品牌大而不强的状况尚未根本改变」
- ❌ 「下一步工作打算」 → ✅ 「锚定 2027 年目标，再用三年时间打牢成熟度评价体系基础」
- ❌ 「成熟度评价体系的整体设计」 → ✅ 「构建'6+1+1'分层评价体系，全面覆盖公司管理诊断范围」

**判定测试：** 把标题单独抄出来，问"这句话有没有可能是假的？"——能成立或推翻的才是判断句。

**标题与正文首句呼应规则（B-3）：**
每个有标题的段落，其正文首句必须包含标题的核心动词或核心名词，形成"主题词锚定"。

#### 三、正文展开逻辑

**工作成效段标准写法（总-分）：**
```
[总体定性句，含核心数据]。
一是[成效名称]。[具体举措]+[数据支撑，必须有同比对比]。
二是……三是……
```
禁止：只有定性没有数字 / 数字没有对比基准 / "从外部看……从内部看……"三维分析框架（咨询风格）

**【进阶写法】观点提炼级（D-08）：**
在总体定性句后，加一句规律性判断（揭示机制，不重复数据）：
```
[总体定性句]。[实践证明/这说明]，[规律性判断]。
一是……二是……三是……
```

规律性判断四项标准：鲜明 / 深刻 / 新颖 / 实用。**全文 2-3 个重点板块使用，其余保持基础写法。**

示例：
- ❌ 基础写法：「2977 条评价条款全部完成编制，42 个能力域、161 个能力子域实现全覆盖。」
- ✅ 分析级写法：「2977 条评价条款全部完成编制……。这说明，**只有把管理评价工具扎根到具体业务场景而非套用通用框架，标准化才能真正落地、评价才能真正有效。**」

**问题段标准写法（直接列举，不展开分析）：**
```
在肯定成绩的同时，我们也清醒地看到问题和不足。一是[问题名称]，[一句话描述]。二是……三是……
```

**工作部署段标准写法（总体要求+分条 一要/二要/三要）：**
每条须含具体的时间节点和量化目标。

#### 四、常用句式规范

引用上级精神：「认真贯彻落实[上级会议/文件]精神」「深入落实[领导姓名][职务]关于[内容]的重要[讲话/指示/批示]」
成效表述：「[工作领域][动词][成果]，[数据]」「在[条件]的情况下，[成效]+[数据对比]」
问题表述：「[工作领域]需进一步[动词]，[具体表现]」「[问题]的问题尚未根本改变」
部署要求：「各部门、各单位要[动词][工作要求]，确保[量化目标]」

#### 五、禁用表述清单

**禁用的咨询报告风格：**
「三重力量共同驱动」「三个维度」「三个层面」「核心价值体现在三个方面」「用一句话概括」「这正是我们建设这套体系的根本出发点」「底层逻辑」「顶层架构」「核心框架」

**禁用的空洞套话（须替换为具体表述）：**
「高度重视」「进一步加强」「扎实推进」「持续深化」「切实提高」

**禁用的主观判断语：**
「来看，应当」「显而易见」「值得高度重视的问题和不足」「诚意所在」「拨冗莅临」

#### 六、段落节奏规范

- 正文段落一般不超过 300 字；超过须用「一是/二是」分条；禁止超过 500 字的无分条长段
- 工作成效段：每个「一是/二是/三是」条目至少含 1 个数据；数据必须含对比基准；全文数据口径必须统一

#### 七、讲话稿 vs 汇报材料语体差异（D-09）

| 维度 | 讲话稿 | 汇报材料 |
|---|---|---|
| 句长上限 | ≤20 字/句 | 25-40 字/句 |
| 长句拆短 | 必须 | 视情况 |
| 排比/对仗 | 多用 | 适度 |
| 从句嵌套 | 避免 | 允许 |
| 数据呈现 | 口头化（约86%/将近三千条） | 精确数字 + 对比基准 |
| 提顿词 | 必须（同志们/下面/要特别注意） | 删除，改书面过渡语 |
| 第一人称 | "我/我们/同志们"混用 | "我们/公司/某部"为主 |

**互改清单**详见原文。

#### 八、讲话稿生动性与鼓动性（D-15）

**生动性：** 全文应有至少 1 处形象化表述
- 比喻：「管理成熟度评价就像企业的体检——不是为了得高分，是为了知道哪里需要治。」
- 典故/成语：「'临渊羡鱼，不如退而结网'……」
- 身边案例：「玉溪卷烟厂用 8 步改善法解决分类对标问题……」

**鼓动性三步：**
1. 明确听众身份（一线职工/中层管理/卷烟厂厂长）
2. 找出听众关切
3. 把号召语锚定到听众关切

**检验方法：** 将号召段中的「我们/大家」替换为具体听众群体，若仍贴切→泛化；若立即不通顺→锚定到位。

**通俗性：** 选 1-2 个关键数据用「相当于……」比较句：
- 「85.7%——相当于每 20 项指标中有 17 项完成了攻坚目标。」
- 「降本增效 36 亿元——相当于一个中型卷烟厂一年的利润总和。」

### 6.2 skill_framework.md v1.4 — 公文逻辑框架设计技能

#### 零、框架设计前置：立意高度确认（D-06 / MT-004 时·事·势）

**开始搭框架之前，须先回答以下三题：**

**① 时——当前最新上级精神/政策是什么？**
> 示例：「国家局推进企业管理提升三年行动……」

**② 事——本文核心工作的现状、问题、本质是什么？**
> 示例：「公司已建成 2977 条评价条款，覆盖 42 个能力域；核心问题是如何让条款从纸面走进卷烟厂和业务部门的实际管理动作；本质是从'有标准'到'用标准'的转化。」

**③ 势——本文论断是否顺应当前行业/公司发展方向？**

**三题回答完毕后，再进入框架设计。** 若某题回答不出来，说明素材准备不足。

#### 一、框架设计的六大核心原则

**原则一：结论先行** — 每个部分第一句是核心结论，不是背景铺垫

**原则二：同级 MECE** — 同一层级相互独立、完全穷尽

**原则三：意思不流窜** — 每个论点、每个数据、每个成效，全文只在一处出现

**原则四：层级递进明确** — 一级是「总体判断」，二级是「支撑一级的具体方面」，正文是「支撑二级的事实和数据」

**原则五：用核心观点统率全文（D-03）** — 先用一句话写出主旨句

主旨句格式：`[时间段] + [主体] + 在[工作领域]方面 + [取得/面临][什么判断] + ，[核心数据/事实印证]`

**主旨句三项检验：**
1. **可证伪性** — 换个单位、换个时段就成立的，不合格
2. **统率性** — 每个分板块能回答「我在为主旨句的哪一面服务」
3. **数据锚** — 含至少一个具体数据或事实锚点

**主旨句与标题的关系：** 主旨句写给自己看（靶心），不直接出现在文稿；主标题、开篇定性句、结尾呼应句是主旨句的不同表达，三处形成"主旨闭环"。

**原则六：排列顺序与内容性质匹配（C-02）**

| 内容性质 | 对应排列顺序 | 错误用法 |
|---------|------------|---------|
| 工作进展/历史回顾 | 时间顺序（过去→现在→未来） | ❌ 先"2026 年计划"后"2024 年启动" |
| 成效汇报/板块并列 | 重要性顺序（最重要先说） | ❌ 边缘工作放第一条 |
| 问题分析/原因阐述 | 意义顺序（原因→结果；问题→措施） | ❌ 先讲措施后讲问题 |

同一层级内不得混用不同排序逻辑。

#### 二、不同文种的框架模板

**工作会议讲话（三段式）：**
```
第一部分：充分肯定/全面总结+工作领域+成效定性
  1 个总体概述段 + 3-5 个分板块 + 1 个问题段
第二部分：准确把握形势/深刻认识意义+动员性结语
  1 个总体判断段 + 2-4 个分析角度
第三部分：锚定目标任务/全力推进+年度重点工作
  1 个总体要求段（含量化目标）+ 3-6 项重点工作（一要/二要/三要）
```

**工作报告框架：**
```
开篇概述（200-300 字）：总体定性 + 核心数据
主要工作板块（4-8 个）：每板块"（X）坚持[做法]，有力[成效判断]"，含数据
存在问题（3-5 条）：一是/二是/三是，不展开
下步安排（3-5 条）：每条有量化目标和时间节点
```

**专题汇报框架：**
```
背景与定位（300-500 字）
核心内容（1500-3000 字，2-4 部分，每部分一是/二是/三是）
推进情况与成果（800-1500 字）
存在问题（300-500 字，直接列举）
下步工作（500-800 字，时间节点+量化+标志成果）
```

#### 三、句级框架设计方法

**句级框架格式：**
```
（一）[小标题]（本段核心论点：XXX）
  第1句：[作用标注]——[具体内容方向]
  第2句：[作用标注]——[具体内容方向]
  衔接词：「在此基础上」「由此带来」「与此同时」「不仅如此」
  第3句：[作用标注]——[具体内容方向]
```

**句间衔接逻辑：**
- 递进：「不仅……更……」「在此基础上……」
- 因果：「正是因为……所以……」「这一举措带来……」
- 转折：「在肯定成绩的同时，我们也清醒地看到……」
- 并列：「一是……二是……三是……」「既……也……」
- 总分：「主要呈现以下特点」「重点做好以下工作」

**工作部署段的三元逻辑检查（D-02 / BG-013）：**

| 段落类型 | 必须包含 | 最低标准 |
|---------|---------|---------|
| 工作部署段 | ②为什么+③怎么办 | 重要性 1 句 + 措施 ≥2 句 |
| 问题分析段 | ①是什么+②为什么 | 说清是什么问题 + 说清危害/原因 |
| 工作总结段 | ①是什么+③怎么办 | 说清做了什么 + 说清结果/数据 |

**示例：**
```
❌ 纯措施段（缺②）：
「一要加快推进评价标准修订。由企管部门牵头，各业务组于7月底前完成三级特征描述的修订，确保等级台阶感清晰可辨。」

✅ 补充②后：
「一要加快推进评价标准修订。当前三级与四级的特征描述区分度不足，直接影响评价结论的说服力和被评价方的接受度——这是本次专家评审最集中的意见，必须在正式发布前解决。由企管部门牵头，各业务组于7月底前完成修订，确保相邻等级台阶感清晰可辨。」
```

#### 四、框架完成后的自查清单

```
主旨检查：
□ 已提炼主旨句，通过三项检验（可证伪性 / 统率性 / 数据锚）
□ 每个一级板块能回答「为主旨句的哪一面服务」
□ 主旨句核心判断词在开篇定性句、结尾呼应句各出现一次（主旨闭环）

结构检查：
□ 一级标题符合烟草系统格式（动词领起+判断句）
□ 同级标题 MECE（相互独立，完全穷尽）
□ 各部分字数分配合理（核心内容占比 60% 以上）

创新点标注（D-05）：
□ 新提法：[首次使用/首次系统阐述的表述]
□ 新数据：[本期新增的最新数据]
□ 新举措：[本期新增的工作机制/方法/路径]
□ 若三项均无创新，须说明原因，并考虑调整框架角度

论点检查：
□ 每部分核心论点唯一（不与其他部分重叠）
□ 意思分布表完整（每个核心论点只在一处出现）
□ 有「结论先行」
□ 论从事出验证（A-4）：遮住结论句，只看支撑段，读者能否自然得出同一结论？

数据检查：
□ 成效部分有量化数据规划
□ 数据有对比基准（同比/目标完成率/行业对比）
□ 全文数据口径明确

逻辑检查：
□ 句间衔接逻辑已标注
□ 段间过渡自然
□ 问题部分与下步部署一一对应
```

### 6.3 skill_quality.md v1.4 — 公文质量检查规范

#### 一、意思不流窜检查

**论点地图：**
```
论点A：[XXX成效] → 仅在 第一部分（二）出现
论点B：[XXX问题] → 仅在 第三部分 出现
数据X：[23项指标提升率85.7%] → 仅在 第一部分开篇 出现
```

#### 二、逻辑层次检查

**MECE 检查：** 同级标题逐对判断是否有内容交叉、是否有遗漏

**层级归属验证——上下位概念并列识别（C-06）：**
对并列 N 个条目执行「任意两条互换测试」——A 是否是 B 的下位概念？

典型错误：
- ❌ 「重点做好三项工作：一是党建引领；二是支部标准化建设；三是发展党员。」（后两项是「党建引领」的下位概念）
- ❌ 「三大管理体系：一是质量管理；二是安全管理；三是 ISO 9001 认证。」（ISO 9001 是质量管理的工具）

**总分数量精确对应检查（C-07）：**

触发条件：文中出现「主要体现在 X 个方面」「重点做好 X 项工作」「主要存在 X 个问题」等总括句时。

检查三项：
1. 数量精确一致
2. 语义匹配
3. 无遗漏无多余

**结构比例检查（C-05）——工作汇报/工作报告类文体：**

| 板块 | 占全文字数 | 常见失衡方向 |
|------|-----------|------------|
| 成效/主要工作 | **40%–55%** | ❌ 超过 60%：变流水账 |
| 问题/不足 | **10%–20%** | ❌ 低于 5%：一句带过 |
| 下步打算 | **25%–40%** | ❌ 低于成效部分一半 |

仅适用工作汇报/工作报告，不适用方案、讲话稿。

**标题-内容对应性检查（B-1）——双向验证：**

**正向：标题→内容** — 摘取标题核心动词和核心对象，检查正文是否在其语义范畴内

**反向：内容→标题（内容归属验证）** — 把正文每句的核心语义抽取出来，逐句判断归属哪个标题范畴

典型错误：
```
❌ 标题：「（一）加强组织领导」
   正文：「成立专项工作组（√）。投入资金 230 万元（✗ 属于资源保障）。
          确保 2026 年 6 月底前完成（✗ 属于时间安排）。」

✅ 修正：
   或扩大标题范畴 → 「（一）强化组织保障」（含组织+资源+时间）
   或拆分为三个独立标题 → 「（一）加强组织领导」「（二）落实资源保障」「（三）明确时间节点」
```

**烟草系统常见误区：** "加强组织领导"标题下杂糅组织/资金/时间/考核四件事，须按业务实质拆分。

**文种-内容侧重点检查（C-04）：**

| 文种 | 主导要素 | 内容比例要求 |
|------|---------|------------|
| 工作汇报/工作报告 | **果**（成效+数据） | 「果」≥50%；「法」≤30% |
| 实施方案/工作方案 | **法**（措施+时间节点+责任人） | 「法」≥60%；「因」≤20% |
| 专题分析/调研报告 | **因**（原因分析） | 至少分析到第二层原因 |
| 发展规划/三年计划 | **类+法**（目标分类+实施路径） | 目标分层 + 对应路径 |

烟草汇报最常见失焦：「一是/二是/三是」各条用 2/3 篇幅描述"做了什么"，只用 1/3 讲"取得了什么"→须翻转比例。

#### 三、烟草行业规范检查

**政治表述顺序（不得倒置）：**
习近平新时代中国特色社会主义思想 → 党的 XX 大精神 → 中央经济工作会议 → 全国烟草工作会议 → 省委省政府要求 → 国家局党组部署

**固定政治套语（不得改写）：**
「坚守发展和规范两条底线」「担当奋进、主动作为、竞相发展」「跳起摸高、争先进位」「高质量发展」（不是"高质量的发展"）

**烟草专业术语（参考 03_dictionary/tobacco_terms/）：**
- 「省局（公司）」不是「省公司」
- 「直属单位」不是「下属单位」
- 「两烟」= 烟叶+卷烟
- 「万担」是烟叶计量单位（1 担=100 斤）
- 「箱」是卷烟计量单位（1 箱=50 条=500 包）
- 「成熟度评价」不是「成熟度考核」
- 「能力域」「能力子域」「核心要素」「关键举措」是专有术语，不得替换

**公文格式：**
- 标题层级：一、→（一）→ 1. →（1），不得跳级，不得混用
- 百分数用阿拉伯数字（85.7%，不是"百分之八十五点七"）
- 序数词用中文（第一，不是第 1）
- 时间节点必须精确到月份

#### 四、数据质量检查

**必须有对比基准：**
- ❌ 「实现税利 148.99 亿元」
- ✅ 「实现税利 148.99 亿元，超额完成年度目标任务」
- ✅ 「一类烟销量占比 17.89%，在 19 家中烟公司中排名第 17 位，低于行业平均水平 38.57%」

**程度副词须有数字印证（A-2）：**

**高风险词表**（出现即触发检查）：
大幅、大幅度、显著、明显、翻倍、跃升、大力、快速、有效、全面、全方位、大幅提升、显著改善、明显好转、大力推进

检查步骤：
1. 全文搜索上述词语
2. 对每处出现，检查其后 **3 句内**是否有具体数字支撑
3. 无数字 → ①补充数字（"大幅提升 → 提升 23 个百分点"）；②删除程度副词，改为可验证表述

#### 五、完成后通读检查

**段头撮要检查（C-03 / A-6 / MT-008）—— 只读首句测试：**
1. 取出所有正文段落首句
2. 只读首句——能否串联起全文完整逻辑主线？
3. 不能 → 修改对应段落首句

段首句合格标准：
- 必须是**判断句**（主语+谓词+宾语/补语，可判真假），不得是过程描述句、背景铺垫句、引言句
- 必须能**概括全段**

**单句信息量检查（A-3 / LR-002「废话」）——零信息句三特征：**
1. **重申型**——只是把上文已说过的观点换种说法再说一遍
2. **过程型**——只描述行为过程（"我们认真组织……扎实推进……"），但没说明结果
3. **可压缩型**——用一个更简洁的短语完全可以替代

**删除测试：** 把这句删掉，重读上下文，文章信息量有无减少？无减少 → 删除。

示例：
- ❌ 「我们高度重视体系建设工作，认真组织各项任务推进，扎实抓好工作落实。」（过程型）
- ❌ 「这一举措的实施，对推动管理水平的提升具有重要意义。」（重申型）
- ✅ 「体系建设投入工作日 1240 个，覆盖 42 个能力域，最终产出 2977 条评价条款。」

**文气通顺检查（D-04 / SP-001）—— 朗读全文，标记三类中断点：**
1. **话题跳跃点**——前后两句话题突然切换，没过渡
2. **节奏断点**——连续 3 句以上字数相近（如全 25 字左右），单调感
3. **逻辑空白点**——读到某处感到"前面没铺垫，这个判断怎么来的"

达标标准：全文中断点清零。任一类 ≥3 次须重新修订。

**句法完整性检查（A-5 / LS-009）—— 三类主语残缺：**

| 句式模式 | 修复方法 |
|---------|---------|
| 「通过……，[提高/实现/达到]……」 | 补充明确主语（公司通过……，实现了……） |
| 「经过……，[取得/形成/建立]……」 | 同上 |
| 「在……情况下，[省略主语][动词]」 | 确认是否可省略，不可省时补全 |

**措施句完整性检查（A-1 / CQ-012）—— 三要素：**
1. 责任主体（谁来做）
2. 具体事项（做什么）
3. 时间节点或量化目标

合格格式：`[责任主体]于[时间节点]前完成[具体事项]，确保[量化目标]。`

典型不合格：
- ❌ 「进一步加强组织领导，持续深化改革攻坚，不断提升工作效能。」（无主体、无时限、无目标）
- ✅ 「企管部门于 6 月底前完成 42 个能力域评价标准的修订，确保每个子域三级特征描述达到'行业达标水准'的明确界定。」

**首尾呼应检查（C-01 / SP-006）：**
1. 摘出开篇核心定性句
2. 摘出结尾号召/结论句
3. 比对：结尾句中是否出现开篇核心定性句的主题词或核心判断词？

示例：
- ❌ 通用结尾：「让我们凝心聚力、担当作为，为公司高质量发展贡献力量！」（任何文章均可用）
- ✅ 呼应式结尾：「下一步，我们将以本次评审为契机，把 2977 条条款真正落到卷烟厂车间和综合管理部门，让'定性判断'走向'定量定级'，推动公司管理成熟度水平迈上新台阶。」

**套话可移植性测试（C-12 / LR-012 奥卡姆原则）：**
将每段的单位名称、数字、具体事项替换为其他单位信息，若替换后仍成立 → 套话，须改写。
每段至少含一个「不可替换信息」（具体数字/专属事件/具体部门+具体行为）。

**论从事出验证（A-4 / LR-008）：**
遮住结论句，只看支撑段，读者能否自然得出同一结论？不能 → 结论与支撑材料脱节。

**删除清单：**
- 「用一句话概括……」「简而言之……」等引导语
- 「这正是……的根本原因/出发点/所在」等总结句
- 「我们也清醒地认识到，……这一问题如果得不到解决……」过度铺垫
- 「诚意所在」「深度参与」「拨冗莅临」文艺化表述

## 七、骨架 YAML 全文

> 来源：`01_templates/A2_审核草稿_11种文体骨架.yaml` + `01_templates/A2_补充骨架_修订版.yaml`

### 7.1 七种核心文体（A2_审核草稿）

涵盖：经验材料、工作计划、实施方案、管理制度、会议纪要、工作汇报、专题汇报

**示例 — 工作汇报：**
```yaml
doc_type: "工作汇报"
usage_scene: "向上级领导或主管部门通报某一时期工作进展、完成情况和下步安排"
word_count_range: "1000-3000"
structure_skeleton:
  - section: "开篇：汇报背景与目的"
    rule: "用1-2句话说明汇报的工作背景和汇报目的；不超过100字；直接切入，不铺垫废话"
  - section: "工作开展情况（主体，分条列项）"
    rule: "按工作板块或推进逻辑分2-4条，每条用小标题领起；每条须有：做了什么、怎么做的、达到什么效果；有数据支撑；每条200-500字"
  - section: "存在的问题和不足"
    rule: "如实列出当前工作中存在的主要问题，须具体到具体事项，不得只写'整体推进顺利'等回避性表述；一般2-4条"
  - section: "下一步工作计划"
    rule: "针对存在问题提出下步举措，须有时间节点和责任要求；一般2-4条"
constraints:
  - "主体部分不得全篇堆砌已完成工作清单，须有工作进展的逻辑脉络"
  - "不得在汇报中夹带对上级的请示事项或资金申请"
  - "存在问题部分不得回避，不能以'总体进展顺利'带过"
  - "时间节点须明确到月份"
  - "数据须真实准确，不得使用'大幅提升''显著改善'等无具体数字的模糊成效"
quality_checklist:
  - "检查开篇是否清楚说明了汇报背景"
  - "检查主体各条是否都有具体数据或事实"
  - "检查存在问题部分是否真实反映了当前卡点"
  - "检查下步计划中的时间节点是否已落到月份"
  - "通篇检查是否有'请领导批示''请给予支持'等请示性表述"
```

**专题汇报骨架要点：**
- 字数 1500-4000
- 结构：专题背景与汇报目的 → 基本情况（现状描述）→ 主要做法与进展（核心段落，2-4 条）→ 存在问题及原因分析 → 下步工作建议（或请示事项）
- 核心 constraint：**全篇聚焦一个主题**，原因分析须有实质内容（不能只写「重视不够」），如涉及请示须明确写出「请求上级……」

**实施方案骨架要点：**
- 字数 1500-4000
- 结构：总体要求（指导思想+原则+目标）→ 主要任务（3-8 条，含牵头单位）→ 职责分工 → 实施步骤（启动准备/全面推进/总结验收三阶段）→ 保障措施 → 督查考核
- 核心 constraint：不得缺少量化工作目标 / 每项任务有明确牵头单位 / 时间节点精确到月份 / 督查考核须有具体机制

**经验材料骨架要点：**
- 字数 1000-2500
- 结构：标题 → 工作概况与成效（开篇点题）→ 主要做法（2-5 条，每条小标题 8 字以内）→ 创新点 → 主要成效（数据支撑）→ 体会与思考
- 核心 constraint：做法小标题不得使用"高度重视、深入推进"等套话；每条做法必须说明"怎么做的"

**工作计划骨架要点：**
- 字数 800-2500
- 结构：指导思想与总体目标 → 工作原则 → 重点工作任务（4-8 项）→ 实施步骤或时间安排 → 保障措施
- 核心 constraint：每项重点工作必须有量化目标 / 时间节点必须明确到月份 / 责任主体明确到部门或岗位

**管理制度骨架要点：**
- 字数 800-3000
- 结构：第一章总则 → 第二章职责分工 → 第三章具体规定 → 第四章监督与考核 → 第五章附则
- 核心 constraint：条款须区分"应/可/不得"三种规范类型 / 处罚条款须有具体措施和量级 / 须明确废止旧制度

**会议纪要骨架要点：**
- 字数 500-2000
- 结构：纪要标识 → 基本信息（会议要素）→ 议程或议题 → 会议内容（分议题）→ 决定事项与责任分工 → 印发说明
- 核心 constraint：未达成共识不得表述为"会议决定" / 不得新增会议未讨论事项 / 决定事项须明确责任人和完成时限

### PW 禁用词精选（绝对用语禁忌 9 条 + 价值判断禁忌 5 条）

**绝对用语：**
- ❌ 最好的 → ✅ 较好的/更好的
- ❌ 完全 → ✅ 基本上/较为/大体上
- ❌ 所有 → ✅ 主要/基本/绝大多数
- ❌ 永远 → ✅ 长期/坚持/始终
- ❌ 必定会 → ✅ 有利于/有助于/可望

**价值判断：**
- ❌ 最先进的 → ✅ 先进的/领先的
- ❌ 最高水平 → ✅ 高水平/较高水平
- ❌ 完美的 → ✅ 良好的/较为完善的

**行业特定禁忌：**
- ❌ 烟草销售 → ✅ 卷烟营销
- ❌ 烟草上瘾 → ✅ 消费习惯
- ⚠️ 烟草利税 → 可用，但需强调社会责任
