# 把一本书做成问答对知识库（CSV）· 完整流程

> 已实测验证：书→萃取→CSV→检索 全链路打通，检索命中率 100%。
> 这份文档教你把任意一本书，做成可检索的问答对 CSV。

---

## 一、整体流程（三步）

```
  一本书（txt/PDF/word）
        ↓ 【第1步】Claude 萃取（靠AI理解，用萃取提示词）
  中间格式文件（|||分隔）
        ↓ 【第2步】运行 to_csv.py 转换
  标准 CSV（问题|答案|关键词|标签|应用场景）
        ↓ 【第3步】放进检索系统
  可检索的问答对知识库
```

**关键认知**：萃取靠的是 **Claude 的理解能力**（第1步），不是固定代码。
代码只负责把萃取结果格式化成 CSV（第2步）。所以这套流程 = **萃取提示词 + 转换脚本**。

---

## 二、问答对的标准格式（5列）

| 列 | 内容 | 关键要求 |
|----|------|---------|
| 问题 | 读者会怎么问 | 口语化，不是书的标题 |
| 答案 | 完整回答 | 300-800字，原理+方法+案例自包含 |
| 关键词 | 检索用词 | **必须含用户口语说法**（决定检索准确率） |
| 标签 | 主题分类 | 便于归类筛选 |
| 应用场景 | 什么时候用 | 具体场景 |

这个格式综合了你提供的两份标准素材（业务问答对表格 + 书籍萃取结构）。

---

## 三、操作步骤详解

### 第1步：用 Claude 萃取（核心）

在 Claude Code 里，把书的内容（或一章）发给 Claude，并让它按 `scripts/萃取提示词.md` 来萃取。

**怎么做**：
1. 把书的文本放进 `input/` 文件夹（txt 格式最简单；PDF/Word 也行）
2. 在 Claude Code 里说：
   ```
   按 scripts/萃取提示词.md 的方法，萃取 input/你的书.txt，
   输出成 ||| 分隔的中间格式，存到 output/萃取结果_中间格式.txt
   ```
3. Claude 会通读内容，识别每个知识点，萃取成问答对

**萃取质量靠这几条保证**（已写进提示词）：
- 一个知识点 = 一个问答对（不合并，保持颗粒度）
- 问题站在读者角度（"怎么写标题吸引人"，不是"技巧03"）
- 答案自包含（只看这条就能理解和用）
- 关键词覆盖口语（"广告没人看"而不只是"当事者意识"）
- 忠于原书不编造

### 第2步：转成 CSV

中间格式有了，运行一行命令：
```
python3 scripts/to_csv.py
```
它会：
- 读 `output/萃取结果_中间格式.txt`
- 转成 `output/知识库.csv`（Excel 能直接打开，不乱码）
- 自动检查：列数对不对、字段空不空、统计字数

### 第3步：用起来

生成的 `知识库.csv` 可以：
- **直接用 Excel 打开**编辑、补充
- **导入检索系统**（前面给你的本地检索系统，把 CSV 转成它的格式即可）
- **导入 Coze/Dify** 等平台（它们都支持 CSV 问答对导入）

## 四、处理一整本书的策略（重要）

一本书几万到十几万字，**不能一次性全塞给 Claude**（超出处理长度）。正确做法：

### 分章节萃取
```
第1章 → 萃取 → 中间格式_第1章.txt
第2章 → 萃取 → 中间格式_第2章.txt
...
最后合并所有中间格式 → 一起转 CSV
```

### 合并多个中间格式
```bash
# 把所有章节的中间格式合并（保留一个表头）
cd output
head -1 中间格式_第1章.txt > 全书合并.txt        # 取表头
tail -n +2 -q 中间格式_*.txt >> 全书合并.txt      # 取所有数据行
python3 ../scripts/to_csv.py 全书合并.txt 全书知识库.csv
```

### 一本书大概能萃取多少条？
参考你提供的素材：一本 17 万字的书，约含 77 个技巧 → 约 77 条问答对。
按这个密度，平均每 2000-3000 字萃取 1 条。

## 五、最关键的提醒：关键词要写口语

实测证明这一条决定检索成败。

萃取时（或事后编辑 CSV 时），关键词列**一定要包含读者的真实问法**：

| 知识点 | ❌ 只写书面词 | ✅ 含口语说法 |
|--------|-------------|-------------|
| 当事者意识 | 当事者意识,相关性 | 当事者意识,相关性,**跟我有关,广告没人看,怎么吸引人** |
| 具体化 | 具体化,强力词汇 | 具体化,强力词汇,**优质严选没用,文案太虚,没有画面感** |

验证数据：用户问"我的广告没人看怎么办"（口语），因为关键词里有"广告没人看"，
所以能 100% 命中"当事者意识"那条。如果关键词只有"当事者意识"，就会漏掉。

## 七、完整示例回顾

本项目已用《好文案一句话就够了》片段跑通：
- 输入：3个技巧的书籍片段
- 萃取：3条问答对（问题站在读者角度，关键词含口语）
- 转换：标准5列CSV
- 验证：用户口语提问，检索命中率 100%

你把自己的书放进 `input/`，重复这个流程即可。
