  dify-api:
    image: langgenius/dify-api:latest
    environment:
      - MODE=production
      - WEAVIATE_ENABLED=1
      - WEAVIATE_ENDPOINT=http://weaviate:8080
    ports:
      - "5001:5001"
    depends_on:
      - postgres
      - redis
      - weaviate

    image: postgres:15-alpine
    environment:
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
    volumes:
      - /data/dify/postgres:/var/lib/postgresql/data
  
  redis:
    image: redis:7-alpine
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - /data/dify/redis:/data
  
  weaviate:
    image: semitechnologies/weaviate:latest
    environment:
      - PERSISTENCE_DATA_PATH=/var/lib/weaviate
      - CLUSTER_HOSTNAME=weaviate
    volumes:
      - /data/dify/weaviate:/var/lib/weaviate

### Task 7.4：RAG 基准性能测试与参数优化
- **任务ID**: T-7.4
- **优先级**: 🟡 中（为后续Agents的稳定运行做准备）
- **负责人**: 工程师

**具体工作**：
```
□ 创建 RAG 基准测试脚本（Python）：
  """
  import requests
  import time
  import json
  
  class RAGBenchmark:
    def __init__(self, dify_api_url, knowledge_base_id):
      self.api_url = dify_api_url
      self.kb_id = knowledge_base_id
      self.results = []
    
    def run_query(self, query_text, top_k=5, threshold=0.5):
      start_time = time.time()
      response = requests.post(
        f"{self.api_url}/retrieval/search",
        json={
          "query": query_text,
          "knowledge_base_id": self.kb_id,
          "top_k": top_k,
          "threshold": threshold
        }
      )
      elapsed = time.time() - start_time
      return {
        "query": query_text,
        "results": response.json(),
        "elapsed_time": elapsed,
        "result_count": len(response.json()['results'])
      }
    
    def benchmark(self, test_queries):
      for query in test_queries:
        result = self.run_query(query)
        self.results.append(result)
      
      # 生成统计报告
      avg_time = sum(r['elapsed_time'] for r in self.results) / len(self.results)
      return {
        "total_queries": len(self.results),
        "avg_response_time": avg_time,
        "p95_time": sorted([r['elapsed_time'] for r in self.results])[int(len(self.results) * 0.95)],
        "results": self.results
      }
  """

□ 执行 RAG 基准测试：
  ├─ 准备 30 个测试查询（涵盖6个文档类型）
  ├─ 运行基准测试
  ├─ 收集性能指标：
  │  ├─ 平均响应时间 < 2秒
  │  ├─ P95 < 3秒
  │  ├─ P99 < 5秒
  │  └─ 检索准确率 > 80%
  └─ 记录结果

□ 根据基准结果优化参数：
  
  如果响应时间 > 2秒：
  ├─ 减少 Top K：5 → 3
  ├─ 增加相似度阈值：0.5 → 0.55（排除低相关性）
  └─ 重新测试
  
  如果准确率 < 80%：
  ├─ 降低相似度阈值：0.5 → 0.45（包含更多结果）
  ├─ 增加 Top K：5 → 7
  └─ 重新测试

□ 最终基准数据记录：
  {
